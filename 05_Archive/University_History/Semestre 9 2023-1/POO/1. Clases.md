## ¿Qué es una clase?
---
Es una forma de 'recetar' o definir cómo van a ser y qué van a contener los objetos que creemos

## ¿Qué es un objeto?
---
Es una instancia de una clase. Cuando instanciamos un objeto, estamos creando una instancia de la clase, es decir, creamos algo que fue el resultado de haberlo pasado por una clase. Ese algo es un **Objeto**

```Python
class Celular():
	# Atributos estaticos
    marca = "Samsung"
    modelo = "S23"
    camara = "48MP"

# Instancias de la clase Celular
celular1 = Celular() # Estos ya son objetos
celular2 = Celular()
celular3 = Celular()
celular4 = Celular()
```


### ¿Cómo construir clases que nos permitan crear objetos de diferentes tipos con distintas características?

# Atributos o Propiedades
---
Son variables que pertenecen a una clase. Los atributos son cosas que caracterizan a un objeto. 
En el ejemplo anterior del celular, los atributos de la clase Celular son:

- marca
- modelo
- camara

## Método especial Python (Constructor)
---
Cada vez que instanciamos esta clase, este método `__Init__` se ejecuta automáticamente. Este método se le conoce como **'El método Constructor'**

```Python
class Celular:
    def __init__(self): # Metodo Constructor
        pass
```

*self:* Es una forma de hacer referencia al mismo objeto  

```Python
self.marca 'es como si dijera' celular.marca
self.modelo 'es como si dijera' celular.modelo
```

```Python
class Celular:
					#Parametros
    def __init__(self, marca, modelo, camara):
		# creando la propieda de self 
        self.marca = marca # accediendo al parametro de la funcion init
        self.modelo = modelo
        self.camara = camara

	# Aca se definen cual va a ser la propiedad del objeto como tal

celular1 = Celular("Samsung", "S23", "48MP")
```

Lo que hace la función es:
- 'self.marca' toma el valor de lo que se le pase al parametro 'marca'
- 'self.modelo' toma el valor de lo que se le pase al parametro 'modelo'
- 'self.camara' toma el valor de lo que se le pase al parametro 'camara'

## Métodos o Acciones
---
Son acciones que puede realizar un objeto.

Ponemos self para que uno de los parámetros haga referencia al mismo objeto que estamos creando. 

De esa forma puede auto referenciarse.

```Python
class Celular:
    def __init__(self, marca, modelo, camara):
        self.marca = marca
        self.modelo = modelo
        self.camara = camara

    def llamar(self):
        print(f'Estas llamando desde un: {self.modelo}')

    def cortar(self):
        print(f'Cortaste la llamada desde tu: {self.modelo}')

celular1 = Celular("Samsung", "S23", "48MP")
celular2 = Celular("Apple", "Iphone 15 pro", "96MP")

celular1.cortar()
```
