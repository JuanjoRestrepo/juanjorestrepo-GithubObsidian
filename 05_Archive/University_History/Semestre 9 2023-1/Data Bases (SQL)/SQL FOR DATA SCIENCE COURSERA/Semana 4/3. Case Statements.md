Case statements are really easy to start to clean up our data. 

- We use them a lot when we're doing things like when we're **hiding, coding, or taking an individual categorical variable** and creating **its own column** out of a binary variable.
- We also do it when we want to create different groupings

# What is a Case Statement
---
Mimics if-then-else statement found in most programming languages.

Can be used in *SELECT*, *INSERT*, *UPDATE* and *DELETE* statements

```SQLite
CASE
WHEN C1 THEN E1
WHEN C2 THEN E2
...
ELSE [result else]
END
```

```SQLite
CASE input_expression
	WHEN when_expression THEN result_expression [...n]
	[ ELSE else_result_expression]
END
```

## Simple Case Statement
---
```SQLite
CASE input_expression
	WHEN when_expression THEN result_expression [...n]
	[ ELSE else_result_expression]
END
```

![[Pasted image 20230929135957.png|600]]

```SQLite
SELECT
employeedud
,firstname
,lastname
,city
,CASE City
	WHEN 'Calgary' THEN 'Calgary'
ELSE 'Other'
	END calgary
FROM Employees
ORDER BY LastName, FirstName;
```

## Search Case Statement
---
```SQLite
CASE WHEN Boolean_expression THEN result_expression [...n]
[ELSE else_result_expression]
END
```
![[Pasted image 20230929140128.png]]

```SQLite
SELECT
trackid
,name
,bytes
,CASE
	WHEN bytes < 300000 THEN 'small'
	WHEN bytes >= 300001 AND bytes <=500000 THEN 'medium'
	WHEN bytes >= 500001 THEN 'large'
	ELSE 'Other'
END bytescategory
FROM tracks;
```
