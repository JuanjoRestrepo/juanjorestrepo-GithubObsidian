---
- Retrieve the data in the format you need *Client vs Server* formatting
- Support Joins
- String Functions:
	- Concatenate
	- Substring
	- Trim
	- Upper
	- Lower

Strings pop up everywhere and are pieces of data we frequently work with.

It can use substrings or SQL can trim the beginning and end of the string.

## Concatenations
---
SQL server supports *'+'* instead of *'||'*

Let's go over concatenating something first. This function is really helpful when you're coming up with a unique ID for something.

![[Pasted image 20230928195139.png]]

```SQL
SELECT
Companyname
,ContactName
,CompanyName || ' (' || ContactName || ')'
FROM customers
```

## Trimming Strings
---
Trims the leading or trailing space from a string
- TRIM
- RTRIM
- LTRIM
```SQLite
SELECT TRIM(" You the
			best       ") AS TrimmedString;
```

## Substring
---
Returns the specified number of characters from a particular position of a given string

```SQL
SUBSTR(string name, string
	  position, number of
	  characters to be returned);
```

```SQL
SELECT first_name, SUBSTR (first_name, 2,3)
FROM employees
WHERE department_id = 60;
```

### Substring Example
---
```SQL
SELECT first_name,
SUBSTR(first_name, 3, 4)
FROM employees
WHERE department_id = 100;
```

![[Pasted image 20230928201156.png|450]]

```SQL
SELECT first_name,
SUBSTR(first_name, 1, 3)
FROM employees
WHERE department_id = 100;
```

## Upper and Lower
---
```SQL
SELECT UPPER (column_name) FROM table_name;

SELECT LOWER (column_name) FROM table_name;

SELECT UCASE (column_name) FROM table_name; --SAME THING AS UPPER
```
