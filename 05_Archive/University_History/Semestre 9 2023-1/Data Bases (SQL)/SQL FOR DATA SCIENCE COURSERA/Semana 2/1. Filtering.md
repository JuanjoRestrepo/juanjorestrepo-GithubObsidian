# Basics of Filtering with SQL
_________________________________________________________
## Why Filtering?
- Be specific about the data you want to retrieve
- Reduce the number of records you retrieve
- Increase query performance
- Reduce the strain on the client application
- Governance limitations

## 1. WHERE Clause Operators

```SQLite
SELECT column_name, column_name
FROM table_name
WHERE column_name operator value;
```

## 2. Filtering on a Single Condition

![[Pasted image 20230814161006.png]]

```SQLite
SELECT ProductName
, UnitPrice
, SupplierID
FROM Products
WHERE ProductName ='Tofu';
```

## 3. Filtering on a Single Value

![[Pasted image 20230814161157.png]]

```SQLite
SELECT ProductName
, UnitPrice
, SupplierID
FROM Products
WHERE ProductName >= 75;
```

## 4. Checking for Non-Matches

![[Pasted image 20230814161415.png]]

```SQLite
SELECT ProductName
, UnitPrice
, SupplierID
FROM Products
WHERE ProductName <> 'Alice Mutton';
```

## 5. Filtering with a Range of Value

![[Pasted image 20230814161515.png]]

```SQLite
SELECT ProductName
, UnitPrice
, SupplierID
, UnitsInStock
FROM Products
WHERE UnitsInStock BETWEEN 15 AND 80;
```

## 6. Filtering No Value
No value returned because there are no NULL values in the product name

```SQLite
SELECT ProductName
, UnitPrice
, SupplierID
, UnitsInStock
FROM Products
WHERE ProductName IS NULL;
```

# Advanced Filtering with SQL
_________________________________________________________
## 1. IN, OR and NOT

### IN Operator:
- Specifies a range of conditions
- Comma delimited list of values
- Enclosed in ()

![[Pasted image 20230814162256.png]]

```SQLite
SELECT ProductID
, UnitPrice
, SupplierID
FROM Products
WHERE SupplierID IN (9, 10, 11);
```

### IN Operator:
- DBMS will not evaluate the second conditions in a WHERE clause if the first condition is met
- Use for any rows matching the specific conditions

![[Pasted image 20230814162501.png]]

```SQLite
SELECT ProductName
, ProductID
, UnitPrice
, SupplierID
, ProductName
FROM Products
WHERE ProductName = 'Tofu' OR 'Konbu';
```

## IN vs OR
- IN works the same as OR
- **Benefits of IN**
	- Long list of options
	- IN executes faster than OR
	- Don't have to think about the order with IN
	- Can contain another SELECT

- Can contain AND and OR Operators
- SQL **processes AND before OR**
- Use ()
