## Retrieving Multiple Columns Using a **Wildcard**
Request all columns by using the asterisk `(*)`  wildcard character instead of a column names

```SQLite
SELECT *
FROM Products;
```

## Why Limit Results?

- If your database is large
- You might only want to see a sample of the data

```SQLite
SELECT columns you wishe to see
FROM specific table
LIMIT number of records
```

### Comparison of Limit Results Using Different Syntaxes

## SQLite
```SQLite
SELECT prod_name
FROM Products;
LIMIT 5;
```
## Oracle
```SQL Oracle
SELECT prod_name
FROM Products;
WHERE ROWNUM <= 5;
```
## DB2
```SQL DB2
SELECT prod_name
FROM Products;
FETCH FIRST 5 ROWS ONLY;
```
