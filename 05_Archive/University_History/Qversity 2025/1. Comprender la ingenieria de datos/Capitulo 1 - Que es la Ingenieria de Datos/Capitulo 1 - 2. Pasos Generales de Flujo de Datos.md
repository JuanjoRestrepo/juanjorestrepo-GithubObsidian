# Data Workflow

En principio, hay 4 pasos generales por los que fluyen los datos dentro de una organización:

1. ***Recopilamos e ingerimos datos procedentes***
	Por ejemplo, del *tráfico web, encuestas o consumo de medios de comunicación*

	Los datos se *almacenan en formato bruto*

2. ***Preparación de los datos***
	Esto incluye la limpieza de los datos, por ejemplo, encontrar valores *omitidos o duplicados* y convertir los datos en un *formato más organizado*

3. ***Exploración y Visualización***
	Los exploramos y visualizamos a través de *gráficas*, *construcción de cuadros de mando* para *seguir los cambios o comparar dos conjuntos de datos*

4. ***Experimentación y Predicción***
	Al tener buen dominio de los datos, podemos experimentar para evaluar, por ejemplo:
	1. *Descubrir qué título de artículo tiene más visitas*
	2. *Construir modelos predictivos para predecir los precios de las acciones*

## Ahora bien, ¿Quiénes se encargan de cada etapa?

### Data Collection y Storage

- Los **Ingenieros de Datos se encargan de este primer paso del proceso**
- Ingerir los datos recopilados y almacenarlos
- Ellos **sientan las bases para el trabajo** de los analistas, los científicos de datos e ingenieros de machine learning
- Si los datos están dispersos, corruptos y son de difícil acceso, no hay mucho material sobre el qué preparar, explorar o experimentar

### Un **Data Engineer**

Entrega:
1. Los datos correctos
2. En el forma correcta
3. A las personas adecuadas
4. Todo con la **Mayor Eficacia** posible

Sus responsabilidades son:
1. Ingerir **datos de distintas fuentes**
2. **Optimizar las bases de datos** para el análisis
3. Gestionar los datos corruptos
4. **Desarrollar, construir, probar y mantener las arquitecturas de datos**, como, *Bases de Datos y Sistemas de Procesamiento a Gran Escalada* (*Para procesar y manejar cantidades masivas de datos*)

## Data Engineers y Big Data

- Con la llegada del Big Data, aumentó la demanda de Data Engineers
- Big Data:
	- Se definen como **Datos Muy Grandes** debido a su tamaño
	- Pensar en **cómo gestionar**, porque son **difíciles de procesar con los métodos tradicionales** debido a su tamaño

## Los MacroDatos suelen caracterizarse por las Cinco **Vs**

- **Volumen** (La cantidad de puntos de datos - How much?)
- **Variedad** (El tipo y naturalidad de los datos. *texto, imagen, video, audio* - What kind?)
- **Velocidad** ( Rapidez con la que se generan y procesan los datos - How frequent?)
- **Veracidad** (Grado de fiabilidad de las fuentes - How accurate?)
- **Valor** ( Cómo de procesables son los datos, la utilidad de los datos, para generar _insights_ y beneficios para el negocio - How useful?)
