## Tipos de Datos No-Tabulares

- De acuerdo al MIT, **el 80% de los datos producidos y consumidos no están estructurados y no son tabulares**. Esto incluye datos como:
	- **Texto**
	- **Audio**
	- **Imágenes**
	- **Videos**
	- **Datos espaciales**
	- **IoT**
- Al no tener datos tabulares, se requiere **invertir mucho tiempo para transformar y extraer caracteristicas** de los datos brutos, no estructurados y **volverlos en un formato tabular**

## APIs y datos JSON

- Las API son herramientas mas utilizadas para recopilar datos de terceros
- La mayoria solo permiten leer datos y evitar eliminaciones o sobrescrituras
- Previene una interacción directa con la base de datos, es decir, en un solo viaje se pueden depositar o retirar datos, como un banco.

En el banco retiramos o depositamos dinero, pero no directamente con acceso a la bóveda, sino por medio de personas capacitadas que lo hacen


Esto hace la API, **nos evita interactuar directamente con una base de datos**

## Leer datos JSON con python
