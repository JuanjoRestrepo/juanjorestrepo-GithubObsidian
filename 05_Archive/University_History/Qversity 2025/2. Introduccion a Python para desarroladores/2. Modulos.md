# ¿Qué son los módulos?

- Los módulos son scripts de Python
    - Archivos que terminan con `.py`
    - Contienen funciones y atributos
    - Pueden contener otros módulos
- Python viene con varios módulos

# **Módulos de Python**

- Hay alrededor de 200 módulos integrados.
- Los módulos populares incluyen:
    - `os` - para interpretar e interactuar con tu sistema operativo
    - `collections` - tipos y funciones de estructuras de datos avanzadas
    - `string` - para realizar operaciones con cadenas
    - `logging` - para registrar información al probar o ejecutar software

Lista completa de módulos de Python: [https://docs.python.org/3/py-modindex.html](https://docs.python.org/3/py-modindex.html)
