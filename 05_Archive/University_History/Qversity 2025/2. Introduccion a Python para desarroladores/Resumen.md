

## Tus aprendizajes recientes

Cuando te fuiste hace 17 horas, trabajabas en The Python Ecosystem, capítulo 1 del curso Python intermedio para desarrolladores. Esto es lo que viste en tu clase más reciente:

Aprendiste sobre las funciones integradas de Python, que son funciones predefinidas en Python que puedes usar para realizar tareas comunes. Estas funciones ayudan a que tu código sea más eficiente y legible. Aquí hay algunos puntos clave:

- **`print()`** muestra salidas, lo que es esencial para depurar o mostrar resultados.
- **`type()`** te dice el tipo de una variable, valor o función, útil para entender estructuras de datos.
- **`range()`** genera una secuencia de números, a menudo utilizada en bucles.
- **`max()` y `min()`** encuentran los valores más grandes y más pequeños en una lista, respectivamente.
- **`sum()`** calcula el total de valores numéricos en una lista.
- **`round()`** redondea un número a un número especificado de decimales. Por ejemplo, redondeando las ventas totales:
    
    ```
    total_sales = round(sum(sales), 2)
    ```
    
- **`len()`** cuenta el número de elementos en una estructura de datos, como listas o cadenas.
- **`sorted()`** ordena los elementos de una lista o cadena en orden ascendente.
- **`help()`** proporciona información sobre cómo usar una función o qué es un tipo de dato.

También exploraste cómo estas funciones pueden simplificar tareas como calcular la suma de una lista de valores, lo que sin la función `sum` requeriría más código y sería propenso a errores. Las funciones integradas de Python son herramientas poderosas para realizar tareas complejas de manera eficiente.
