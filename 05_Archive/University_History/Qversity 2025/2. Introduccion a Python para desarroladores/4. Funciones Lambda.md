- `lambda` keyword
	- Representa una *función anónima*
	- **Puede** almacenar como una variable y llamarse

```python
# Funcion simple
def average(values): # definicion
	average = sum(values)/len(values) # cuerpo funcion / expression

	return average


# Funcion Lambda
lambda argument(s): expression

```

- La convención es usar  `x`  para **un solo argumento**
- La parte de `expression` es el equivalente al cuerpo de la función
- No se necesita el statement `return`

---
## Creating a Lambda function

```python
# Lambda average function
lambda x: sum(x) / len(x)

# Custom average function
def average(x):
	return sum(x) / len(x)

average(x)	
```

---
## Using Lambda functions

```python
# Get the average
( lambda x: sum(x) / len(x) ) ([3, 6, 9])
							# parametros de X

# En este caso, le pasamos una lista, la cual se le sacara el promedio (3+6+9)/3
```

---
## Storing and calling a Lambda function

```python
# Store lambda function as a variable
average = lambda x: sum(x) / len(x)

# Call the average function
average([3, 6, 9])
```
---
## Multiple parameters

```python
# Lambda function with two parameters
(lambda x, y: x**y)(2, 3)
```

## Lambda with iterables

- `map()`: aplica una función **para todos los elementos** en un iterable

```python
names = ["john", "sally", "leah"]

# Apply a lambda function inside map()
capitalize = map(lambda x: x.capitalize(), names )
print(capitalize)

# Si lo imprimimos, nos muestra la direccion de memoria donde se almacena la funcion
```

```bash
<map object at 0x7fb200529c10>
```

Para corregir esto y ver los valores reales de nuestra función `capitalize` hacemos la conversión a string

```python
# Convert to a list
list(capitalize)
```

```bash
['John', 'Sally', 'Leah']
```

## Custom vs. Lambda functions

| Scenario                 | Function Type |
|--------------------------|---------------|
| Complex task             | Custom        |
| Same task several times  | Custom        |
| Simple task              | Lambda        |
| Performed once           | Lambda        |



```python
sales_prices = [29.99, 9.95, 14.50, 39.75, 60.00]

# Create add_taxes to add 20% to each item in sales_prices
add_taxes = map(lambda x: x * 1.2, sales_prices)

# Use add_taxes to return a new list with updated values
print(list(add_taxes))
```
