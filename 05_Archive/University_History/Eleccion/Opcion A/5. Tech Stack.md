# 🛠️ Tech Stack Seleccionado — Opción A

La selección tecnológica prioriza la reproducibilidad, el tipado estático estricto, la baja latencia de inferencia y la facilidad de despliegue local.

---

## 💻 Tabla de Componentes y Justificación

| Capa / Componente | Tecnología | Propósito | Justificación Técnica |
| :--- | :--- | :--- | :--- |
| **Entorno & Lenguaje** | Python 3.12 (`uv`) | Núcleo de desarrollo | Rendimiento, tipado estático riguroso y gestión determinista de dependencias con `pyproject.toml`. |
| **ETL & Procesamiento** | Pandas, NumPy | Limpieza y agregaciones | Manejo eficiente de datos estructurados tabulares y series de tiempo multi-zona. |
| **Análisis Estadístico** | SciPy, Statsmodels | Detección de anomalías | Modelado estadístico riguroso (Z-score, IQR, tests de hipótesis y descomposición de tendencias). |
| **Visualización** | Plotly / Seaborn | Gráficos ejecutivos | Calidad de publicación e interactividad para tableros de control y diapositivas. |
| **Generación & LLM** | OpenAI API / Llama 3 local | Razonamiento de negocio | Extracción de diagnósticos estructurados en formato JSON a partir de resúmenes numéricos. |
| **Vector Storage (Opcional)** | FAISS (local) | Indexación semántica | Almacenamiento y recuperación rápida de contexto sin dependencias de infraestructura en la nube. |
| **Aplicación & Demo** | Streamlit + FastAPI | Interfaz de usuario | Creación rápida de tableros interactivos para demostración en vivo. |
| **Contenerización** | Docker | Reproducibilidad | Asegura ejecución idéntica independiente del sistema operativo host. |
