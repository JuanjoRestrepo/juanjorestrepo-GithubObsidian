# 🛡️ Estrategia de Sustentación Técnica — Opción A

Para garantizar que la propuesta de LLMs e Insights sea **altamente defendible y rigurosa** ante un panel técnico, se implementa una arquitectura híbrida que separa el cálculo determinista de la generación de lenguaje natural.

---

## 🏗️ Pilares de la Estrategia

### 1. Desacoplamiento: Cálculo Numérico vs. Generación Lingüística
- **Capa Numérica (Determinista):** Todo cálculo de estadísticas, tests de hipótesis, detección de anomalías, deltas y segmentaciones se ejecuta en código Python reproducible (Pandas/NumPy/SciPy).
- **Capa Generativa (Interpretabilidad):** El LLM consume exclusivamente resúmenes estructurados y matrices de anomalías procesadas.
- **Resultado:** Cada afirmación cualitativa emitida por el modelo está directamente anclada a una evidencia numérica auditable.

---

### 2. Salida Estructurada (JSON Schema Contract)
El modelo no devuelve texto libre; opera bajo un contrato de esquema JSON estricto:

```json
{
  "summary": "Diagnóstico conciso del comportamiento de la zona.",
  "top_drivers": [
    {
      "metric": "Orders",
      "delta_pct": -18.4,
      "severity": "high"
    }
  ],
  "confidence_score": 0.92,
  "supporting_evidence_ids": ["ZONE_MX_042_L0W_ANOMALY"]
}
```

---

### 3. Mecanismo de Grounding y Prevención de Alucinaciones
- **Context Ingestion:** Inyección de pasajes sintetizados desde la base vectorial (FAISS) o contexto tabular directo.
- **Strict Evidence Policy:** Si el contexto no contiene información suficiente para justificar un factor causal, el prompt instruye devolver explícitamente: `"sin evidencia suficiente"`.

---

## 📈 Métricas de Evaluación para la Defensa

| Métrica | Definición Operativa | Meta / Benchmark |
| :--- | :--- | :--- |
| **Coverage** | Porcentaje de afirmaciones del LLM respaldadas por datos del contexto. | $\ge 95\%$ |
| **Precision (Facts)** | Ratio de hechos correctos verificados en muestra de control ($N=30$). | $\ge 90\%$ |
| **Latency & Cost** | Conteo promedio de tokens de entrada/salida y costo estimado por consulta. | $< 1.5\text{s} \text{ / } < \$0.005 \text{ por query}$ |
| **Quality Score** | Calificación humana de utilidad y claridad de negocio (escala 1 a 5). | $\ge 4.2 / 5.0$ |

## ⏱️ Estructura del Demo en Vivo (3 Minutos)

1. **Minuto 1 — Arquitectura y Propósito:** Explicación del flujo de datos desacoplado y contrato JSON.
2. **Minuto 2 — Consultas de Negocio en Streamlit:**
   - *Query 1:* *"¿Por qué bajaron las órdenes en la Zona X durante la semana L0W?"* $\rightarrow$ Mostrar métricas crudas, respuesta en JSON y evidencias vinculadas.
   - *Query 2:* *"Top 3 zonas con riesgo de contracción en las próximas 2 semanas."* $\rightarrow$ Mostrar ranking heurístico y plan de acción.
3. **Minuto 3 — Verificación y Auditoría:** Demostración de cómo la herramienta bloquea afirmaciones cuando falta evidencia empírica.
