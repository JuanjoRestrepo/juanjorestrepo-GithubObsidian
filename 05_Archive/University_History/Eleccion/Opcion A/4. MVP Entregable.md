# 📋 Checklist de Aceptación del MVP — Opción A

A continuación se detallan los entregables mínimos requeridos y sus criterios de aceptación técnica para la sustentación:

---

## 🎯 Lista de Entregables y Criterios

- [ ] **Repositorio GitHub Reproducible:**
  - Código fuente versionado con historial de commits convencional.
  - `README.md` con instrucciones precisas de despliegue local y variables de entorno.
  - `Dockerfile` funcional y script de ejecución `run_local.sh`.

- [ ] **Pipeline ETL y Feature Engineering:**
  - Ingesta automatizada de hojas `RAW_INPUT_METRICS` y `RAW_ORDERS`.
  - Transformación y cálculo de indicadores derivados ($\Delta$ semanal, $\%$ cambio, z-score).

- [ ] **Notebooks Analíticos:**
  - Análisis exploratorio de datos (EDA) documentado.
  - Detección estadística de anomalías y generación de 2 a 4 visualizaciones clave.

- [ ] **Módulo RAG & LLM:**
  - Indexación de resúmenes tabulares en FAISS / inyección directa de contexto.
  - Generación de respuestas estructuradas en formato JSON bajo esquema validado.

- [ ] **Marco de Evaluación Factual:**
  - Archivo `human_eval.csv` con $N=30$ casos de prueba ejecutados.
  - Reporte de métricas de precisión, cobertura y latencia.

- [ ] **Material de Sustentación:**
  - Presentación ejecutiva en PDF.
  - Guion de demostración técnica `demo_script.md`.
