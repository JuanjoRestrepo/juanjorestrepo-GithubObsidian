# 🛠️ Tech Stack Seleccionado — Opción B

Herramientas seleccionadas para garantizar máxima resiliencia en navegación web moderna, procesamiento determinista de datos y total reproducibilidad.

---

## 💻 Tabla de Componentes Tecnológicos

| Capa del Sistema | Tecnología | Propósito Específico | Justificación Técnica |
| :--- | :--- | :--- | :--- |
| **Lenguaje de Programación** | Python 3.12 (`uv`) | Núcleo del sistema | Ecosistema robusto de automatización, tipado estático estricto (`mypy`) y alta velocidad de desarrollo. |
| **Motor de Automatización / RPA** | Playwright (Sync API) | Renderizado dinámico e interceptación | Control avanzado de contextos de navegador Chromium, intercepción nativa de tráfico XHR/Fetch y soporte de ejecución *headless*. |
| **Normalización & Análisis** | Pandas / RapidFuzz | Limpieza y entity matching | Procesamiento estructurado de JSONs anidados y emparejamiento difuso de nombres de productos heterogéneos. |
| **Persistencia de Datos** | JSON / CSV / SQLite | Almacenamiento local de resultados | Formatos estándar y ligeros que permiten auditoría directa sin sobrecarga de infraestructura. |
| **Visualización & Demo** | Matplotlib / Seaborn / Plotly | Gráficos exploratorios y ejecutivos | Generación de visualizaciones estadísticas (histogramas bimodales, boxplots comparativos y heatmaps). |
| **Contenerización** | Docker | Despliegue reproducible | Aislamiento completo de dependencias de sistema (incluyendo binarios de Chromium y drivers). |
| **Aseguramiento de Calidad** | Pytest + Logging | Validación de parsers | Pruebas unitarias sobre funciones de sanitización y logging estructurado por evento. |
