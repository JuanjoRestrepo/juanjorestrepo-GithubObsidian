
# Alcance mínimo viable (MVP)

**Objetivo MVP:** 
- Construir un pipeline reproducible que scrapee 3 competidores (webs o APIs) en 3 dimensiones (precio, tiempo estimado de entrega, y características del producto/servicio), entregue dataset normalizado y un dashboard + notebook con benchmarks y conclusiones accionables.


**Entregables mínimos:**
1. Repo en GitHub con:
    - `README.md` con instrucciones de ejecución (Docker/venv).
    - Código de scraping (scripts o Scrapy/Playwright).
    - Pipeline de ETL básico (`etl.py` o DAG simple).
    - `notebook.ipynb` con análisis reproducible y pasos.
    - Carpeta `slides/` con presentación (PDF/PowerPoint).

2. Dataset limpio (CSV con versionado).
3. Dashboard simple (Streamlit / Plotly Dash) o notebook con gráficos estáticos.
4. Documento de **Limitaciones, Consideraciones Legales y Éticas**.
5. `demo_script.md` con guion corto para la sustentación (qué mostrar y por qué).
