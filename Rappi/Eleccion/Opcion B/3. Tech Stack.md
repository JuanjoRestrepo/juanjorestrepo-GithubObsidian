

# Tech stack sugerido (rápido y defendible)

- Lenguaje: **Python 3.10+**
- Scraping: **Requests + BeautifulSoup** (si estático) o **Playwright** (si JS), o **Scrapy** (si escala).
- Normalización & análisis: **Pandas**, **fuzzywuzzy / RapidFuzz** para matching.
- Orquestación simple: **cron / GitHub Actions** para reproducibilidad (no necesitas Airflow si es PoC).
- Persistencia: CSV / SQLite (para demo local) o PostgreSQL / BigQuery si quieres escalabilidad.
- Dashboard/demo: **Streamlit** o Jupyter Notebook exportado.
- Contenerización: **Docker** (imagen simple para correr demo).
- Tests básicos: scripts unitarios para parsers (pytest).
