
# Análisis comparativo

**Opción A — LLMs / Insights**
- Ventajas: alto impacto percibido; permite prototipos rápidos con APIs (OpenAI, etc.).
- Dificultades para la defensa:
    - Métricas menos objetivas (calidad de insight difícil de cuantificar).
    - Riesgo de hallucinations / sesgo → debes presentar mitigaciones técnicas (RAG, verificación, fact-checking).
    - Requiere explicar diseño de prompts, embeddings, vector DB, y trade-offs de costo/latencia.

- Implementación: rápida para prototipo pero compleja para evaluación rigurosa.

**Opción B — Competitive Intelligence (recomendada)**
- Ventajas para defensa:
    - Resultados cuantificables y reproducibles (número de items scrappeados, precisión del parser, cobertura temporal).
    - Visualizaciones y comparativas claras que el jurado entiende inmediatamente.
    - Menos dependencia de modelos ML complejos; el foco está en data engineering y análisis.

- Riesgos/consideraciones: scraping puede requerir manejo de JS (Playwright), límites/robots.txt, y normalización de entidades (fuzzy matching).
- Implementación: clara progresión técnica y entregables fácilmente demostrables en una demo.
