
# Métricas y criterios para defender resultados

- **Cobertura:** % de páginas/productos extraídos respecto a un objetivo.
- **Parsing accuracy:** ratio campo_correcto / total_campos (verificado manualmente en sample).
- **Freshness:** latencia entre actualización y captura.
- **Comparative KPIs:** precios promedio, distribución de tiempos de entrega, puntaje de features (binario o score).
- **Robustez:** logs de errores, retries, manejo de CAPTCHAs (si aplica).
- **Reproducibilidad:** tiempo y pasos para reproducir (documentar con `Docker`).
