
## Tech stack y opciones (rápidas)

- **Lenguaje:** Python 3.10+
- **ETL / análisis:** pandas, numpy, matplotlib/plotly
- **Anomalías / estadísticas:** scipy, statsmodels (o simple Z-score / IQR)
- **LLM / embeddings:** OpenAI (si tienes API) — o Llama2 / local si no puedes usar APIs externas.
- **Vector DB (opcional):** FAISS (local) / Milvus / Pinecone (si cloud). Para este caso podríamos simplificar y pasar contexto tabular directamente al prompt (más reproducible y rápido).
- **API / demo:** FastAPI + Streamlit (o solo notebook para la demo).
- **Contenerización:** Docker (imprescindible para reproducibilidad).
