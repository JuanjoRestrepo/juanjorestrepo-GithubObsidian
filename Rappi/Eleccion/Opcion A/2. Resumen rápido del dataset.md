

- Hojas:
    - **RAW_INPUT_METRICS** — 12.573 filas × 15 columnas (métricas por country/city/zone; columnas `L8W_ROLL` … `L0W_ROLL`, y meta info `ZONE_TYPE`, `ZONE_PRIORITIZATION`).
        
    - **RAW_ORDERS** — 1.242 filas × 13 columnas (series `L8W` … `L0W`, métrica `Orders`, por zona).
        
    - **RAW_SUMMARY** — documentación de columnas (15 filas) — muy útil para el readme y para explicar variables en la defensa.
        
- Conclusión: **datos tabulares y temporales** (series y métricas rolladas) — ideales para análisis estadístico, detección de anomalías, tendencias y para que un LLM explique/justifique hallazgos.
