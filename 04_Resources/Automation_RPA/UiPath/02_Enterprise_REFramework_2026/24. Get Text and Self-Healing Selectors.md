# Topic: Get Text and Self-Healing Selectors

In this section, you'll learn about using the **Get Text** activity and how to implement self-healing selectors effectively. Here's a breakdown of the key points:

1. **Get Text Activity**:
    - The **Get Text** activity is used to extract or scrape text data from UI elements. This is essential for validating outputs or gathering information dynamically during the automation process.
    - To configure the **Get Text** activity correctly, ensure you select the right UI element from which you want to extract text.

2. **Making Selectors Dynamic**:
    - Just as with previous activities, it’s crucial to make your selectors dynamic to ensure reliability. Dynamic selectors can adapt if the UI structure changes.
    - For this specific activity, focus on making the anchor of the **Get Text** dynamic, just like you did for other elements, such as the invoice number.

3. **Editing Selectors**:
    - Access the selector editor to modify the components of your selector. You should check each element in the breadcrumb trail to ensure that attributes specific to an instance (like automation ID or invoice numbers) are not hardcoded unless necessary.
    - Use **fuzzy logic** (set to a value other than zero) for text elements that may slightly change, which enhances the selector’s flexibility.

4. **Creating Self-Healing Selectors**:
    - Utilize self-healing features in UiPath where possible. This involves defining selectors that can adjust themselves based on surrounding context or relationship to other stable UI elements.
    - Use anchors effectively, ensuring that your target selection is less vulnerable to UI changes.

5. **Testing and Validation**:
    - After setting up your **Get Text** activity with dynamic selectors, run a test to validate that you are capturing the correct outputs.
    - Review the outputs and make adjustments to your selectors as needed to improve reliability.

By following these steps, you’ll effectively implement the **Get Text** functionality while ensuring that your automation workflows remain robust against interface alterations.
