# Practice Activity: For Each File in Input Folder

## Activity Objective
* Construct a workflow that iterates through every file within a targeted input directory and outputs the absolute file path of each item to the **Output Panel**.

---

## Technical Prerequisites & Setup
* Ensure the target input folder exists on your local machine containing the files to process (e.g., `C:\Robot Six\scanned receipts`).

---

## Step-by-Step Implementation Guide

### 1. Initialize the Container
* Open your project in **UiPath Studio**.
* Drag a **Sequence** container into the **Main.xaml** canvas.

### 2. Add the Folder Iteration Activity
* Drag the **For Each File in Folder** activity into the main sequence.
* Set the target folder path in the activity configuration:
  * Input the target path in the **In Folder** property field (e.g., `"C:\Robot Six\scanned receipts"`).
  * Take note of the iteration reference variable automatically generated in the **For Each** loop (default: `currentFile`, of type `System.IO.FileInfo`).

### 3. Configure Output Logging
* Drag a **Write Line** activity inside the **Body** of the **For Each File in Folder** loop.
* Set the **Text** property expression to:
  ```vb
  currentFile.FullName
