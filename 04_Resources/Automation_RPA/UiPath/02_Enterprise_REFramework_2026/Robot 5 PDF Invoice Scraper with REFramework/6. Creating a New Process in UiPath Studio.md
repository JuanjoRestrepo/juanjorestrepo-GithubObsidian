## Lesson Objectives
* Outline the step-by-step procedure for creating a new process in UiPath Studio.
* Understand the core structural elements and components of a UiPath automation process.

## Step-by-Step Guide to Process Creation

### 1. Launch UiPath Studio
* Open **UiPath Studio** on your local machine.

### 2. Initialize a New Project
* Select **New Project** on the home screen.
* Choose **Process** as the template type.
* Define a clear project name (e.g., `MyNewProcess`) and specify the target save directory.

### 3. Structure the Workflow
* Open the newly initialized, blank workflow canvas.
* Design the process architecture using core container elements such as **Sequences**, **Flowcharts**, or modular sub-workflows.

### 4. Implement Activities & Logic
* Drag and drop components from the **Activities Panel** onto the canvas.
* Configure activity properties, declare variables, and map input/output arguments across your sequences.

### 5. Save & Publish
* Save progress regularly using `Ctrl + S`.
* Click **Publish** on the top ribbon to package and deploy the project to **UiPath Orchestrator** for testing or deployment.

### 6. Debug & Validate
* Run unit tests and execution traces directly within **UiPath Studio**.
* Use the native **Debugging Panel** (Breakpoints, Step Into, Watch Window) to resolve runtime errors and optimize workflow performance.

## Conclusion
Building a process requires initializing the project, designing structured workflow logic, configuring individual activities, and validating output quality before publishing to Orchestrator.
