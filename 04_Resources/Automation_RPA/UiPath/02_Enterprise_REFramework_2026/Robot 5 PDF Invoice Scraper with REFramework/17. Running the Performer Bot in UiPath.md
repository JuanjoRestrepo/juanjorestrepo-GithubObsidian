# Running the Performer Bot in UiPath

## Lesson Objectives
* Master the execution workflow for the **Performer** bot to consume and process transaction items from UiPath Orchestrator Queues.
* Understand deployment, runtime initiation via UiPath Assistant, and execution monitoring in Orchestrator.

---

## Architectural Role of the Performer
The **Performer** process (typically built on top of **REFramework**) acts as the queue consumer. It connects to Orchestrator, fetches pending transaction items sequentially, executes target business logic, and updates each item's processing status (*Successful*, *Business Exception*, or *System Exception*).

---

## Step-by-Step Execution Guide

### 1. Prepare the Performer Workflow
* Open your **Performer** project in **UiPath Studio**.
* Verify that queue consumption logic is configured to fetch items from the designated Orchestrator Queue (e.g., matching the `OrchestratorQueueName` parameter).

### 2. Verify Agent Connection
* Launch **UiPath Assistant** on the target execution environment.
* Ensure the agent status displays **Connected** and **Licensed** to your target Orchestrator tenant.

### 3. Verify Queue Item Availability
* Access **UiPath Orchestrator** via browser.
* Navigate to **Queues > View Transactions** for your target queue and verify that transaction items exist in the **New** status state (populated by the Dispatcher).

### 4. Publish & Deploy Process
* Click **Publish** in **UiPath Studio** to package and upload the Performer project to Orchestrator.
* In Orchestrator, navigate to **Processes** and deploy or update the process package inside the target workspace/folder.

### 5. Initiate Bot Execution
* **Manual Execution (UiPath Assistant)**: Locate the deployed Performer process in **UiPath Assistant** and click **Play**.
* **Automated Execution (Orchestrator)**:
  * **Queue Trigger**: Configure an Orchestrator Queue Trigger to launch the Performer automatically whenever new items are added.
  * **Time Schedule**: Configure a Time Trigger to execute the Performer at specified intervals.

### 6. Monitor Execution & Logs
* Track real-time execution states under **Orchestrator > Jobs**.
* Inspect item status transitions (*In Progress* $\rightarrow$ *Successful* / *Faulted*) under **Orchestrator > Queues**.
* Review detailed diagnostic execution traces in the **Logs** tab or **UiPath Assistant** to troubleshoot any runtime errors.

---

## Conclusion
Executing the Performer bot completes the transactional processing lifecycle. By leveraging Orchestrator Queues alongside automated triggers, Performer bots deliver scalable, fault-tolerant, and asynchronous workload processing.
