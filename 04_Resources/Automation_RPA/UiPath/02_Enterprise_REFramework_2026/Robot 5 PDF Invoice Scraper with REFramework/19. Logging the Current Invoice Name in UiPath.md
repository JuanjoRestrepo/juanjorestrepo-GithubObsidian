# Practice Activity: Logging the Current Invoice Name in UiPath

## Lesson Objectives
* Transition from local output debugging (`Write Line`) to enterprise logging using the **Log Message** activity.
* Learn how to capture and stream file execution metadata to **UiPath Orchestrator** using `FileInfo` properties and string concatenation.

---

## Technical Overview: `Log Message` vs. `Write Line`

* **Write Line**: Displays plain text output strictly within the local **Output Panel** in UiPath Studio. Useful for rapid local prototyping, but output is lost when running in production.
* **Log Message**: Transmits structured log events directly to local log files and **UiPath Orchestrator**. Essential for audit trails, real-time monitoring, and centralized operational dashboards.

---

## Step-by-Step Implementation Guide

### 1. Insert the `Log Message` Activity
* Open your workflow sequence in **UiPath Studio**.
* Replace or append after the existing `Write Line` activity by dragging a **Log Message** (`UiPath.Core.Activities.LogMessage`) activity inside your file processing loop.

### 2. Configure the Log Level
* Access the **Properties Panel** for the **Log Message** activity.
* Set the **Level** dropdown property to **Info** (appropriate for routine operational progress events).

### 3. Build the Log Expression
* In the **Message** property field, bind the file iteration variable (`CurrentFile` of type `System.IO.FileInfo`) using string concatenation.
* Use `CurrentFile.Name` to log only the file name with extension, or `CurrentFile.FullName` if the absolute path is required:
  ```vb
  "Processing: " + CurrentFile.Name
```
