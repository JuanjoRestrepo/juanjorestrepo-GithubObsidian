This lesson focuses on setting up and configuring unattended robots using UiPath, covering several important concepts that RPA (Robotic Process Automation) developers and users should consider when deploying and managing these robots. Below is a detailed summary of the concepts covered in the lesson:

## REFramework
It is excellent at ***handling Transactional Business Processes***
- Each individual PDF that needs to be scraped and captured as an example would count as single transaction
- ***Those transactions (each of them) are handled*** withing ***Orchestrator Queues***


### 1. Operations Folder Creation

- **Importance**: Creating an operations folder is essential for deploying automated processes.
- **Function**: This folder helps organize and manage the files and documents that robots will need during their operation.

### 2. Types of Robots

- **Attended Robots**:
    - **Operation**: They run locally on the user's machine.
    - **Interaction**: They require user interaction to perform tasks.
- **Unattended Robots**:
    - **Operation**: They can run in cloud environments, on servers, or remotely.
    - **Interaction**: They do not require direct user intervention, allowing for higher efficiency in automation.

### 3. Unattended Robot Configuration

- **Access**: The tenant section in UiPath is accessed to launch the unattended setup wizard.
- **Hosting Options**:
    - **UiPath-Hosted**: The robot operates in a serverless environment provided by UiPath.
    - **Self-Hosted**: The robot operates on the user's machine, granting greater control.

### 4. Hosting Options Considerations

- **Serverless Environment**: Suitable for cross-platform automation, but cannot handle local desktop applications.
- **Virtual Environment Configurations**:
    - Option to rent virtual machines from UiPath or third-party providers (e.g., Amazon EC2, Google Cloud, Microsoft Azure).
    - **Importance of Understanding Pricing Structures**: Crucial to understand the fees associated with these services to avoid unplanned costs.

### 5. Chosen Setup Option

- **Self-Hosted Setup**: The speaker opts for a self-hosted configuration.
- **Template Selection**:
    - A **static machine template** is selected for a single unattended robot.
    - It is explained that this option differs from an **elastic robot pool**, which utilizes multiple machines for load balancing.

### 6. Next Steps

- The speaker mentions that the upcoming steps in setting up the unattended robot will be covered in the next lesson.

This summary provides a clear overview of the key concepts and considerations to keep in mind when working with unattended robots in UiPath.
