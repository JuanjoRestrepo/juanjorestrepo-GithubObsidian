# Open Each PDF in Microsoft Edge

## Lesson Objectives

- Build a workflow to batch-open target PDF files in **Microsoft Edge** using Modern UI Automation activities.
- Learn how to pass file path arguments dynamically into browser and application execution containers in UiPath Studio.

---

## Technical Prerequisites & Setup

- **Target Directory**: Ensure a valid directory containing target `.pdf` files is accessible (e.g., `"C:\Path\To\Folder"`).
- **UiPath Extension for Edge**: Verify that the UiPath Web Automation extension for Microsoft Edge is installed and enabled.

---

## Step-by-Step Implementation Guide

### **Initialize Variables**

- Create a variable named `pdfFilePaths` of type `Array of String` or `List<String>`.
- Populate this variable with all the PDF paths, for example, using `Directory.GetFiles`.

```vb
pdfFilePaths = Directory.GetFiles("C:\Path\To\Folder", "*.pdf")
```

### 2. Configure Directory Iteration / For Each Loop

- Drag a **For Each** loop (`UiPath.Core.Activities.ForEach`) into your sequence.
- Set the **Type Argument** property to `System.String`.
- Set the iteration item reference variable to `pdfPath` and pass `pdfFilePaths` into the **Values** property.

```vb
For Each pdfPath in pdfFilePaths
```
### 3. Configure Application & Browser Container

- Drag a **Use Application/Browser** activity (`UiPath.UIAutomationNext.Activities.NApplicationCard`) inside the Body of the loop.
- Set the properties in the Properties Panel:
    - **BrowserType**: `Edge` or `Chrome`
    - **Application Arguments**: `pdfPath`
    - **OpenMode**: `Always` (or `IfNotOpen`)

```text
Application Arguments: pdfPath
```
### 4. Insert Render Delay

- Insert a **Delay** activity (`UiPath.Core.Activities.Delay`) immediately after the Use Application/Browser card.
- Set the **Duration** property field to `00:00:03` (3 seconds) to ensure PDF rendering finishes before the loop proceeds.

---

## Workflow Execution & Architectural Structure

```text
Variables:
  pdfFilePaths = Directory.GetFiles("C:\Path\To\Folder", "*.pdf")

For Each pdfPath In pdfFilePaths
    Use Application/Browser:
        BrowserType: Microsoft Edge
        Application Arguments: pdfPath
        Indicate Edge window (optional)
        End Indicate
    Delay: 00:00:03
End For
```

### Flow Diagram Summary:

```text
Start
  |
  v
Fetch all PDF paths -> Store in pdfFilePaths
  |
  v
For each pdfPath in pdfFilePaths
  |
  v
  Open pdfPath in Edge using Use Application/Browser
  |
  v
  Wait for 3 seconds (Delay)
  |
  v
Repeat for next pdfPath
  |
  v
End
```

---

## Key Best Practices

- **Argument Enclosure**: If file paths contain spaces, wrap the argument string in double quotes: `"""" + pdfPath + """"` to ensure Microsoft Edge receives a valid command-line argument.
- **Process Cleanup**: For large directories, append a **Close Application** or **Kill Process** activity (`ProcessName: "msedge"`) at the end of each iteration to prevent high memory usage from multiple open tabs.

---

## Conclusion

Passing array paths into the **Application Arguments** property of the Modern **Use Application/Browser** card enables fast, batch-driven PDF rendering and UI automation across Microsoft Edge instances.
