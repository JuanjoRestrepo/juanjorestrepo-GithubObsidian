## ¿Qué es Data Manipulation?
La manipulación de datos es el proceso de modificar, estructurar, formatear o clasificar datos para facilitar su uso y aumentar sus capacidades de gestión.

## ¿Cuáles son algunos escenarios comerciales en los que utilizaré la manipulación de datos?
Los propietarios de sitios web emplean con frecuencia métodos de manipulación de datos para extraer y ver información específica de los registros de su servidor web. Eso permite ver sus páginas más populares, así como sus fuentes de tráfico.
Considere el proceso de interrogación de bases de datos legales o financieras públicas. La manipulación de datos proporciona los medios para que los analistas de crédito extraigan solo los datos relevantes y los utilicen en otros documentos o los correlacionen con información de otras fuentes.

# 1. ¿Qué son las Listas?

Las listas (o `List<T>`, como las encontrará) son estructuras de datos que consisten en objetos del mismo tipo de datos (por ejemplo, cadena o entero). Cada objeto tiene una posición fija en la lista; por lo tanto, se puede acceder a él por índice. Mientras que las matrices son estructuras de tamaño fijo para almacenar múltiples objetos, las listas nos permiten agregar, insertar y eliminar elementos.

Las listas pueden almacenar una gran cantidad de elementos: nombres, números, coordenadas de tiempo y muchos otros. Las listas proporcionan métodos específicos de manipulación, como:

- Adición y eliminación de elementos (Adding and removing items).
- Buscando un elemento (Searching for an element).
- Recorriendo los elementos (y realizando ciertas acciones en cada uno). (Looping through the items (and performing certain actions on each).)
- Ordenando los objetos (Sorting the objects.)
- Extraer elementos y convertirlos a otros tipos de datos (Extracting items and converting them to other data types.)

## ¿Cuáles son algunos escenarios comerciales en los que probablemente encontrará listas?

- Almacenar los nombres de las computadoras de los miembros de un equipo de proyecto para una determinada configuración que se debe realizar.
- Recopilación y almacenamiento de los números de facturas que cumplen determinados criterios.
- Hacer un seguimiento de los números de boletos creados en un período determinado sobre un tema determinado.


# **The Invoke and String Conversion Method**

### Método Invoke
La actividad Método de `Invoke` es otra forma de implementar un código que está fuera de las actividades integradas estándar. Puede usar esta actividad para invocar un método de una clase.

No es necesario que la clase forme parte del flujo de trabajo ni utilice ninguna de las clases base del flujo de trabajo. El método de invocación llama a un método público de un objeto o tipo especificado.

Este método en realidad convierte la primera letra de cada palabra en una cadena a mayúsculas y las siguientes letras a minúsculas.

Los argumentos son los siguientes: la cadena que se va a convertir, seguida de la configuración de conversión, Visual Basic String Convert dot ProperCase.
- **StrConv(Ciudad,VbStrConv.ProperCase)**

**Lo que funciona en proyectos de Windows-Legacy:**
- StrConv(Ciudad, VbStrConv.ProperCase)

## Listas y Arrays
La variable de **Array** es un tipo de variable que le permite almacenar múltiples valores del mismo tipo. UiPath Studio admite tantos tipos de matrices como tipos de variables. Esto significa que puede crear una matriz de números, una de cadenas, una de valores booleanos, etc.

Si desea trabajar con una colección que no tiene un número fijo de elementos, puede usar una **lista** en lugar de cualquier matriz.

La diferencia entre matrices y listas es que la matriz tiene un tamaño fijo, pero el tamaño de la lista puede variar.

## Inicialización del tipo de referencia

Inicializar una variable es especificar un valor inicial para asignarle. Todas las variables reciben un valor inicial cuando se declaran. Sin embargo, este proceso es un poco diferente dependiendo de si las nuevas variables son del tipo valor o referencia.

- **Tipo de valor:** para valores numéricos, booleanos, de fecha y hora y otros tipos de valores, el compilador les dará un valor válido si no lo hacemos explícitamente. Por ejemplo, *Ints* se inicializa en cero de forma predeterminada, *DateTimes* se inicializa en *DateTime.MinValue* de forma predeterminada. En Studio, a las cadenas también se les asigna un valor predeterminado en blanco, aunque sean del tipo de referencia.

- **Tipo de referencia:** las variables de tipo de referencia, como listas y diccionarios, se inicializan en el objeto que proporcionamos. El compilador no asignará un valor si no lo hacemos. Esto significa que necesitamos instanciar un objeto y asignarlo a la variable que acabamos de declarar.

Para comenzar a usar tipos de referencia como Listas y Diccionarios, debemos seguir tres pasos: *declarar, instanciar y asignar el objeto.*

1. Declaramos una variable de referencia, digamos una Lista de tipo String. Proporcionamos el nombre, seleccionamos el tipo `System.Collections.Generic.List<T>` e indicamos String.
2. Instanciamos un objeto a asignar como valor inicial de la variable. En nuestro caso, queremos comenzar con un objeto List of String que no contiene valores, por lo que usamos la expresión new List (of String).
3. Asignamos el objeto a la nueva variable (o inicializamos la variable) usando el valor Predeterminado en el panel Variables o usando una actividad Asignar.


# 2. Diccionarios y Enteros (Integers)

Los diccionarios (o `Dictionary<TKey, TValue>`, como los encontrará) son colecciones de pares (clave, valor), en las que las claves son únicas. Piense en la libreta de direcciones de su teléfono móvil, donde cada nombre tiene sus datos correspondientes (número(s) de teléfono, correo electrónico).

Los tipos de datos para claves y valores deben elegirse cuando se declara la variable. Los tipos de datos en los diccionarios pueden será cualquiera de las variables admitidas (incluidos los diccionarios, por ejemplo).

Las operaciones que se asocian con más frecuencia a los Diccionarios son:
- Agregar y eliminar pares (clave, valor).
- Recuperar el valor asociado a una clave.
- Reasignación de nuevos valores a claves existentes.

### ¿Cuáles son algunos escenarios comerciales en los que probablemente encontrará diccionarios?
- Almacenar detalles de configuración u otra información a la que se debe acceder durante un proceso.
- Almacenar los títulos de trabajo u otra información relevante de los empleados.
- Almacenamiento de las cuentas bancarias de los proveedores.


### Métodos para trabajar con Diccionarios

1. **Initialization** 
Al igual que en el ejemplo de Listas, las variables de diccionario deben inicializarse con objetos instanciados. En el ejemplo anterior, la creación de instancias y la inicialización se realizaron dentro de una actividad 'Asignar'. Sin embargo, como recordará del capítulo Listas, también se pueden hacer desde el panel de Variables.

2. **Adding Key-Value Pairs**
`VarName.Add(Key, Value)` – agrega un elemento a un Diccionario existente. Debido a que Add no devuelve un valor, usamos la actividad Invoke Method.

3. **Removing Keys**
 `VarName.Remove(Key)` – elimina un elemento del Diccionario. Se puede utilizar en una actividad de 'Asignar'.

4. **Retrieving**
	- **VarName.Item(Key):** devuelve el elemento del diccionario por su clave.
	- **VarName.Count:** devuelve un valor Int32 del número de elementos del diccionario.
	- **VarName.ContainsKey(Key):** comprueba si el elemento con la clave dada existe en el Diccionario y devuelve un resultado booleano.
	- **VarName.TryGetValue(Key, Value)** – comprueba si existe un elemento con una clave determinada en el Diccionario y devuelve un resultado booleano y el valor si lo encuentra.

## Métodos en UiPath que usan el constructor RegEx

### Matches
- Busca una cadena de entrada para todas las ocurrencias y devuelve todas las coincidencias exitosas.
- Output datatype: 
```
System.Collections.Generic.IEnumerable<System.Text.RegularExpressions.Match>
```
### IsMatch
- Indica si la expresión regular especificada encuentra una coincidencia en la cadena de entrada especificada.
- Tipo de datos de salida: booleano

### Replace:
- Reemplaza las cadenas que coinciden con un patrón de expresión regular con una cadena de reemplazo especificada.
- Tipo de datos de salida: Cadena
