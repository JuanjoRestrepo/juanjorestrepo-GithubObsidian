# ¿Qué son los selectores?
Un selector en UiPath Studio es una característica que permite la identificación de un elemento específico de la interfaz de usuario a través de su dirección y atributos. Estos se almacenan como fragmentos ==XML.==

La identificación de elementos se hace para realizar actividades específicas en un proyecto de automatización. Los selectores se generan automáticamente cada vez que usamos una actividad que interactúa con elementos de la interfaz gráfica de usuario.

Podemos pensar en el proceso de identificación de elementos logrado a través de selectores como un cartero que ====entrega cartas a una determinada dirección.== Para que el cartero entregue las cartas, ====se requiere una ruta específica y debe contener detalles estructurados y jerarquizados== como: 
- País > Ciudad > Código postal > Nombre de calle > Número de calle > Número de apartamento. 

De manera similar, UiPath Studio requiere la ruta detallada a un elemento específico dentro de la interfaz de usuario.

# ¿Cuáles son algunos escenarios comerciales en los que los selectores son útiles?
La mayoría de las veces, cuando un proceso automatizado implica trabajar con elementos de la interfaz de usuario, se utilizan selectores. Las actividades típicas incluyen:

- Hacer clic en los botones.
- Ingresar o Scrapping de texto en/desde un campo en un sitio web.
- Elegir una opción de una lista desplegable (drop-down list).

# **Tags & Attributes of Selectors**

As you saw, selectors are made of nodes. And each node is made of tags and attributes. Let's take an example to explain the two. Below is a selector node.

```html
<webctrl parentid=‘slide-list-container’ tag=‘A’ aaname=‘Details’ class=‘btn-dwnl’ />
```

### Tags
- Nodes in the selector XML fragment.
- Correspond to a visual element on the screen.
- First node is the app window.
- Last node is the element itself.

For example:
1. wnd (window)
2. html (web page)
3. ctrl (control)
4. webctrl (web page control)
5. java (Java application control)

### Atributes
Cada atributo tiene un nombre y un valor. Debe usar solo atributos con valores constantes o conocidos.

Por ejemplo:
- `parentid=‘slide-list-container’`
- `tag=‘A’`
- `aaname=‘Details’`
- `class=‘btn-dwnl’`
