# ¿Qué es?
El UI Explorer es la funcionalidad en UiPath Studio que le permite analizar y editar selectores. Contiene un botón de estado que muestra a los usuarios el estado del selector, un panel de árbol visual que muestra una interfaz de usuario navegable de cada aplicación que se ejecuta en ese momento, así como el elemento de interfaz de usuario seleccionado. 
El Explorador de la interfaz de usuario muestra todas las etiquetas y atributos disponibles y le da la opción de registrarlos o retirarlos.

# ¿Cuáles son algunos escenarios comerciales en los que usaré UI Explorer?
El UI Explorer se puede usar siempre que los selectores que se generaron automáticamente no sean lo suficientemente estables o confiables. Por ejemplo, cuando:

- Los selectores cambian de una ejecución a otra.
- Los selectores pueden cambiar después de las actualizaciones del producto.
- Los selectores usan información poco confiable, como index.

# UI Frameworks
Para devolver el mejor selector para el elemento de interés, podemos cambiar entre los diferentes marcos de interfaz de usuario disponibles en UiExplorer. Puede encontrar la opción de marcos de interfaz de usuario en la pestaña Opciones de UiExplorer.

#### Default
Este es el método propietario que normalmente funciona correctamente con todo tipo de interfaces de usuario.

#### Active Accessibility
Esto representa una solución anterior de Microsoft que hace que las aplicaciones sean accesibles. Se recomienda cuando se utiliza software heredado, si el marco predeterminado no funciona como se esperaba.

#### UI Automation
Este es el modelo de accesibilidad mejorado de Microsoft, que se recomienda al usar aplicaciones más nuevas en caso de que el marco predeterminado no funcione como se esperaba.
