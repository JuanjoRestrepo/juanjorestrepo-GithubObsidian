# **At the end of this lesson you should be able to:**

- Create a UiPath Automation Cloud account, invite a new user to the organization and allocate a license.
- Use Orchestrator to assign a role to the newly added user.
- Download and install Studio.
- Use Studio to create a new project, add an activity to the workflow, and publish to Orchestrator.
- Use UiPath Assistant to run the newly published process.


Para configurar tu entorno de desarrollo de automatización para incluir un robot atendido conectado a Orchestrator es realmente fácil con la integración entre los componentes principales, los grupos predeterminados configurados en Automation Cloud y la función de inicio de sesión.

Para tener una buena comprensión de cómo funcionan los componentes, veremos un escenario en el que una empresa con un plan comunitario tiene Orchestrator como un servicio de nube de automatización.

## **Scenario:**  
Un nuevo desarrollador acaba de unirse a la empresa. Ahora, el administrador de la organización debe proporcionar al nuevo usuario la licencia y el rol necesarios para crear proyectos de automatización.

## **Here's a quick recap of the steps:**

Steps to set up your attended user and run your first job


### **As the Automation Cloud account admin:**

1. Invite the new user to Automation Cloud and include them in the Automation Developers group.
2. Allocate the **Automation Developer - Named User license type.**
3. Go to **Orchestrator**, search for the newly added user, and assign the **Robot** role.

**As the attended user:**

1. Check your mailbox and accept the invitation from the administrator.
2. Login to Automation Cloud.
3. On the Home tab, click Download UiPath Studio.
4. Run the Studio installer.
5. Sign in to Automation Cloud from Studio.
6. Choose the Studio profile.
7. Create a new automation process in Studio.
8. Add a Message Box activity and input the desired message.
9. Publish the project to Orchestrator.
10. Open UiPath Assistant, install, and run a job for the newly added process.


### **Note:**
*When you publish an automation process to the **Orchestrator Personal Workspace**  a process is created automatically if one doesn't already exist, and existing processes are automatically updated to the latest published version*

## Preguntas

1. **How does the scenario vary based on the license?**
Larger enterprise customers may choose an on-premises deployment and the integration with Active Directory. In this case, the user groups would be imported in the host tenant, where licenses would also be allocated. From that point onwards, the steps in the video would apply.
For Community accounts, the first user would also be the admin on the Automation Cloud and the Orchestrator service.

2. **What's the relation between Automation Cloud and Orchestrator?**

UiPath Automation Cloud is our cloud platform, hosting our cloud products and services.
Cloud Orchestrator is a service hosted in Automation Cloud. Users and groups need to be created first in Automation Cloud. Then you'll be able to add them and configure their permissions and licenses in Orchestrator. The Automation Users and Automation Developers groups are by default added in Orchestrator.

3. **What's the relation between Attended Robot and Assistant?**
Right now, UiPath Assistant is an interface between the human user and the attended robot. It's the default way used to run and customize jobs in attended mode.

4. **Do users need to first be added to Automation Cloud to receive any type of license?** R// Yes
5.  **To which of the following products and profiles will a user with an Automation Developer - Named User license assigned from Automation Cloud have access to?** An **Automation Developer - Named User** license provides a unique user with the right to use **Studio**, **StudioX**, **attended robot**, **Data Service**, **Action Center**, and **Task** **Capture**.
	What the user can and cannot do within each product is further controlled using roles and permissions.
