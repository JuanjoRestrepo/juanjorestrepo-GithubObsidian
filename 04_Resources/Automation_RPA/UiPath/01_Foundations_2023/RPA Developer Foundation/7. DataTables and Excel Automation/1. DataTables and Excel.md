## Qué son las DataTables?

## Review:

![[Pasted image 20230718102941.png | center | 500]]


- DataTable is the type of variable that can store data as a simple spreadsheet with rows and columns. 
- You can identify each piece of data based on its unique column and row coordinates. Think of it as the memory representation of an Excel worksheet. 

In DataTables, individual cells can be identified by using the Column name or zero-based index and the row index.

## **What is the difference between a worksheet and a DataTable?**

![[Pasted image 20230718103157.png|500]]
- **Worksheet** es una representación visual de datos con diferentes opciones de visualización y un uso extensivo de la GUI
- **DataTable** es una representación en memoria de una sola Base De Datos que tiene una colección de filas y columnas

## Cómo se crean las DataTables

#### La actividad Construir tabla de datos

- Al usar esta actividad, eliges el número de columnas y el tipo de datos de cada una de ellas.
- Además, puede configurar cada columna con opciones específicas como permitir valores nulos, valores únicos, incremento automático (para números), valor predeterminado y longitud (para cadenas).
### Las actividades de la gama de lectura
- Esta actividad obtiene el contenido de una hoja de trabajo (o una selección de esa hoja de trabajo) y lo almacena en una variable de DataTable, que se puede crear desde el panel Propiedades usando Ctrl + K.

### La actividad Leer CSV
- Esta actividad captura el contenido de un archivo CSV y lo almacena en una variable DataTable. Aunque ya no se usa comúnmente, todavía hay aplicaciones heredadas o internas que funcionan con este tipo de documentos.

### La acción de extracción de datos
- Esta funcionalidad de UiPath Studio le permite extraer datos estructurados de su navegador, aplicación o documento a un DataTable.

### La actividad Generar tabla de datos a partir de texto
- Se puede utilizar para crear un DataTable a partir de texto estructurado, permitiendo al usuario indicar los separadores de filas y columnas.

# DataTable Activities

1. **Build Data Table:** Se usa para crear un DataTable usando una ventana dedicada. Esta actividad permite la personalización de número de columnas y tipo de datos para cada columna.
2. **For Each Row in Data Table:** Se utiliza para realizar una determinada actividad para cada fila de un DataTable (similar a un bucle For Each).
3. **Filter Data Table:** Permite filtrar un DataTable a través de un Filter Wizard, usando varias condiciones. Esta actividad se puede configurar para crear una nueva DataTable para la salida de la actividad o para mantener la existente y filtrar (eliminar) las entradas que no cumplen las condiciones de filtrado.
4. **Add Data Column:** Agrega una columna a una variable DataTable existente. Los datos de entrada pueden ser de tipo DataColumn o se puede agregar la columna vacía, especificando el tipo de datos y configurando las opciones (permitiendo valores nulos, solicitando valores únicos, autoincrementable, valor por defecto y longitud máxima).
5. **Add Data Row:** Agrega una nueva fila a una variable DataTable existente. Los datos de entrada pueden ser del tipo DataRow o pueden ingresarse como Array Row, haciendo coincidir cada objeto con el tipo de datos de cada columna.
6. **Clear Data Table:** Borra todos los datos en una variable DataTable existente.
7. **Generate Data Table From Text:** Se puede usar para crear una tabla de datos a partir de texto estructurado, al permitir que el usuario indique los separadores de fila y columna.
8. **Join Data Tables:** Combina filas de dos tablas usando valores comunes entre sí mediante el Asistente para unir, de acuerdo con una regla de unión que responde a la pregunta "¿Qué hacer con los datos que no coinciden?". Es una de las actividades más útiles en escenarios de negocios, donde es muy común trabajar con más de una Tabla de Datos. Es por eso que cubriremos el tema con más profundidad en las próximas lecciones.
9. **Lookup Data Table:** Es similar a vLookup en Excel. Puede buscar un valor proporcionado en un DataTable específico y RowIndex devuelve su valor. O puede configurarse para devolver el valor de una celda con las coordenadas dadas (RowIndex y Target Column).
10. **Merge Data Table:** Se utiliza para agregar un DataTable específico al DataTable actual. La operación es más simple que la actividad Unir tipo de datos, ya que tiene 4 acciones predefinidas para realizar sobre el esquema faltante.
11. **Output Data Table:** Escribe un DataTable en una cadena usando el formato CSV.
12. **Remove Data Column:** Elimina una determinada columna de un DataTable especificado. La entrada puede consistir en el índice de la columna, el nombre de la columna o una variable de columna de datos.
13. **Remove Data Row:** Elimina una fila de un DataTable especificado. La entrada puede consistir en el índice de fila o una variable de fila de datos.
14. **Remove Duplicate Rows:** Elimina las filas duplicadas de una variable DataTable especificada, conservando solo la primera aparición.
15. **Sort Data Table:** Puede ordenar una tabla de datos de forma ascendente o descendente en función de los valores de una columna específica.
16. **Get Row Item:** Recupera un valor de una fila en un DataTable según una columna especificada.
17. **Update Row Item:** Asigna un valor especificado a la columna indicada de una fila de DataTable.


## Joining DataTables

#### Cómo funciona?
![[Pasted image 20230718114042.png|500]]
1. Se deben especificar tres variables de tabla de datos: dos tablas de datos de entrada y una tabla de datos de salida. Tenga en cuenta que el orden de los dos primeros es muy importante, ya que hay una opción que mantiene los valores de la Tabla de datos 1 y no se puede cambiar.

2. Se debe elegir el Tipo de unión; hay tres opciones:
	- Interno: mantenga todas las filas de ambas tablas que cumplan con la regla Unir. Las filas que no cumplan la regla se eliminan de la tabla resultante.
	- Izquierda: mantenga todas las filas de DataTable1 y solo los valores de DataTable2 que cumplan con la regla Unir. Los valores nulos se insertan en la columna de las filas de DataTable1 que no tienen una coincidencia en las filas de DataTable2.
	- Completo: conserva todas las filas de DataTable1 y DataTable2, independientemente de si se cumple la condición de combinación. Los valores nulos se agregan a las filas de ambas tablas que no tienen una coincidencia.

3. Las reglas de Unión tienen que ser configuradas (puede haber una o más reglas):
	- Una columna de cada DataTable tiene que ser especificada por sus nombres (String), por su índice (Int32) o por variables ExcelColumn.
	- Se tiene que elegir el operador: = (Igual a), != (Diferente a), > (Mayor que), < (Menor que), >= (Mayor o igual que), <= (Menor que o igual a).


## ¿Cuáles son algunos escenarios comerciales en los que usaré Join Data Tables?

Unir tabla de datos proporciona una de las formas más fáciles de traer datos de dos fuentes en un solo lugar:

- Reunir dos bases de datos de empleados extraídas de dos aplicaciones.
- Comprobar cuáles de los clientes (base de datos 1) han sido contactados en una campaña de marketing (base de datos 2).
- Consultar cuáles de los proveedores de una empresa (base de datos interna) han solicitado ayudas públicas (base de datos pública).
