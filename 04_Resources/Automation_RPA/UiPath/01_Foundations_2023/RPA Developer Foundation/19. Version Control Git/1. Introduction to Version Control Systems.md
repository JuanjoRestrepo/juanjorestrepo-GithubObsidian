## **¿Qué son los sistemas de control de versiones?**

Los sistemas de control de versiones son herramientas utilizadas por los equipos de desarrollo de software para gestionar la colaboración en grandes proyectos.

Un sistema de control de versiones permite a los desarrolladores realizar un seguimiento de un cambio de código, revisar el historial del código y volver a una versión anterior del proyecto, si es necesario.

Estos son algunos de los beneficios de usar sistemas de control de versiones:

#### Enhanced collaboration
_________________________________________________________
Team members can work freely on any file at any time and merge the 
changes into a common version at the right time.

#### Storing versions
_________________________________________________________
Only the current version is stored on the disk, all the others are in the system.

#### Restoring previous versions
_________________________________________________________
Restore older versions of the file at any time.

#### Tracking different project versions
_________________________________________________________
New versions are usually saved with change descriptions. Versions of the same file can also be compared.


Los sistemas de control de versiones con los que está integrado UiPath Studio son **Git, TFS y SVN.** La conexión a un sistema de control de versiones se realiza a nivel de proyecto. Para administrar sus conexiones, acceda a Studio, vaya a la **vista Backstage** y haga clic en la **pestaña Equipo.**

Alternativamente, el botón Agregar al control de código fuente en la barra de estado ofrece accesos directos a **Git Init, Copiar a Git, Agregar a TFS y Agregar a SVN**

## ¿Qué sistema de control de versiones debería elegir?

Independientemente del tipo de sistema de control de versiones que se utilice, los archivos de proyecto se almacenan en un servidor donde envía sus archivos después de haber completado su trabajo en su máquina local.

Sin embargo, decidir si usar un sistema de control de versiones centralizado como SVN o un sistema de control de versiones distribuido como Git afecta la forma en que realiza los cambios. Esto se cubrirá más adelante en este curso.
