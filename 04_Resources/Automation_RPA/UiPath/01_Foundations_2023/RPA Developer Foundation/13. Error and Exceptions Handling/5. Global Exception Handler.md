El **controlador de excepciones globa**l es un tipo de flujo de trabajo diseñado para determinar el comportamiento del proceso cuando se encuentra con una excepción inesperada. Esta es la razón por la que solo se puede configurar **un controlador** de excepción global por proyecto de automatización.

En su configuración predeterminada, Global Handler detecta las excepciones generadas por cualquier actividad en el proceso en tiempo de ejecución y ejecuta una respuesta estándar: ignorar, reintentar, cancelar o continuar, según lo predefinido en el momento del diseño. Para escenarios atendidos, se puede configurar para que el usuario seleccione la acción.

![[Pasted image 20230723143650.png]]

A Global Exception Handler can be created by adding a new workflow file with this type. It can also be created by setting an existing workflow as Global Exception Handler from the Project panel.

¿Como funciona?

El controlador de excepciones global tiene 2 argumentos predefinidos, que no deben eliminarse:

- **errorInfo** con la dirección de entrada: contiene la información sobre el error que se produjo y el flujo de trabajo que falló.

- **result** con la dirección de Salida - utilizado para determinar el siguiente comportamiento del proceso cuando encuentra el error.

El controlador de excepciones global contiene las actividades predefinidas a continuación. Si es necesario, también podemos agregar otras actividades en nuestro controlador.

## Error de registro
Esta parte simplemente registra el error. El desarrollador puede elegir el nivel de registro: fatal, error, advertencia, información, seguimiento, etc.

![[Pasted image 20230723143748.png]]

## Elija el siguiente comportamiento
Aquí el desarrollador puede elegir la acción a tomar cuando se encuentra un error durante la ejecución:

- **Continue**: se vuelve a lanzar la excepción.
- **Ignore**: la excepción se ignora y la ejecución continúa desde la siguiente actividad.
- **Retry**: se vuelve a intentar la actividad que generó la excepción.
- **Abort**: la ejecución se detiene después de ejecutar el controlador actual.

![[Pasted image 20230723143837.png]]

## NOTA: **El controlador de excepciones global no está disponible para proyectos de biblioteca, solo para procesos.**

Solo las excepciones no detectadas llegarán al controlador de excepciones. Si se produce una excepción dentro de una actividad **TryCatch** y se captura y maneja con éxito dentro del bloque Catches (y no se vuelve a generar), no llegará al controlador global de excepciones.
