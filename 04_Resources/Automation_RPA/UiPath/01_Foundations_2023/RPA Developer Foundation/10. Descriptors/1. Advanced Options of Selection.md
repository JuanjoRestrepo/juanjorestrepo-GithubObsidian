# Opciones avanzadas
_______________________________________________________________
El objetivo de Modern Design es crear una automatización de interfaz de usuario más confiable que deba ajustarse y corregirse con menos frecuencia en producción.

La ventana de opciones de selección proporciona opciones avanzadas, como Forzar visibilidad, Destino de texto dinámico, Destino de texto nativo y modo de selección de imagen.

Puede usar estas funcionalidades y configurarlas según la aplicación que esté automatizando o el tipo de elemento de la interfaz de usuario que esté seleccionando.

Estas opciones ayudan a configurar el descriptor muy confiable mientras indican el objetivo en sí.

Aprendamos en detalle sobre estas siguientes opciones avanzadas:

1. **Hacer cumplir la visibilidad/Enforce Visibility:** is a property that lets you work with UI elements which are visible when it is enabled. During Run-time, also considers only the visible elements.
2. **Objetivo de texto dinámico/Dynamic Text Target:** addresses the need of targeting regardless of their specific content, such  as trying to click on the first element in a search list or just trying to click on a dynamic element (e.g. a link that can have different texts)
3. **Objetivo de texto nativo/Native text:** enables Native Text targeting methods. It is useful mostly for legacy applications where not all elements are selectable 
4. **Modo de selección de imagen/Image selection mode:** This feature helps you identify a UI Element in situations where selectors and fuzzy selectors are not available, by using only image recognition.

# Modo de selección de imagen
_______________________________________________________________
Esta función lo ayuda a identificar un elemento de la interfaz de usuario en situaciones en las que los selectores y los selectores difusos no están disponibles, utilizando solo el reconocimiento de imágenes.

Presionar la tecla F3 puede habilitar la selección de imágenes. Mire la demostración a continuación para aprender a usarla.
