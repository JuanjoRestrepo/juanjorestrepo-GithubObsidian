No se recomienda la edición manual del Descriptor. El método de segmentación unificada funciona mejor, proporcionando buenos resultados sin necesidad de una configuración avanzada de Unified Target. Aún así, en casos excepcionales, es posible que necesitemos ajustar el método de orientación unificado donde los descriptores no son lo suficientemente confiables.

Considere el ejemplo, un elemento de interfaz de usuario requerido, que no tiene un nombre único. Y tampoco tiene otro elemento de interfaz de usuario confiable en la aplicación para establecer como ancla. O el elemento de la interfaz de usuario cambia su estado, posición o ID cada vez que se actualiza una página web.

# Key Actions to Fine-tune the Unified Target for Descriptor

El método de orientación unificada utiliza una pila de tres métodos de orientación Selector, Fuzzy selector e Image para encontrar el elemento de la interfaz de usuario necesario. Estos tres métodos de orientación son redundantes entre sí, lo que significa que todos intentan identificar el elemento objetivo simultáneamente y se utiliza el que encuentre el objetivo primero.

Puede ajustar el método de segmentación unificado ajustando los **Target** y **A****anchor** **selectores**, **selectores difusos** e **imágenes**, según la interfaz de usuario de la aplicación o los criterios para identificar el elemento de la interfaz de usuario.

En el curso **Selector in Studio** aprendió las formas de ajustar los selectores. Además, ha aprendido a ajustar los selectores de diferentes formas.

En esta lección, aprendamos cómo ajustar los **Selectores difusos** y **Imagen** métodos de segmentación.


# **Fine-tuning of the Fuzzy Selector Targeting method.**

El Fuzzy Selector es muy similar a un Selector. Pero, Fuzzy Selector identifica el elemento de la interfaz de usuario incluso con una coincidencia aproximada en lugar de una coincidencia perfecta como en Selector. Como resultado, el **Fuzzy Selector** puede generar múltiples elementos. Donde Selector identifica el único elemento de la interfaz de usuario.

---------------------------------------------------------------
![[Pasted image 20230721164301.png]]

El Selector difuso se puede editar desde su sección dedicada en la ventana Opciones de selección.

Puede ajustar el selector Fuzzy de las siguientes maneras:

- Ajustando la precisión de coincidencia del Selector difuso desde el control deslizante Precisión.
- Mediante el uso de comodines (?,*) en el selector difuso generado para el objetivo requerido. ***'?'**** reemplaza un carácter y  ```'*'```  reemplaza cero o más caracteres.
- Mediante el uso de Variable y Argumento en el Selector difuso para el objetivo requerido. Puede crear una nueva variable/argumento o usar la variable existente desde el menú contextual del selector Fuzzy.

---------------------------------------------------------------

Si el elemento indicado contiene texto, el texto se muestra en el cuadro de entrada debajo de la ventana de edición del Selector difuso.

El menú desplegable junto al cuadro de entrada le permite seleccionar entre las dos opciones **Text is** e **Ignore text.**

Para que el elemento de la interfaz de usuario se considere una coincidencia cuando se selecciona Texto en el cuadro de entrada, el texto mencionado debe estar presente en el elemento de la interfaz de usuario en tiempo de ejecución.

Puede utilizar comodines ```(?,*)```   al editarlo.
Al seleccionar **Ignore text**, se ignora el texto especificado en el cuadro de entrada.
