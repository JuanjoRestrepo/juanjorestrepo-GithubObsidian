Los sistemas de control de fuente son particularmente útiles en proyectos más grandes, donde varios equipos e individuos contribuyen en cada etapa. Los sistemas de control de código fuente permiten a los usuarios de diferentes equipos y ubicaciones acceder a los mismos recursos y trabajar en el mismo proyecto. También se utilizan para versionar el código y mantener el historial de todos los cambios realizados durante el desarrollo.

A través de la página Teams en la vista backstage, Studio admite los siguientes sistemas de control de código fuente:


## GIT

Con la integración de Git puedes:

- Clonar un repositorio remoto.
- Agregar un proyecto.
- Comprometerse y empujar.
- Copie un proyecto a Git.
- Crear y administrar sucursales.
- Resuelve conflictos con la opción File Diff.

## TFS

Se admiten las siguientes versiones:
- 2012
- 2013
- 2015
- expreso 2012
- expreso 2013
- expreso 2015

Primero, debe configurar TFS en Studio.
Luego puede abrir un proyecto o agregar un nuevo proyecto al TFS.


## SVN

Con la integración de SVN puedes:
    
- Abra un proyecto desde SVN.
- Agregar un proyecto a SVN.
