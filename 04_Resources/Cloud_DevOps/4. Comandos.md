# Comandos

## Inicializar directorio de trabajo
```terraform
terraform init
```

## Generar un plan de ejecución
```terraform
terraform plan
```

## Aplicar los cambios definidos
```terraform
terraform apply
```

## Eliminar los recurso
```terraform
terraform destroy
```
