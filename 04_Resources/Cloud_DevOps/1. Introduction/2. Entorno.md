# Explorar una aplicación de función
![[Pasted image 20260529144656.png]]

Formas parte del equipo de desarrollo de Cipher Coffee, una cafetería especializada que combina innovación con excelentes cafés. A medida que la tienda amplía su presencia digital con un sistema de pedidos online y una aplicación de recompensas para clientes, el equipo está explorando los servicios de computación en la nube para respaldar estas iniciativas.

En Azure, «sin servidor» significa ejecutar código o servicios sin gestionar los servidores subyacentes, ya que Azure se encarga automáticamente del escalado, la disponibilidad y la infraestructura.

Para probar la computación sin servidor, ya se ha configurado una aplicación de funciones. ¡Vamos a sumergirnos y acceder a la aplicación de funciones preconfigurada para ver cómo funciona!



![[Pasted image 20260529145535.png]]

#### ¿Cuál de las siguientes opciones describe mejor una aplicación de Azure Function?

- Experiencia informatica sin servidor basada en eventos para acelerar tu desarrollo.

> **Azure Function App** te permite ejecutar código en respuesta a desencadenadores como solicitudes HTTP, temporizadores o mensajes, sin necesidad de administrar servidores.
