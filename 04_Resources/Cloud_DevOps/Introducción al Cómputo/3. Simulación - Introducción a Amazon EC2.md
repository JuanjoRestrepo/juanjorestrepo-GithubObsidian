# Información general y objetivos de la simulación

En esta simulación, se proporciona información general básica sobre el inicio, la modificación de la capacidad, la administración y la supervisión de una instancia de Amazon Elastic Compute Cloud (Amazon EC2). 

Amazon EC2 es un **servicio web** que proporciona **capacidad de cómputo de tamaño modificable** en la nube. 

Está diseñado para hacer que la computación en la nube a escala web sea intuitiva y simple de utilizar. 

Amazon EC2 le proporciona acceso rápido a las instancias de servidores nuevas y puede realizar un aumento o una reducción vertical de la capacidad rápidamente a medida que cambian los requisitos informáticos. 

Esta simulación está limitada en su capacidad para que se pueda acceder con un lector de pantalla. Si utiliza un lector de pantalla, utilice las Instrucciones de la simulación ubicadas en la ventana del reproductor para comprender cómo llevar a cabo las acciones.
