Cipher Coffee’s online ordering system has suddenly gone down. A misconfigured firewall is blocking all incoming traffic, including the connection needed to access the Virtual Machine. Customers can’t place their coffee orders, and time is of the essence!

Use the Azure Serial Console to check whether the VM is still operational to get the system brewing again as quickly as possible.

Now that the VM is created, lets start it up and connect to it!

- Access your newly created VM.
- In the left-hand menu, navigate to the _Connect_ section.
