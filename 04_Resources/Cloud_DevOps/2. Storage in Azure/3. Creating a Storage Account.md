Now that you have explored Storage accounts, lets create one!

Note: This is a 3 part exercise, we recommend completing it in the same session 1/3.

- In the Azure Portal, navigate to _Storage Accounts_ and _create_ a new account.

![[Pasted image 20260602202136.png]]

![[Pasted image 20260602202149.png]]

Lets configure the Storage account:

- Select the _Resource group_ `student-`
- Choose a unique _name_ such as `ciphercoffeestorage`followed by random characters
- Set the _region_ to `(US) East US`

![[Pasted image 20260602202205.png]]

Cipher Coffee needs to store unstructured data like images, receipts, and training materials while staying cost-effective and have backups in case of any hardware failure. Lets ensure the Storage account will do just that!

Select the following options:

- Primary service :
    - `Azure Blob Storage or Azure Data Lake Storage Gen 2`
- Performance:
    - `Standard`
- Redundancy:
    - `Locally-redundant storage (LRS)`

![[Pasted image 20260602202434.png]]

Next, lets finalize the Storage account:
- Now select `Review + create`
- Then `Create` to provision your storage account.

Congrats! You’ve successfully created your first Storage Account!🎉
