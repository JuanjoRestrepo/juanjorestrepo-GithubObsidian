### Windows
```bash
winget install Hashicorp.Terraform
terraform --version
```

### Mac
```bash
brew tap hashicorp/tap
brew install hashicorp/tap/terraform
terraform --version
```

## Herramientas
### aws cli
```bash
brew install awscli
aws configure
```

### Repositorio
```bash
git remote add origin https://github.com/JuanjoRestrepo/terraform.git
```
