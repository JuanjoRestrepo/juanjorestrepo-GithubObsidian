# 3. Port Mapping

![[Port Mapping 1.png]]

> **Nota**: a partir de una Docker Image, *puedo crear* `n` *cantidad de contenedores*

- Tenemos 3 contenedores aislados con sus propios *archivos, redes y procesos* para evitar conflictos
- ¿Que pasaría si alguien externo intenta acceder a las Bases de Datos Postgres?
	- **NO PODRIA HACERLO** 
	![[Port Mapping 2.png]]

	- Esto es gracias al **Port Mapping**, *porque esa maquina externa no sabría como redirigir el trafico de las imagenes*

## ¿Qué es el Port Mapping?

Es la capacidad de **mapear los puestos externos de mi computadora física, con los puertos internos de mis containers** 

![[Port Mapping Correcto.png]]

- Lo que llega al Port `5432` se redirige al primer container `5432`
- Lo que llega al Port `5433` se redirige al segundo container
- Lo que llega al Port `8080` se redirige al tercer container

**Lo que llega al** `Port X` **se manda un Port del Container**
