# 2. What is Azure App Service?

![[Pasted image 20260622174143.png]]

It is a cloud-based platform designed to simplify application hosting

- It provides a reliable and scalable environment
- It supports multiple programming languages and Framework
- Flexible for Development Needs
- Built-in Security and Features **Automatic Scaling and High Availability**

It is an ***All-In-One Solution for Modern App Hosting***

# 3. Why use Azure App Service?

![[Pasted image 20260622174509.png]]

- Allows you to focus on **Building Great Applications** without worrying about **Managing Severs**

### For example:

If we have a Small Business, and we want to launch an Online Store:
1. We need a place to Host the Website
2. Handle **Traffice Spikes** during promotions
3. Update code often

### Azure App Service helps ups to:
- Deploy quickly without managing servers
- Scale automatically based on traffic
- Monitor your app without third-party tools.

---
## 4. What are App Service Plans?

![[Pasted image 20260622174948.png]]

To run your website, we will need an App Service Plan. An App Service Plan is like
renting a virtual server from Azure. 
1. It defines how much compute power your app gets - including memory, CPU, and
scaling options (like manual or automatic). 
2. You pay for the server (the Plan), and you can host one or many apps on it. 
3. Plans range from Free (for testing) to Premium (for production apps that need serious speed and scale).

---
## 5. Deployment Options

![[Pasted image 20260622175205.png]]

Deploying your app to Azure App Service is **straightforward**. 

1. You can use the Azure Portal for a simple interface
2. The Azure CLI for automation
3. or integrate directly with development tools like Visual Studio.

For frequent updates, you can enable continuous deployment by connecting your app to repositories such as GitHub or Azure DevOps.

---

## Deployment Slots

![[Pasted image 20260622175337.png]]

For zero-downtime deployments, App Service provides deployment slots. 
These staging environments let you:
1. deploy a new app version to a slot
2. Test it with a real URL
3. and then swap it into production instantly. 

This makes continuous integration and delivery smooth and reliable.

---

## Built-in Security & Compliance

![[Pasted image 20260622175453.png]]

Azure App Service includes several built- in security features: 
1. Role-based access control ensures that only authorized users can access your resources. 
2. For sensitive information, you can use Azure Key Vault to store secrets like API keys.
3. You can also restrict access to your app using IP filtering or private endpoints. 
4. It also meets key compliance standards, making it suitable for regulated industries.
