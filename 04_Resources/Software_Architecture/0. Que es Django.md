- Es un `Framework` opensource para crear aplicaciones web (Web Apps) usando Python
- Permite crearlas rapidamente, simplificando tareas repetitivas
- Permite crear:
	- **Bases de Datos**
	- **Auth usuarios**
	- **Forms**
	- **Protected Routes**
	- **Tener un Admin Panel**

- Es el framework mas popular, sobre FastAPI y Flask
