Ahora escribiremos, de manera individual, un script de python en la plataforma Google Colab para procesar el conjunto de datos que te compartimos a continuación. Para esta tarea se recomienda usar como base el script del momento anterior. El objetivo del conjunto de datos es entrenar un modelo para determinar si un tumor es benigno o maligno.

[Descargar conjunto de datos](https://archive.ics.uci.edu/ml/datasets/Breast+Cancer+Wisconsin+%28Original%29)

El script debe realizar las siguientes actividades:

1. Cargar el conjunto de datos en un data frame de pandas.
2. Separar los datos en conjunto de entrenamiento y prueba.
3. Construir un modelo a partir de los datos de entrenamiento (construir un modelo de clasificación por regresión logística).
4. Probar el modelo utilizando los datos de prueba. Reportar la medida accuracy para el modelo construido.

El programa resultante debe ser entregado a través de la actividad "**Procesamiento de la base de datos Breast Cancer Wisconsin**". Para acceder, haz clic [aquí](https://auladigital.javerianacali.edu.co/d2l/common/dialogs/quickLink/quickLink.d2l?ou=255010&type=dropbox&rcode=3DD214ED-5CEF-4D53-8AAA-879627930DB4-798760).
