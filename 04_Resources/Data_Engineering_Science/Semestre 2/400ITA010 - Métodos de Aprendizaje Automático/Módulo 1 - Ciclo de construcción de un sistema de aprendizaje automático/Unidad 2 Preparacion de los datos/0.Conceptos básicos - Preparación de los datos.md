Todo comienza **conociendo los datos sobre los que se va a trabajar.** 

A partir de esto, los **aspectos** que se van a **detectar y corregir** tienen que ver con: 
- El manejo de datos faltantes
- De datos atípicos
- De datos muy correlacionados 
- De datos desbalanceados
# Objetivo

Analizar conjuntos de datos detectando en ellos características que dificultan el aprendizaje y alternativas para corregirlas, a través del análisis de casos prácticos para adquirir la habilidad de preparar conjuntos de datos que faciliten realizar aprendizaje automático.

## Conexión transversal

La preparación para aprendizaje automático parte de [[Master Data Science/Semestre 1/Metodos y Simulacion Estadistica/Unidad 1/Ordenar y Limpiar Datos|la limpieza estadística de datos]]. Antes de entrenar un modelo, se deben definir de forma reproducible las reglas para datos faltantes, atípicos, codificación, escalamiento y partición de los conjuntos de entrenamiento, validación y prueba.
