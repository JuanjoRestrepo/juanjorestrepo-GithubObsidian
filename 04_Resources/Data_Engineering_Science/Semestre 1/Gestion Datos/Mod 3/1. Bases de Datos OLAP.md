Las bases de datos que vimos en el primer módulo del curso son ***perfectas para persistir los datos que una organización o empresa*** considere indispensables para el logro de sus objetivos. En este mundo empresarial, es muy común que las bases de datos más utilizadas sean las Bases de Datos Relacionales, mismas que organizan los datos en estructuras con forma de tablas, donde las mismas se relacionan mediante identificadores únicos.

Profesionales dueños de los datos, como Ingenieros de Software e Ingenieros de Datos, utilizan este tipo de bases de datos para realizar diversas operaciones de gestión como la ***inserción de datos, la lectura de datos, la modificación de datos o la eliminación de datos.*** Estas operaciones son de ***carácter transaccional o atómica***, por lo que se le denominan procesos transaccionales. En consecuencia, aquellas bases de datos sobre las que se ejecutan estos procesos se engloban en las llamadas ***OnLine Transactional Processing, OLTP.***


Ahora bien, aunque las Bases de Datos OLTP son bastante eficientes para realizar operaciones transaccionales, presentan desventajas frente a consultas de tipo analítico, sumamente importantes para los Científicos de Datos. Esto se debe a que dichas consultas requieren obtener datos de muchas tablas diferentes. Entre las desventajas más notorias podemos encontrar consultas cruzadas demasiado largas y complejas y tiempos de respuesta muy grandes. Para solventar esta situación, aparecen las OnLine Analytical Processing, Bases de Datos OLAP, cuyas estructuras, basadas en Modelos Multidimensionales, permiten la generación eficiente de reportes para el análisis y visualización de datos. En esta unidad veremos conceptos como Modelos Multidimensionales, Data Marts, Data Warehouses, Cubos OLAP y Procesos ETL.

# ¿Qué es Business Inteligence (BI)? 
---
La **inteligencia de negocios (BI)** se centra en proporcionar información relevante, confiable y accesible a las personas correctas en el momento oportuno para tomar decisiones más rápidas y acertadas. Su objetivo principal es organizar datos desordenados y convertirlos en información útil para mejorar los procesos de decisión estratégica.

### Principales componentes de BI:

1. **Fuentes de datos operativos:** Datos estructurados provenientes de bases de datos, sistemas CRM/ERP, entre otros, que alimentan la toma de decisiones estratégicas.
2. **Proceso ETL (Extracción, Transformación y Carga):** Prepara y optimiza los datos para integrarlos en un **Data Warehouse** o presentarlos directamente a los usuarios.
3. **Data Warehouse (almacén de datos):** Base de datos centralizada y estructurada que permite almacenar y analizar el historial de datos estratégicos, optimizando las consultas.
4. **Plataforma BI:** Facilita la interacción entre los usuarios y el Data Warehouse, incluyendo mecanismos de seguridad y herramientas de análisis.

### Herramientas y técnicas de BI:

- **Consultas y reportes:** Presentan información predefinida con filtros y parámetros personalizables.
- **Cubos OLAP:** Permiten consultas dinámicas similares a tablas dinámicas en Excel.
- **Data Mining:** Identifica patrones y relaciones ocultas en los datos, como casos emblemáticos (ej. relación entre compras de pañales y cerveza).
- **Tableros de control:** Monitorean objetivos estratégicos a través de visualizaciones como gráficas, indicadores y tablas.
- **Alertas y notificaciones:** Generan avisos automáticos cuando indicadores clave (KPI) se desvían de los objetivos.
- **Modelado y predicción:** Aplica métodos estadísticos para predecir eventos futuros basándose en patrones históricos.

### Beneficios:
- Mejora la competitividad empresarial.
- Optimiza el conocimiento sobre factores que afectan el modelo de negocio.
- Permite decisiones informadas y alineadas con objetivos estratégicos.

### Ejemplo práctico: Gestión minorista
Una tienda minorista puede usar tarjetas de lealtad para rastrear compras de clientes en tiendas físicas y en línea. BI permite analizar estos datos para identificar preferencias, hábitos de compra y oportunidades para ofrecer promociones personalizadas en tiempo real. Esto ayuda a fidelizar clientes, aumentar ventas y mejorar la experiencia del cliente.

### En resumen:
BI no solo organiza y presenta datos, sino que los convierte en un recurso estratégico invaluable. Facilita el acceso a información precisa y accionable, ayudando a las organizaciones a comprender mejor sus operaciones y aprovechar al máximo su potencial. Es una herramienta esencial para cualquier empresa que desee innovar, ser más competitiva y responder a las demandas del mercado de manera efectiva.
