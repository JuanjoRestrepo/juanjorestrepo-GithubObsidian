La base de datos aparece con datos faltantes para variables cuali y cuanti

Hay que saber que hacer con las variables faltantes y si se van a imputar o no

Y para responder a las preguntas, hay que determinar dichas variables y los gráficos o tablas


# Datos Atipicos

- Son muy importantes
- Modelo sencillo que no sea sensible a los datos atipicos
- De nada vale que tan bonito sea el modelo si la parte del pre-procesamiento está mala



Hacer analisis estadistico

De acuerdo a lo que se busca responder:
- Decidir cuales son las variables y clasificarlas (poner que variables en anexos)
- Nos enfocamos si son cuanti o cuali o discretas
- Arrancamos con la variables importantes, revisamos en la cuanti el grafico para buscar atípicos, revisamos si hay una que puede ser error (Dato faltante, error). Lo mas recomendable es ponerlo como dato faltante al no tener al entrevistador que hizo esa base.
- Revisamos si hay patrones
- Tomamos las variables cuanti y tomamos decisiones en como presentarlas: tablas, gráficos o indicadores posición, dispersion, etc... (va en anexos)
- Si hay atípicos usamos la mediana, desviación, 



Ser breve, contando en un parrafo donde se muestre que realmente se hizo un procesamiento de manera resumida, si se necesito imputar una variable y por que cosa se imputo (media, mediana)
