
**PURPOSE**

During this exercise you will become familiar with the Unix System Services (USS) component of the IBM® z/OS® operating system and learn how to navigate and deal with files, folders and programs in a shell-based environment. We will also show you how files can go between "sides" of the system.

So far we've spent a lot of time in the _Data Sets_ and _Jobs_ sections of Zowe. Maybe you're curious about the USS area in between?

_Guess what? Your dreams are about to come true._

USS is just another way to use the z/OS operating system. Instead of using interfaces that are specific to z/OS, it features an interface that's more familiar to people who use Linux® or other UNIX-like operating systems. Behind the scenes, everything is still handled by the same operating system, but we'll use USS for more interactive back-and-forth type tasks, thanks to the shell.

In computer terms, a shell is an interface that you use to have a conversation with the system. You type something and press **enter**, the system does something, and replies to you.

  

**FOR EXAMPLE**

If you say 'ls', that's telling the system to _list_ everything around you and reply with that list of things. You'll also learn a new way of moving around, running programs, and working with files and folders.

The USS file system is hierarchical, meaning that files and folders can go inside other folders. In UNIX terms, folders are typically called _directories._ Moving around a hierarchical file system means simply changing your view from one directory to another.

You'll connect to USS by using Secure Shell (SSH). If you're on a fairly recent version of Windows, MacOS, or Linux, you probably have SSH already installed. If you get to step #2 and SSH is not installed, there will be a few recommendations for you to follow, so keep an eye out for them.

  

**REMEMBER**

You're using the same system, just a different part of it.

- Your user ID and password will be the same, but you'll need to enter your username in lowercase like z12345, not Z12345
- Use the same formatting with your password; make sure you enter it in all lowercase letters
