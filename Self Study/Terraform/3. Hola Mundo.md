# Provider
Un proveedor en Terraform es un **plugin** que interactúa con un **servicio o API** específica de un **proveedor de infraestructura**
```terraform
provider "aws" {
	region = "us-east-1"
}
```

En este ejemplo, nos conectamos con el proveedor **AWS**

# Resource
Los recursos son la unidad básica de configuración de Terraform
```terraform
resource "aws_instance" "nginx-server" {
	ami = "ami-0440d3b780d96b29d"
	instance_type = "t3.micro"
}
```

- **resource:** el tipo de recurso. En este caso es `"aws_instance"` y lo llamamos con `"nginx-server"`
- **ami (Amazon Machine Image):** es una plantilla preconfigurada que define el OS y el software base para lanzar instancias EC2 en AWS. En ese caso `"ami-0440d3b780d96b29d"` es tipo linux.
- **instance_type:** define el **tamaño y la capacidad de hardware** (CPU, memoria, red) que tendrá tu servidor en AWS.
