# Provider
Un proveedor en Terraform es un **plugin** que interactúa con un **servicio o API** específica de un **proveedor de infraestructura**
```terraform
provides "aws" {
	region = "us-east-1"
}
```

En este ejemplo, nos conectamos con el proveedor **AWS**
