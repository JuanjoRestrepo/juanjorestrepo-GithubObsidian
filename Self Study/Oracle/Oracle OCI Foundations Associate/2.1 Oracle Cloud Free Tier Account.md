### Tenemos una Región de Infraestructura de Oracle Cloud (OCIR)

1. Esta región está formada pro varios Dominios de Disponibilidad (**Availability Domain**). Estos son nada más que **Data Centers**
2. La Primera Dependencia que tiene el Servicio o Hosts Informáticos es la ***Red Virtual en la Nube***
	1. Esta Network se divide en Subnets/Subredes
	2. Las Subnets se deben crear antes de crear un Host de Recursos Informáticos

3. Un **Host Informático (Compute Host)** es una ***construcción física***
