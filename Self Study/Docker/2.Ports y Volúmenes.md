

# 1. Como Docker identifica las imágenes

![[EstructuraImagenDocker.png]]

- **Registry**: ubicación donde se almacenan las Docker Images
- **namespace**: identifica a quien le pertenece la imagen. Quien es el dueño
- **image**: nombre de la imagen
- **tag**: identifica la versión de la imagen
