
# 1. Antes

1. Se creaban aplicaciones, ya sea con `django`, `postgres`, `rex`, etc... se requeria instalarlo en su propio server para **aislar las dependencias**
2. Esto era para ahorrar recursos

![[AntesDocker.png|500]]

## La matriz del infierno

3. Los servicios debian separarse. Pero para cada aplicación, se necesitaban **librerías especificas**.
4. Si todo esto se instalaba en el mismo server, podrían haber **problemas de versiones, entre OS**

![[MatrizDelInfierno.png|450]]
*"En mi maquina funciona"*

## Virtual Machines - Primera solucion

5. Lograba aislar las aplicaciones y lo de la matriz del demonio
6. **Las dependencias, el OS y todo se aislaba** y no creaba conflictos entre versiones, OS, etc...
7. Lo malo, es que las **VM son muy pesadas y lentas** de inicializar al tener que cargar todo un OS desde cero.
8. Esto necesitaba utilizar muchos recursos

![[VirtualMachine Primera Solucion.png|450]]

## Docker - La salvacion
9. Docker es la manera para crear un aislamiento entre aplicaciones
10. Ya no crea conflictos gracias a las `Containers`
11. Los Containers
