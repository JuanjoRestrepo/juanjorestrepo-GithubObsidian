# 1. Que es una imagen

![[Que es una Docker Image.png|450]]

- Es un **paquete de lectura que contiene todo lo necesario** para que una Applicacion pueda ejecutarse
	- *Sistema de archivos, OS, Dependencias, librerías, etc...*
- Se puede ver como un *"paquete todo en uno"*, que se usa para crear distintas instancias de la Applicacion
- Las **instancias se refiere a los Docker Containers**
