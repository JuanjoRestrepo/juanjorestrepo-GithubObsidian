# 1. Que es una imagen

![[Que es una Docker Image.png|450]]

- Es un **paquete de lectura que contiene todo lo necesario** para que una Applicacion pueda ejecutarse
	- *Sistema de archivos, OS, Dependencias, librerías, etc...*
- Se puede ver como un *"paquete todo en uno"*, que se usa para crear distintas instancias de la Applicacion
- Las **instancias se refiere a los Docker Containers**

---

## Relación con POO


![[Screenshot 2025-07-15 at 6.42.14 PM.png|450]]

- Las **Docker Images** se pueden ver como una **Clase**
- Cada **Container** se puede ver como la **Instancia de esa Clase**
- Es decir, a partir de una imagen de docker, en este ejemplo, una imagen `Postgres`, puedo **instanciarla para que se generen 3 containers** con sus propias configuraciones: 
	- Un Container para Dev (Tests)
	- Un Container para QA
	- Un Container para Producción

## De donde salen las Docker Images?

![[Screenshot 2025-07-15 at 6.48.22 PM.png|500]]

- Se almacen de un **registro**
- El registro más importante para almacenar Docker Images es **Docker Hub**
	- También existen otros tipos de registros como *Amazon ECR, GitHub Container Registry, Google Registry

# 2.  Ejemplo con Ubuntu Image

```bash
docker run -it -p 8000:8000 ubuntu
```

- `it`: ejecutar de forma interactiva
- `-p`: Haciendo port mapping. Lo que llega a la maquina desde el puerto 8000, se redirige al puerto 8000 del container
- Este container esta basado en la imagen de Ubuntu


# 3. Para crear una applicacion en produccion

1. Actualizar repositorio de la imagen (En este caso la de Ubuntu)

Actualizar registros
```bash
apt-get update
```

Actualizar dependencias

Instalar python y pip
```bash
apt-get install -y python3
apt-get install -y python3-pip
```

2.  Creamos el directorio de archivos

```bash
root@ae73be486e86:/# pwd
/
root@ae73be486e86:/# mkdir app
root@ae73be486e86:/# ls
app
```

3. Creamos el `requirements.txt`
```bash
apt-get install nano
nano requirements.txt

ls
cat requirements.txt
```

4. Instalamos el `requirements.txt`

```bash
pip3 install -r requirements.txt

# Saltarse la limitante de Ubuntu
pip3 install -r requirements.txt --break-system-packages
```

5. Creamos nuestro `main.py`
```python
from fastapi import FastAPI

app = FastAPI()

@app.get("/")
def hello():
	return {"message": "Hola desde FastAPI en Ubuntu Docker!"} 
```

6. Ejecutamos nuestra app
```bash
python3 -m uvicorn app.main:app --host 0.0.0.0 --port 8000
```

- `-m`: para acceder al modulo de python
- `uvicorn`: es nuestro servidor asincrono
- `app.main`: ubicacion de nuestra aplicacion
- `--host 0.0.0.0`: ip para publicar nuestra app (`0.0.0.0`) es publica
- `--port 8000`: la publicamos en el puerto 8000

Para ver nuestra Contenerizada, vamos a la ip `http://127.0.0.1:8000/` con el puerto 8000

# Dockerfiles (Creación de Imágenes Optimizada)

`Dockerfile`:
- Conjunto de instrucciones que usa Docker para generar las imágenes

## Ejemplo:

En este archivo, escribiremos todas las instrucciones que habíamos hecho anteriormente a mano.

> **NOTA**: ESTOS SON LOS PASOS QUE SE DEBERIAN EJECUTAR EN PRODUCCION DE MANERA AUTOMATIZADA

```Dockefile
FROM ubuntu:22.04

RUN apt-get update && apt-get install -y \
	python3 \
	python3-pip

WORKDIR /app
COPY requirements.txt .
RUN pip3 install -r requirements.txt

COPY app/ ./app/
CMD ["python3", "-m", "uvicorn", "app.main:app", "--host", "0.0.0.0", "--port", "8000"]
```

Los comandos para ejecutar la aplicación, se pasan como **una lista de strings, comando por comando**

## Construir el Dockerfile

```bash
docker build -t fast-api-demo .
```
- `docker build`: construir la imagen docker
- `-t fast-api-demo`: tag para la imagen (*fast-api-demo*)
- ` .`: para que busque los archivos necesarios (*dockerfile*) para crear la Image en la ubicación actual
