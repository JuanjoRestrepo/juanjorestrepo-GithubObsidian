Si yo quiero volver a correr una DB desde cero, puedo tirarla, es decir, eliminarla. Para ello, usamos `DROP`

```MySQL
DROP DATABASE IF EXISTS twitter_db; 
-- Elimina la Database si Existe. 
-- Sino existe, entonces la crea

CREATE DATABASE twitter_db;

USE twitter_db;
```

Lo mismo podemos hacer para las tablas `TABLE`

```MySQL
DROP TABLE IF EXISTS users;

CREATE TABLE users(
 -- Crear campos...
)
-- Elimina la Tabla si Existe. 
-- Sino existe, entonces la crea

INSERT INTO users(
 -- Insetar registros
)
```
