  

# Updating the Configuration File in UiPath

## Lesson Objectives
* Learn how to modify and manage the project configuration file (`Config.xlsx`) to adjust runtime parameters, asset mappings, and environment settings.
* Understand the role of externalized configurations in maintaining enterprise-grade, environment-agnostic automation workflows.

---

## Structure of `Config.xlsx`
In standard **REFramework** projects, the `Config.xlsx` file is stored in the `Data` directory and consists of three main sheets:
* **Settings**: Global configuration key-value pairs (e.g., timeouts, application URLs, maximum retry counts).
* **Constants**: Immutable system values used across execution runs (e.g., maximum log lengths, system default delays).
* **Assets**: Mappings for **UiPath Orchestrator Assets** (e.g., Orchestrator credential names, global configuration assets).

---

## Step-by-Step Implementation Guide

### 1. Locate the Configuration File
* Open your project workspace in **UiPath Studio**.
* Expand the **Project Panel** and navigate to the `Data` directory.
* Locate `Config.xlsx` (or right-click the file and select **Open File Location**).

### 2. Open & Inspect `Config.xlsx`
* Open `Config.xlsx` using Microsoft Excel or an equivalent spreadsheet editor.
* Select the relevant sheet (**Settings**, **Constants**, or **Assets**) based on the parameter you need to adjust.

### 3. Modify Parameter Values
* **Settings Sheet**: Update local file paths, application directory strings, or execution flags under the `Value` column matching the target `Name` key.
* **Assets Sheet**: Add or edit key entries under `Name` and map them to their corresponding Orchestrator asset keys under `Asset`.
* **Credentials**: Ensure sensitive credential references correspond to named **Orchestrator Credentials** rather than plain-text strings.

### 4. Save & Close the File
* Save changes (`Ctrl + S`) in Microsoft Excel.
* **Crucial Step**: Close `Config.xlsx` before running the automation to avoid file-lock errors during execution.

### 5. Validate Reference Ingestion
* Open your **Main.xaml** or `InitAllSettings.xaml` workflow in **UiPath Studio**.
* Run the workflow (`F5`) to verify that the `Config` dictionary object populates keys and values correctly without runtime parsing errors.

---

## Best Practices & Security
* **Never Hardcode Credentials**: Store credentials exclusively in **UiPath Orchestrator** and reference their asset keys within the **Assets** sheet.
* **Environment Agnosticism**: Keep local machine paths dynamic or relative whenever possible to support smooth migration between Dev, Staging, and Production environments.

---

## Conclusion
Updating and maintaining `Config.xlsx` enables seamless environment management and allows parameter adjustments without modifying underlying workflow logic (`.xaml` files).
