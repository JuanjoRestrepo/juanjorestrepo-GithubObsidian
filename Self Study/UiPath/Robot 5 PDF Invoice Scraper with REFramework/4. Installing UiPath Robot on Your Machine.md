# Notes on Installing UiPath Robot on Your Machine
## Lesson Objectives
* Guide users through the process of installing UiPath Robot.
* Ensure the robot is correctly configured for operational use.

## Step-by-Step Installation Guide

### 1. Download the Installer
* Visit the official UiPath website.
* Select the option to download the **Community Edition**.
* The installer bundle includes both **UiPath Studio** and **UiPath Robot**.

### 2. Run the Installer
* Open the downloaded executable file once finished.
* Follow the on-screen prompts provided by the setup wizard.

### 3. Select Components
* Choose the specific components to install when prompted.
* Ensure **UiPath Robot** is explicitly selected as part of the package.

### 4. Complete Installation
* Close the wizard once the setup finishes successfully.
* Locate **UiPath Robot** or **UiPath Assistant** via the System Start Menu to launch it.

### 5. Initial Configuration
* Connect to **UiPath Orchestrator** upon first startup if operating within an orchestrated environment.
* Configure jobs directly from **UiPath Studio** to execute them locally if not using Orchestrator.

## Key Recommendations & Support
* Verify that you are installing the correct edition (**Community** vs. **Enterprise**) if setup issues arise.
* Refer to the official UiPath documentation for detailed environment configuration options.

## Conclusion
Completing these steps prepares your machine with UiPath Robot to execute local or orchestrated automation projects.
