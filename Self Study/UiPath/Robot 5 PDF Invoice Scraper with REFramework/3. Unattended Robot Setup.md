
# Assigning Unattended Licenses to a Tenant

## Lesson Objectives
- Configure the unattended license within tenants.
- Allow processes to run in an unattended manner.

## Steps to Assign the Unattended License

### 1. Create a New Folder
- Open the admin menu in the tenant.
- Navigate to Folders.
- Create a new folder for the process, naming it accordingly (e.g., "operations").

### 2. Configure the Folder
- When creating the folder, select Tenant Package Feed.
- Ensure the description is left blank if not needed.

### 3. Machine Permissions and Setup
- Verify that the new folder is created correctly.
- You will notice that a single local user is shown. There will be no machines configured initially.
- You will need to configure a machine and assign permissions to the user for the unattended license.

### 4. Assign the Unattended License
- Go to the admin area where licenses can be managed.
- If the assignment shows "0 of 1", select Edit Allocation.
- Change the number to "1" in production to allocate the license.
- Click Save to complete the allocation.
- Verify that the allocation is correct; it should indicate that the license is assigned.

## Conclusion
Once the license is correctly assigned, you will be able to use the unattended license in the tenant to run automated processes.
