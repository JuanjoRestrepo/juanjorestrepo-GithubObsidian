# Notes on Signing In to License the UiPath Robot

## Lesson Objectives
* Master the steps required to sign in and activate the UiPath Robot license.

## Step-by-Step Licensing Procedure

### 1. Launch UiPath Assistant
* Locate and open **UiPath Assistant** on your machine (the core application for managing local robots).

### 2. Configure Service URL
* Navigate to the connection settings within **UiPath Assistant**.
* Select the **Service URL** connection type.
* Input the Orchestrator URL: `https://cloud.uipath.com`.

### 3. Authenticate User Account
* Click **Connect** to trigger the authentication prompt.
* Sign in using your **UiPath Orchestrator** credentials (or register a new account if necessary by following the on-screen steps).

### 4. Assign Robot License
* Verify that a valid robot license is mapped to your user profile upon signing in.
* **Troubleshooting "No robot configured for current user" error:**
  * Navigate to your **Tenant** settings inside UiPath Orchestrator.
  * Access **Manage Access** and assign the appropriate robot license type to your user account.

### 5. Verify Connection Status
* Return to **UiPath Assistant** and confirm that the status reads as **Licensed and Connected**.

## Recommendations & Support
* Double-check user credentials and active tenant license allocation if connection failures occur.
* Consult the official UiPath Documentation or Community Forums for extended troubleshooting guides.

## Conclusion
Completing this authentication workflow successfully licenses your robot for executing orchestrated automations.
