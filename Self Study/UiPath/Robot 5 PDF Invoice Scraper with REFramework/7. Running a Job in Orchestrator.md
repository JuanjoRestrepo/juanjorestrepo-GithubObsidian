
# Notes on Running a Job in Orchestrator

## Lesson Objectives
* Understand the core steps required to trigger and execute a job from UiPath Orchestrator.
* Learn to effectively monitor execution status and manage running jobs.

## Step-by-Step Execution Guide

### 1. Access UiPath Orchestrator
* Log in to your **UiPath Orchestrator** tenant using your web browser.

### 2. Navigate to Processes
* Select **Processes** from the left-hand navigation menu on the main dashboard to view all deployed processes.

### 3. Select the Target Process
* Locate the specific process you wish to execute from the published list.
* Click on the process entry to inspect its configuration details.

### 4. Open the Jobs View
* Navigate to the **Jobs** tab within the process details view.
* Review historical execution records associated with this specific process.

### 5. Trigger a New Job
* Click the **Start Job** button on the action bar.
* Select the appropriate target environment and execution runtime type (**Attended** or **Unattended**) based on your architecture.

### 6. Monitor Execution Progress
* Track real-time progress under the global **Jobs** management panel.
* Verify the execution state indicators (e.g., *Pending*, *Running*, *Successful*, *Faulted*).

### 7. Review Execution Logs
* Access detailed execution traces via the **Logs** tab in Orchestrator upon job completion.
* Cross-reference execution details with local system events in **UiPath Assistant** if needed.

## Key Recommendations & Support
* Verify that the designated robot agent is active, connected, and in an *Available* status prior to initiating jobs.
* Inspect process argument inputs and asset dependencies if runtime setup failures occur.

## Conclusion
Running jobs in UiPath Orchestrator requires selecting a published process, dispatching execution to available runtimes, and utilizing logs for real-time monitoring and post-execution troubleshooting.
