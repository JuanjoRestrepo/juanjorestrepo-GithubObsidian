# Storage Accounts

One of the most powerful features

Storage is at the **heart of cloud computing**, and understanding how to use it effectively is key to **building scalable applications**

## Back at Cipher Coffee

They have **grown into a booming franchise** and they need **a better way to store and manage their data**

### What are they dealing with:

1. **Customer Loyalty rewards:** so customers can redeem free drinks
2. **Inventory Data:** to track coffee bean shipments and supplies
3. **Sales Records:** to understand what's selling best

***Azure Storage*** is the best solution to ***store, access and analyze*** that data

### What is a storage account:
- A centralized location to store different types of data
- Highly scalable
- Secure and durable storage options

![[Pasted image 20260602195837.png]]

### Why use a storage account:
- Scalability to handle large datasets.
- High durability and redundancy options.
- Seamless integration with other Azure services.
- Cost-effective data management with lifecycle policies.

# Types of Storage

## Blob Storage
![[Pasted image 20260602200044.png|600]]

- Stores unstructured data, like ***images, logs and backups***

## File Storage
![[Pasted image 20260602200127.png|600]]

- Provides managed file shares accessible by VMs
- Create and manage file shares
- Can be accessed by multiple devices, both in the **Cloud** and **On-premises**

## Queue Storage

![[Pasted image 20260602200301.png|600]]

- Enables message-based communication between applications

## Table Storage
![[Pasted image 20260602200510.png|600]]
- **Table Storage:** A NoSQL key-value store for large-scale structured data.

# Focusing on Blob Storage
![[Pasted image 20260602200659.png|600]]
## Binary Large Object (Blob)
- **Go-to for storing unstructured** data
- Even hosting **static websites**
- Scalable, secure and always available

### For Cipher Coffee:
It is useful for storing:
- Customer receipts and invoices
- Marketing images and product photos
- Backup logs for business continuity
