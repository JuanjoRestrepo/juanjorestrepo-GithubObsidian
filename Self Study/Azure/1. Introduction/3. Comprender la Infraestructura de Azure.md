# Recursos de Azure (Azure Resources)

![[Pasted image 20260529150245.png]]

- Es cualquier item/objeto manipulable que se pueda crear o usar dentro del ambiente de Azure

Algunos ejemplos para el contexto de Cipher Coffee son:

- Una **Virtual Machine** para **hostear** la **aplicación de inventario**
![[Pasted image 20260529150353.png]]


-  Una **cuenta de storage** para **almacenar de forma segura** los **datos de fidelización de los clientes**
![[Pasted image 20260529150528.png]]


- Una **Base de Datos (DB)** para **organizar y analizar**  **los registros de ventas (sales records)**
![[Pasted image 20260529150622.png]]


# Servicios (Services)

- Un **Servicio** se refiere a una **categoría de features** como *"Computar", "Almacenar" , "Redes" *(*Compute, Storage, Networking*)

![[Pasted image 20260529151106.png]]

- Un **Recurso** es el **producto o instancia** específca de un servicio, como *Virtual Machine, Storage Account, Virtual Network* (*Máquina Virtual, Cuentas de Almacenamiento, Red Virtual*)  
	-  Una VM para computar
	- Cuentas de Almacenamiento para Almacenamiento
	- Red Virtual para Redes

Gestionar un negocio, como Cipher Coffee, requiere de múltiples recursos y deben ordenarse de manera eficaz y eficiente. **Los recursos son para eso**

![[Pasted image 20260529151419.png]]

- Mantener todo **organizado y agrupar recursos relacionados** como la VM, Storage Account y las DB bajo el mismo ámbito
- Monitorear rendimientos
- Controlar accesos y rastrear costos
- Eliminar un grupo entero

# Actividad

#### Encontrar Grupos de recursos

Cipher Coffee ha completado con éxito uno de sus proyectos y ahora necesita limpiar los recursos no utilizados para evitar cargos innecesarios. **Te han encargado la tarea de identificar estos recursos que ya no son necesarios.**

En Azure, un grupo de recursos es como un contenedor que alberga recursos relacionados, como máquinas virtuales, bases de datos y almacenamiento, lo que facilita su administración como una unidad.

Los grupos de recursos son esenciales para administrar tus recursos en Azure.
- Una vez que hayas iniciado sesión en el portal, ve a la sección _Grupos de recursos._
![[Pasted image 20260529151717.png]]

Ahora que estás en la página de resumen de grupos de recursos:

- Abre el _grupo de recursos_ denominado `student-...`

#### Gestión de grupos de recursos

![[Pasted image 20260529153258.png]]

Ahora que has localizado correctamente el proyecto, **es hora de limpiar los recursos** para evitar que Cipher Coffee incurra en gastos innecesarios.


Los grupos de recursos simplifican la gestión de recursos. En este caso, queremos eliminar todo el grupo para borrar todos los recursos asociados de una sola vez.

- En el grupo Recursos, ve a _Eliminar grupo de recursos_ y selecciónalo.

![[Pasted image 20260529153421.png]]


# Resources vs Resource groups

Which of the following statements correctly describes the difference between a resource and a resource group in Azure?
