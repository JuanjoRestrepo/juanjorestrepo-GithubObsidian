Cipher Coffee is growing its online presence and setting up cloud-based resources to support new digital services. One key resource is a Virtual Machine (VM). A cloud powered computer that can run applications, process data, and support web services behind the scenes.

Explore the existing Cipher Coffee VM, check out its key details, and once you're done, shut it down to prevent unnecessary costs, just like turning off an espresso machine when it’s not in use! 🔌☕

We have made a pre-configured VM for you to explore before you make your own!

- In the list of items, open the pre-configured virtual machine named `vm...` to open its overview page.

Lets now explore some key settings:

- Operating System (OS) 🖥️ – The software that runs on the VM. It determines how applications run and interact with the system.
- Size ⚡ – Defines the VM’s hardware power, including CPU, memory, and performance capacity.
- Availability Zone 🌍 – A physical location within an Azure region that helps keep services running even if one data center experiences an issue.

**Operating system**
Linux (ubuntu 24.04)

**Size**
Standard DS1 v2 (1 vcpu, 3.5 GiB memory)

**Availability zone**
3

Cipher Coffee only requires this machine to be running during work hours which is until 5pm. Lets enable auto-shutdown outside of these hours to save on running costs.

- Navigate to _Operations_ in the left-side menu
- Open _Auto shutdown_
- Set enablement to _On_
- Set the "Scheduled shutdown" to `5:00:00 PM`
- Set the "Time zone" to `(UTC-08:00) Pacific Time (US & Canada)`
- Save the settings

Now the VM will auto shutdown everyday at 5PM, ensuring it doesn't incur unnecessary costs in case the team forget to shut it down after use.

Imagine leaving your computer running for 24 hours a day, when you only need it for 8, what a waste!
