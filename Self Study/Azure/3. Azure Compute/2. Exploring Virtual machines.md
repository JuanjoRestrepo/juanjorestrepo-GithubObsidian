Cipher Coffee is growing its online presence and setting up cloud-based resources to support new digital services. One key resource is a Virtual Machine (VM). A cloud powered computer that can run applications, process data, and support web services behind the scenes.

Explore the existing Cipher Coffee VM, check out its key details, and once you're done, shut it down to prevent unnecessary costs, just like turning off an espresso machine when it’s not in use! 🔌☕

Lets now explore some key settings:

- Operating System (OS) 🖥️ – The software that runs on the VM. It determines how applications run and interact with the system.
- Size ⚡ – Defines the VM’s hardware power, including CPU, memory, and performance capacity.
- Availability Zone 🌍 – A physical location within an Azure region that helps keep services running even if one data center experiences an issue.
