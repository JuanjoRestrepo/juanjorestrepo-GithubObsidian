El servicio EC2 ofrece **instancias virtuales escalables** en la nube, muy similares a los servidores físicos tradicionales.

### Conceptos clave

- **AMI (Amazon Machine Image)**: Plantillas con SO y configuración predefinida (Ubuntu, Amazon Linux, Windows).
- **Tipos de instancia**: Variaciones en CPU, RAM y red. Ejemplo en capa gratuita: `t2.micro`.
- **EBS (Elastic Block Store)**: Volúmenes de almacenamiento persistente conectados a instancias.
- **Pares de claves SSH**: Para acceso seguro. AWS genera un par (pública/privada) al lanzar la instancia.
- **Grupos de seguridad**: Firewall virtual que controla tráfico de entrada y salida a nivel de instancia.
### Pasos para lanzar una instancia EC2

1. Accede a la consola de EC2 y haz clic en **Launch Instance**.
2. Selecciona una **AMI** (filtra “Free tier only” para evitar costes).
3. Elige un **tipo de instancia** (p. ej. `t2.micro`).
4. Configura **Key Pair**: crea o usa uno existente para SSH.
5. Define **Security Group**: abre puertos (SSH 22, HTTP 80, HTTPS 443).
6. Adjunta **volúmenes EBS** según necesidad (30 GB gratis en Free Tier).
7. Revisa y **lanza** la instancia.
### Conexión y gestión

```bash
# Conectar vía SSH:
ssh -i "mi-clave.pem" ec2-user@<EC2_PUBLIC_IP>

# Instalar actualizaciones (Linux):
sudo yum update -y
```

- Para detener o terminar instancias, usa la sección **Instances** → **Actions** → **Instance State**.
- Eliminar instancias que no se usen para **evitar cargos**.

### Elasticidad con EC2

- **Auto Scaling Groups**: Definen políticas de escalado automático basadas en métricas (CPU, red).
- **Elastic Load Balancer**: Distribuye tráfico entre instancias para alta disponibilidad.
- Se pueden levantar máquinas virtuales como quieras y que necesites. Se pueden tener desde windows, ubuntu, macos, hasta de los OS de Amazon
