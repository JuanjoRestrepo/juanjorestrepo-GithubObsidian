# Headers y Buffers: Notas Clave
*Basado en contenido del video vinculado (sección ~34:39).*

---

## 🔑 **Headers HTTP**  
Metadatos enviados en solicitudes/respuestas para controlar comportamiento de la comunicación.

### Tipos de Headers
| Categoría         | Ejemplos comunes              | Uso                                      |
| ----------------- | ----------------------------- | ---------------------------------------- |
| **Generales**     | `Content-Type`, `User-Agent`  | Formato de datos y cliente usado.        |
| **Autenticación** | `Authorization`, `Cookie`     | Gestionan acceso y sesiones.             |
| **Caché**         | `Cache-Control`, `ETag`       | Controlan almacenamiento temporal.       |
| **CORS**          | `Access-Control-Allow-Origin` | Permiten/habilitan solicitudes cruzadas. |

---

### Casos Prácticos
```http
GET /data.json HTTP/1.1
Host: api.ejemplo.com
Authorization: Bearer xyz123
Accept: application/json
```

### Headers clave en APIs

- `Accept`: Indica formato esperado (JSON, XML, etc).
	
- `Content-Length`: Tamaño del cuerpo en bytes.
	
- `User-Agent`: Identifica cliente (ej: `Postman/10.0`).


```javascript
// Crear un buffer desde un string
const buf = Buffer.from('Hola mundo', 'utf8');

// Leer datos
console.log(buf.toString('hex')); // 486f6c61206d756e646f

// Manipulación
const buf2 = Buffer.alloc(10); // Buffer vacío de 10 bytes
buf2.write('Node');
```
