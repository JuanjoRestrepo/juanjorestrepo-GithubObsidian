# Protocolo HTTP: Explicación Clara

**HTTP** (*HyperText Transfer Protocol*) es el protocolo de comunicación que permite la transferencia de información en la web (ej: navegadores, APIs). Opera bajo el modelo **cliente-servidor** y es la base de Internet.


```javascript
const http = require('node:http'); // Protocolo HTTP

  

const desiredPort = process.env.PORT ?? 1234;

  

// Servidor

const server = http.createServer((req, res) => {

  console.log('request received');

  res.end('Hola papi');

});

  

server.listen(desiredPort, () => {

  console.log(`Server running on port http://localhost:${desiredPort}`);

});
```

# ¿Cómo funciona el protocolo Http?

Es el protocolo de red de transferencia de hipertexto más utilizado en páginas web para transmitir información

---
## Conceptos Básicos
- **Stateless**: No guarda información entre solicitudes (se usan cookies o tokens para mantener estado).  
- **Texto plano**: Las solicitudes/respuestas son legibles por humanos (aunque en HTTP/2 se usa binario).  
- **Puerto por defecto**: `80` (HTTP) / `443` (HTTPS).

---
  
## Estructura de una Solicitud/Respuesta HTTP

### 1. **Solicitud (Cliente → Servidor)**
```http
GET /index.html HTTP/1.1
Host: ejemplo.com
User-Agent: Mozilla/5.0
Accept: text/html
- **Método**: Acción a realizar (`GET`, `POST`, `PUT`, etc.).
    
- **Headers**: Metadatos (ej: tipo de contenido, autenticación).
    
- **Body** (opcional): Datos enviados (ej: formularios POST).
```
