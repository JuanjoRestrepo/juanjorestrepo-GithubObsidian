Lo primero que hay que hacer para pasar un proyecto de *commonJS* a *ESModules* de NodeJS es: 

- Ir al `package.json` donde por default, el `type` es `"commonjs"`
```json

{
  "name": "rest-api",
  "version": "1.0.0",
  "description": "",
  "main": "app.js",
  "type": "commonjs", // default
  "engines": {
    "node": "14.x"

  "scripts": {
```

### Solución
#### 1. Usamos `fs`

```javascript
//========== COMO LEER UN JSON EN ESModules ==========
import fs from 'node:fs';
const movies = JSON.parse(fs.readFileSync('./movies.json', 'utf-8'));
```
##### Explicación
1. **`fs/promises`**: Este módulo permite leer archivos de forma asíncrona usando promesas.
2. **`readFile`**: Lee el archivo `movies.json` de forma dinámica.
3. **`JSON.parse`**: Convierte el contenido del archivo (una cadena de texto) en un objeto JavaScript.

#### 2. Podemos crear un `require` como función

```javascript
//========== COMO LEER UN JSON EN ESModules RECOMENDADO POR AHORA ==========

import { createRequire } from 'node:module';
const require = createRequire(import.meta.url);
const movies = require('./movies.json');
```

- `import.meta.url`: tiene la dirección del archivo actual

No obstante, hay otra alternativa mucho mejor, que minimiza el proceso tanto, que solo es necesario crear un archivo `utils.js` en donde se creen los `require` y este `utils` se llame al `app.js`

`utils.js`
```javascript
import { createRequire } from 'node:module';

const require = createRequire(import.meta.url);

  

export const readJSON = (path) => require(path);
```


`app.js`
```javascript
import express, { json } from 'express'; // usamos require luego pasaremos a commonJS
import { randomUUID } from 'node:crypto'; // modulo de node para hashear
import cors from 'cors';

import { validateMovie, validatePartialMovie } from './schemas/movies.js';
```

# Implementación de Routes en Express 🗺️

## Estructura Básica de Routes

```javascript
import express from 'express';
const app = express();

// Ruta GET básica
app.get('/movies', (req, res) => {
  res.json(movies);
});

// Ruta con parámetros
app.get('/movies/:id', (req, res) => {
  const movie = movies.find(m => m.id === req.params.id);
  res.json(movie);
});
```

## Mejores Prácticas para Routes ✅

1. **Separar rutas en módulos:**
```javascript
// routes/movies.js
export const router = express.Router();

router.get('/', (req, res) => { /* ... */ });

// app.js
import { router as moviesRouter } from './routes/movies.js';
app.use('/movies', moviesRouter);
```
2. **Validar parámetros:**
```javascript
app.get('/movies/:genre/:year', (req, res) => {
  const { genre, year } = req.params;
  // Validar con Zod
});
```

3. **Manejo centralizado de errores:**
```javascript
app.use((err, req, res, next) => {
  console.error(err.stack);
  res.status(500).send('Error en el servidor!');
});
```
