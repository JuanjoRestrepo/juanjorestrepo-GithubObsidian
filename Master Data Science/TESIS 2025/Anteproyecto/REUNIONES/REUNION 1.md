# 🧪 Proyecto de Investigación: Multiple Instance Learning (MIL)

## 📍 Objetivo General del Proyecto

Aplicar técnicas de aprendizaje débilmente supervisado, específicamente *Multiple Instance Learning*, para resolver un problema aplicado en el contexto de datos estructurados en bags, empleando bases de datos biomédicas (cáncer o EEG).

## 📦 Material Técnico Base

- 🧮 Código base
- 🔬 Experimentos sintéticos
- 🎯 Datos estructurados en *bags*:
  - Se conoce la etiqueta de la bolsa (*bag*), **no** de las instancias individuales.

---

## 🎯 Enfoque Temático

### Bases de Datos Candidatas

1. 🧫 **Histopatología (Cáncer de colon)**
2. 🧠 **Electroencefalografía (EEG - Cerebro)**

### Estrategia de Selección

- **Paso 1:** Explicar el problema de interés de cada base de datos.
- **Paso 2:** Evaluar accesibilidad, relevancia clínica y complejidad experimental.
- **Paso 3:** Seleccionar una base y formular el discurso técnico.
- **Paso 4:** Si se elige *cáncer de colon*:
  - Describir el contexto clínico
  - Justificar el uso de MIL
  - Enlazar con los objetivos del proyecto

## 📌 Notas Importantes

- El enfoque se basa en **aprendizaje débilmente supervisado**, especialmente en problemas donde:
  - Las instancias individuales **no están etiquetadas**, pero los *bags* sí.
- Se propone empezar con **experimentos sintéticos** para validar la arquitectura.
- El código debe ser modular y extensible para futuras pruebas con múltiples datasets.
