# Modelado de capacidades empresariales

- Forma de descomponer las habilidades de un equipo en componentes mutuamente excluyentes
- Los componentes se pueden asignar a los objetivos estratégicos de la organización
- Cualquier laguna se puede abordar a través de una **Hoja de Ruta de Talento Humano**


![[Pasted image 20251004105539.png]]

La creación de los modelos requiere:
- Desglosar las familias claves de capacidades que se requieren
- Conocimiento funcional, técnico y liderazgo
- Cada elemento de esas *capacidades de nivel 1*, se **desglosa** en *capacidades de nivel 2*
- Ilustra lo que se requiere para el **Éxito de la función analítica** y Permitir diferentes **Campos de Visión**


Para realizar este ejercicio se debe:
- Realizar **Entrevistas Personalizadas** con cada miembro del equipo de ciencia de datos
- Establecer el Estado Actual:
	- Cómo se siente
	- Cuáles son sus habilidades
	- Etc...
- Establecer el Estado Futuro:
	- Planes en los siguientes años
	- Qué le gustará profundizar
	- Responsabilidades: Importancia para el éxito del equipo, rendir cuentas?, quién es el responsable de esto

Luego de haber desarrollado el modelo de capacidades para el equipo, se debe hacer un tabla

### 1. Capacidades Actuales:
Lo que el equipo puede hacer actualmente

### 2. Capacidades Futuras
Hacia dónde quiere ir el equipo

### 3. Mandato Percibido
Lo que el equipo cree que debe hacer


### 4. Brechas Futuras
El inverso de las capacidades futuras. Aquellos elementos en los que el equipo no tendrá cobertura


# Resultado

Una principal fuente de datos para desarrollar una Estrategia de Talento Humano

Estos modelos de capacidad empresarial se puede comprender rápidamente los puntos fuertes y débiles de un equipo para desarrollar una estrategia viable y bien diseñada a tal efecto

Este modelo vincula la **Estrategia** y la **Ejecución** y una base para la contratación de nuevos talentos


## Pila Tecnológica

Combina tecnologías que usa una empresa para crear y ejecutar una aplicación o proyecto

Se conforma de

![[Pasted image 20251004111307.png]]


- Una función analítica adecuada debe tener el **número de herramientas lo más bajo posible**
- Herramientas de propósito especial y específico
- Usar Plataformas establecidas:
	- Reduce complejidad de mantenimiento
	- Contratación de Personal
	- Interoperabilidad

#### En Resumen:
La revisión de la Pila Tecnológica es:
- Minimizar la complejidad del número del equipo reduciendo el número de herramientas de la caja de herramientas

### Evaluación de la Tecnología

Debe responder a 3 preguntas principales:

1. ¿Se está utilizando?
Cada tecnología debe hacer su parte. Entre más herramientas haya, mayores requisitos de mantenimiento y menos productividad del equipo

2. ¿Hay una superposición?
Los cambios en la estructura del equipo, las prácticas y procesos heredados, pueden conducir a situaciones de mantenimiento y que se tengan que escribir modelos en múltiples plataformas y lenguajes.
