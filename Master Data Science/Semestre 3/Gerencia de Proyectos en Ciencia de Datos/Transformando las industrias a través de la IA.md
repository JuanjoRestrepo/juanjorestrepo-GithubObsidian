# What is the Model Context Protocol (MCP)?
https://modelcontextprotocol.io/docs/getting-started/intro

MCP (Model Context Protocol) es un estándar de código abierto para conectar aplicaciones de IA a sistemas externos.

Al utilizar MCP, las aplicaciones de IA como Claude o ChatGPT pueden conectarse a fuentes de datos (por ejemplo, archivos locales, bases de datos), herramientas (por ejemplo, motores de búsqueda, calculadoras) y flujos de trabajo (por ejemplo, indicaciones especializadas)—, lo que les permite acceder a información clave y realizar tareas.

Piense en MCP como un puerto USB-C para aplicaciones de IA. Así como USB-C proporciona una forma estandarizada de conectar dispositivos electrónicos, MCP proporciona una forma estandarizada de conectar aplicaciones de IA a sistemas externos.

![[Pasted image 20251026141804.png]]

## ¿Qué puede habilitar MCP?
- Los agentes pueden acceder a su Google Calendar y Notion, actuando como un asistente de IA más personalizado.
- Claude Code puede generar una aplicación web completa utilizando un diseño de Figma.
- Los chatbots empresariales pueden conectarse a múltiples bases de datos en toda una organización, lo que permite a los usuarios analizar datos mediante el chat.
- Los modelos de IA pueden crear diseños 3D en Blender e imprimirlos utilizando una impresora 3D.


## ¿Por qué es importante MCP?

Dependiendo de dónde se encuentre en el ecosistema, MCP puede tener una variedad de beneficios.

- **Desarrollador**: MCP reduce el tiempo de desarrollo y la complejidad al crear o integrar una aplicación o agente de IA.
- **Aplicaciones o agentes de IA**: MCP proporciona acceso a un ecosistema de fuentes de datos, herramientas y aplicaciones que mejorarán las capacidades y mejorarán la experiencia del usuario final.
- **Usuarios finales**: MCP da como resultado aplicaciones o agentes de IA más capaces que pueden acceder a sus datos y tomar acciones en su nombre cuando sea necesario.
