# 1. Fundamentos (qué son marcas y canales)

- **Marca (mark):** elemento gráfico básico que representa una observación o un grupo de observaciones. P. ej.: **punto** (0D), **línea** (1D), **área** (2D), **volumen** (3D). Estas dimensiones aparecen en los diagramas de Munzner.

![[Pasted image 20250810122124.png|550]]


- **Canal (visual channel):** atributo visual que controla la apariencia de una marca y es independiente a la dimensión en la que se está trabajando la figura geométrica: 

En general, es posible clasificar los canales en los que se refieren a:

- **posición**: en referencia a el lugar donde se encuentra ubicada la figura geométrica
- **profundidad**:(en referencia cuando se trabaja en tres dimensiones)
- **color** (tono, luminancia, saturación)
- **tamaño**: se basa en la dimensión que se esté trabajando
- **curvatura y ángulo**

Los canales son independientes de la dimensión de la marca.

![[Pasted image 20250810122242.png]]


> Idea práctica: piensa las visualizaciones como “marcas” (qué elemento dibujas) + “canales” (qué propiedades de ese elemento codifican tus datos).

A través del siguiente ejemplo se entenderá un poco más claro la forma en que se presentan las marcas y los canales:

![[Pasted image 20250810122703.png]]


Un gráfico de barras generalmente permite conocer atributos cuantitativos (valor que alcanza cada una de las barras), para ello, se usa un canal de posición y se presenta en forma vertical, adicionalmente, se combina con un valor categórico (generalmente expresado en el eje x) para conocer los valores asociados a cada categoría del elemento en cuestión.

![[Pasted image 20250810122710.png]]

Para este segundo ejemplo, se usa un gráfico de dispersión, en el cual, se basa igualmente en un atributo categórico y se agregan dos canales para codificar la visualización (puntos y aspectos asociados al color).

![[Pasted image 20250810122719.png]]


Para el siguiente ejemplo, se usa igualmente un gráfico de dispersión que se encuentra basado en un atributo categórico, pero se agregan 3 canales para representar los elementos visuales (***puntos, aspectos asociados al color y el tamaño de cada uno***).


Esto permite generar una aproximación a que l**os canales no son excluyentes entre sí,** es decir, **es posible usar para los mismos atributos, múltiples canales** y generar que para el público objetivo de la visualización, **sea más fácil de “entender” el mensaje** detrás de la misma

> Se debe tener en cuenta que para algunos casos, no siempre es posible combinar todos los canales,


por ejemplo, ***si estamos realizando una representación del tamaño total de población por m2 por país a través de un mapa geográfico***, generalmente cada país y cada provincia/ estado, *ya tienen unos tamaños definidos*, por lo cual, en este caso, *no podríamos hacer uso de la codificación que varíe el tamaño de la marca o del elemento.*


# 2. Jerarquía de eficacia de los canales (cómo asignar datos → canales)

- **Regla general:** para los datos _más importantes_ o _que requieren comparaciones precisas_, usa **posición** (eje X/Y). Es lo más preciso perceptualmente.
- **Canales no-posicionales (en orden de efectividad típica):**
    1. **Longitud / longitud relativa (p. ej. barras)** — muy preciso para datos cuantitativos.
    2. **Área / tamaño** — menos preciso que la longitud; ten cuidado con la percepción de área (áreas circulares engañan).
    3. **Luminancia / brillo** — bueno para datos ordenados; permite ver bordes y detalles finos; usar con pocos niveles (ideal <5 pasos para claridad).
    4. **Saturación** — útil para destacar regiones; sensible a tamaño visual (difícil en regiones pequeñas), conveniente para pocos niveles (≲3).
    5. **Matiz / hue (tono)** — muy apto para **datos categóricos**; no transmite orden; recomendado usar **≈6–7** categorías como máximo para que el ojo las distinga bien. 
    6. **Forma, orientación, textura** — útiles para categorías limitadas; forma funciona solo con pocas clases (pocas formas distinguibles).


- **Consejo:** evita codificar cantidades que requieren medición precisa usando solo matiz o sólo textura. Prefiere posición/longitud para comparaciones exactas.
