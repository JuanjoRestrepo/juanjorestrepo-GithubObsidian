En el módulo anterior, hablamos de las visualizaciones, los tipos de datos existentes, sus agrupaciones y todo el proceso de ingeniería que existe detrás de los datos

En este módulo 2, nos centraremos en las visualizaciones:

# Objetivos 
Comprender los elementos que conforman una representación visual a través del estudio de las marcas, canales, aspectos perceptuales, idiomas y mecanismos de evaluación de las visualizaciones para identificar elementos visuales que tengan coherencia con el propósito de la visualización.
