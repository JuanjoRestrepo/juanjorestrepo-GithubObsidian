
# Mapeo de visualizaciones   según el tipo de datos y   percepción (visual encoding)


# Introducción
En esta unidad se presentan los diseños más comunes de representaciones visuales utilizadas para comunicar datos en un entorno empresarial, o en diferentes contextos, casos específicos o de uso. Los tipos específicos de visuales cubiertos incluyen texto simple, tabla, mapa de calor, gráfico de líneas, gráfico inclinado, gráfico de barras verticales, gráfico de barras verticales apiladas, gráfico de cascada, gráfico de barras horizontales, gráfico de barras horizontales apiladas cuadrado.

Se realiza un estudio de los elementos visuales más comunes a la hora de realizar la construcción y el diseño, tales como, marcas, áreas, los diferentes canales y la efectividad de cada uno, igualmente se abordan variables de diseño que contribuyen a la efectividad del mensaje como lo son la forma, tamaño, el uso del color y el cómo estructurar la información para presentar a través de series de datos.

# Objetivo
Contrastar las visualizaciones adecuadas según el tipo de información a presentar a través de la caracterización de un conjunto de datos para entender la definición de su estructura, tipos de datos, tipos de atributos y su aplicación.
