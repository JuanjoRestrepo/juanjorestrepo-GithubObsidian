# Ensayo de opinión
Para el momento de acción, realizaremos un ensayo de opinión el cuál debe seguir estos lineamientos:

- Máximo contenido de una página.
- Contener la estructura de un ensayo de opinión, para ello, se debe iniciar la idea, desarrollarla, argumentar y concluir con la opinión del estudiante sobre el tópico.

Temática: La presentación de información a través de visualizaciones en medios públicos.

Guía: Considere nombrar puntos asociados a la información presentada, cómo se estructura, aciertos, fallos, recomendaciones, cómo integraría los conceptos vistos versus los mensajes presentados en medios masivos.
