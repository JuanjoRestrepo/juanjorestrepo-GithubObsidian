# Introducción
En esta unidad se aborda la visualización de datos como un **proceso esencial para la comunicación efectiva** en entornos organizacionales y analíticos. Se estudiarán los conceptos fundamentales que permiten comprender tanto el propósito como los elementos técnicos involucrados en la **creación de visualizaciones,** tales como el data `storytelling`, la `estructura del pipeline de visualización`, y los `tipos de acciones` que guían **la toma de decisiones basadas en datos.**

Además, se profundizará en la comprensión de los fundamentos de los datos: sus atributos, metadatos, categorizaciones y tipificaciones. Este conocimiento es crucial para seleccionar adecuadamente el tipo de visualización más eficaz según las características de los datos y el mensaje que se desea comunicar. Una visualización mal seleccionada puede distorsionar la percepción del mensaje y aumentar la carga cognitiva del público objetivo, mientras que una visualización adecuada permite generar valor real para los stakeholders y facilitar la toma de decisiones.  

ObjetivoIdentificar las necesidades de visualización de datos, de acuerdo con las necesidades de los stackeholders, mediante el reconocimiento de las necesidades de comunicación de información y los tipos de datos para seleccionar el tipo de visualización más idónea y eficiente para maximizar la claridad del mensaje.
