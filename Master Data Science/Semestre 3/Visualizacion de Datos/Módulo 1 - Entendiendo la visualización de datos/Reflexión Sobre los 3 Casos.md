
### 1. ¿De los ejemplos dados cuál es el mensaje que mejor recuerda?
El mensaje que más recuerdo es el del caso **sobre la sobrepesca (“How my dad fishes for the future”),** porque la narrativa de este caso, combina datos científicos con una historia personal emotiva ("mi papá"), lo que genera empatía. De acuerdo con buenas prácticas de narrativa visual, humanizar los datos y apoyarse en múltiples canales (texto, imágenes, personajes) facilita que el mensaje permanezca en la memoria.  
  

### 2. ¿En cuál ejemplo considera que el mensaje se transmite de la mejor manera?
En este mismo caso, es decir, el **caso 2,** es también el más efectivo en transmisión. No solo presenta datos fiables, sino que estructura la historia con un **inicio contextual, desarrollo visual de evidencia y llamado a la acción**, alineándose con una estructura narrativa clásica (inicio, medio, fin).

### 3. **En el último caso, ¿Qué cambiaría o añadiría para representar la intención del autor?** 

El caso **“Cuando los datos no cuentan una historia: errores de visualización de datos”** ejemplifica malas prácticas como la falta de contexto, el uso innecesario de color y gráficos confusos.

Para mejorarlo:

- **Introducir un punto de partida contextual:** ¿Qué problema aborda esta visualización?
- **Simplificar gráficos:** corregir escalas truncadas, eliminar elementos decorativos innecesarios.
- Incorporar **anotaciones**, **etiquetas explicativas** o **micro-narrativas** dentro de cada gráfico para guiar la interpretación.

### 4. Identifique malas prácticas ilustradas en el último caso
En el caso mencionado se observan:
- **Falta de narrativa**: gráficas aisladas sin historia que cohesione la información.
- **Escalas engañosas o truncadas**, que distorsionan percepciones.
- **Uso poco estratégico del color**, generando ruido visual en lugar de énfasis.
- Exceso de detalles sin jerarquía visual, que genera sobrecarga cognitiva.

### 5. ¿Qué caso le llamó más la atención? y ¿por qué?
Sin duda, el de la **sobrepesca,** debido a que la mezcla de narrativa emocional, datos confiables y visualización accesible crea una experiencia memorable. Este caso representa el ideal del storytelling con datos: **mensaje relevante + presentación inteligente + humanización del dato**. Así lo recomiendan gurús de visualización: cada gráfico debe tener intención, contexto y claridad para no perder nunca el foco del mensaje
