Para este momento responderemos, de **manera individual**, las siguientes preguntas a partir de la lectura realizada en el momento anterior.

1. ¿Qué es aprendizaje automático (machine learning)?
2. ¿Qué diferencia hay entre el aprendizaje supervisado y el no supervisado? Escribe un ejemplo de un problema que se resuelva con cada uno de los dos tipos de aprendizaje.
3. ¿Cuáles son las etapas que se deben llevar a cabo para poder construir un modelo mediante aprendizaje automático? Enuméralas y explica qué se hace en cada etapa.

---
# Solución

1. **¿Qué es aprendizaje automático (machine learning)?** 
	El aprendizaje automático es un campo de estudio cuyo objetivo principal es el diseño y análisis de algoritmos que permiten a las computadoras aprender a partir de datos. Se utiliza para diversas tareas, como detección de objetos en imágenes, reconocimiento de voz, descubrimiento de conocimiento en las ciencias médicas y análisis predictivo en economía y ventas​.

3. **¿Qué diferencia hay entre el aprendizaje supervisado y el no supervisado? Escribe un ejemplo de un problema que se resuelva con cada uno de los dos tipos de aprendizaje.**
	- **Aprendizaje supervisado**: Se basa en un conjunto de datos de entrenamiento donde cada entrada tiene una etiqueta o resultado esperado. El modelo aprende a predecir estas etiquetas a partir de nuevos datos.
		- _Ejemplo_: Clasificación de imágenes para diferenciar entre gatos y perros. Se entrena un modelo con imágenes etiquetadas y luego se utiliza para clasificar imágenes nuevas​.
	- **Aprendizaje no supervisado**: No utiliza etiquetas, sino que el modelo encuentra patrones o estructuras en los datos sin supervisión.
		- _Ejemplo_: Agrupación de clientes en un banco según sus hábitos de gasto, para identificar diferentes segmentos de mercado.

**3. ¿Cuáles son las etapas que se deben llevar a cabo para poder construir un modelo mediante aprendizaje automático? Enuméralas y explica qué se hace en cada etapa.**  
Según el documento, el proceso de aprendizaje automático sigue un pipeline general​:
1. **Definir el problema**: Determinar la tarea específica que se desea resolver con el modelo.
2. **Recolección de datos**: Obtener datos para entrenar y probar el modelo. Cuanto más diverso y grande sea el conjunto de datos, mejor será el rendimiento del modelo.
3. **Diseño de características (features)**: Identificar qué características o atributos de los datos son relevantes para la tarea de aprendizaje.
4. **Entrenamiento del modelo**: Ajustar los parámetros del modelo utilizando técnicas de optimización numérica en el conjunto de datos de entrenamiento.
5. **Evaluación del modelo**: Probar el modelo en un conjunto de datos de prueba para medir su desempeño. Si los resultados son deficientes, se pueden volver a ajustar las características o recolectar más datos para mejorar el modelo.
