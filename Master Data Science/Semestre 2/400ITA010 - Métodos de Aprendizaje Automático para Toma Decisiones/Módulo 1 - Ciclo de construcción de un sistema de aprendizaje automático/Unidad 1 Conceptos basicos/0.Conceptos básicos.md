## Pero que es el Machine Learning?

**FORMALMENTE**
- Es la ciencia de hacer que los computadores realicen una tarea sin ser programados explicitamente. *La gran diferencia entre los Algoritmos clásicos y modelos de ML radica en la forma en que los definimos*

**ALGORITMOS CLASICOS**
- Se les dan las reglas exactas y completas para completar una tarea


|                      **ALGORITMOS CLASICOS**                       |                               **ALGORITMOS DE MACHINE LEARNING**                                |
| :----------------------------------------------------------------: | :---------------------------------------------------------------------------------------------: |
| Se les dan las reglas exactas y completas para completar una tarea |              *Reciben pautas generales* que definen el modelo junto con los datos               |
|                                                                    | Los datos deben contener la información faltante necesaria para que el modelo complete la tarea |
|                                                                    |                                         Un modelo de ML                                         |
