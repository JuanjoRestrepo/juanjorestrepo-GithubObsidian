# ¿Pero qué es el Machine Learning?

![[Screenshot 2025-07-24 at 9.14.43 PM.png|600]]]

**FORMALMENTE**
- Es la ciencia de hacer que los computadores realicen una tarea sin ser programados explícitamente. *La gran diferencia entre los Algoritmos clásicos y modelos de ML radica en la forma en que los definimos*


|                       **ALGORITMOS CLASICOS**                        |                                                                             **ALGORITMOS DE MACHINE LEARNING**                                                                              |
| :------------------------------------------------------------------: | :-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------: |
| Se les dan las *reglas exactas y completas* para completar una tarea |                                                            *Reciben pautas generales* que definen el modelo junto con los datos                                                             |
|                                                                      |                                              *Los datos deben contener la información faltante necesaria* para que el modelo complete la tarea                                              |
|                                                                      | Un algoritmo de ML puede realizar su tarea *cuando el modelo se haya ajustado con respecto a los datos* (**Ajustamos el modelo a los datos - el modelo debe ser entrenado con los datos** ) |

## Ejemplo de aplicación

### Predecir el precio de una casa

- Basado en: *tamaño de la casa, tamaño del jardin y número de habitaciones*
- Con los algoritmos clásicos se haría con una fórmula exacta predeterminada.
- Sin embargo, **en la práctica esta fórmula usualmente no se conoce**

![[Screenshot 2025-07-24 at 8.59.54 PM.png]]

**USANDO UN MODELO DE MACHINE LEARNING**
- El algoritmo de ML definiría un modelo que puede ser la fórmula incompleta (*creada a partir de nuestro conocimiento limitado*)
- El modelo se entrena dandole **datos de ejemplo** sobre los precios de las viviendas
- Al hacerlo, **combinamos un modelo con algunos datos**

![[Screenshot 2025-07-24 at 9.02.16 PM.png]]


# En resumen

![[Screenshot 2025-07-24 at 9.06.53 PM.png]]

- Un modelo ML **se usa cuando tenemos información incompleta o información que es demasiado compleja para codificarse a mano**
- **Se da la información que tenemos disponible** a nuestro modelo y **dejamos que este aprenda la información faltante que necesita por sí mismo**
- Luego **usará técnicas estadísticas** para **extraer el conocimiento faltante** directamente de los datos

# Categorías del Machine Learning

## Aprendizaje Supervisado

![[Screenshot 2025-07-24 at 9.15.33 PM.png]]

![[Screenshot 2025-07-24 at 9.15.33 PM 1.png]]
- Queremos que un modelo prediga la **etiqueta (label)** de los datos en función de sus **características (features)**
- Para aprender el **mapeo entre features y labels**, el modelo debe **ajustarse (fitted) a ejemplos dados de features con sus labels relacionados**
	- "Se entrena en un Dataset Etiquetado"

### Labels Predecibles

![[Screenshot 2025-07-24 at 9.24.39 PM.png]]
- Pueden ser **números o categorías**
- Podemos predecir el precio de una casa, siendo un número lo que queremos predecir. En este caso, hablaríamos de un **Modelo de Regresión**

![[Screenshot 2025-07-24 at 9.29.50 PM.png|450]]

- De lo contrario, podríamos definir un modelo para predecir una categoría como `gato` o `no gato` basándose en **features dados**. En este caso, hablamos de un **Modelo de Clasificación**

![[Screenshot 2025-07-24 at 9.33.31 PM.png|450]]


## Aprendizaje No Supervisado

![[Screenshot 2025-07-24 at 9.35.37 PM.png]]

- Definimos un modelo que **revele estructuras en algunos datos** que *se describen solo por sus features* pero **sin labels**
- Estos modelos pueden ayudar a responder preguntas como:

![[Screenshot 2025-07-24 at 9.36.48 PM.png|450]]

- Puede buscar diferentes tipos de estructuras subyacentes en los datos, como:

**GRUPOS ENTRE LOS DATOS**
![[Screenshot 2025-07-24 at 9.39.59 PM.png|600]]
- *Clustering Model (Modelo de Agrupación*)
- Un ejemplo sería, un modelo que **segmenta a los clientes** de una empresa **en función de sus perfiles**


**REDUCCIÓN DE LA DIMENSION** 
![[Screenshot 2025-07-24 at 9.42.45 PM.png|600]]
- *Dimension Reduction Modelo (Modelo de Reducción de la Dimensión)*
- Si tenemos un modelo que **transforma los datos y los representa con un número menor de features**
- Un ejemplo sería un modelo que **resume las múltiples características técnicas de autos en unos pocos indicadores principales**
