

En esta guía iniciamos el desarrollo del primer módulo del curso, en el cual vamos a familiarizarnos con las etapas del ciclo de construcción de un sistema de aprendizaje automático. 

Hemos dividido el módulo en **tres unidades**, en esta guía abordamos la primera unidad, que tiene que ver directamente con los conceptos *introductorios del curso.* 

Revisaremos:

1. Los **conceptos básicos** sobre aprendizaje automático
2. Los **enfoques disponibles para la construcción** de este tipo de sistemas
3. Las **etapas básicas del proceso de entrenamiento** de un sistema que aprende.

---
# Objetivos
Analizar el ciclo de construcción de un sistema que aprende, a través del estudio de algunos conceptos básicos y de las etapas que lo componen, para comprender el proceso como un todo.
