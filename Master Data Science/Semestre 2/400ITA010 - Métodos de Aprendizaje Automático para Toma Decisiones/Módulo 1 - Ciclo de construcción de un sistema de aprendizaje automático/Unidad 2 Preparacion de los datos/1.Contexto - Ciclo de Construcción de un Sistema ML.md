## Pasos de preparación para un Sistema Supervisado


### La Preparación de Datos

> **Objetivo:**  
> *Eliminar del conjunto aquellas características que pueden restar desempeño o impedir el aprendizaje.*

Podemos ver las diferentes etapas:
1. **Conocimiento de los Datos**  
2. **Preparación**  
3. **Modelado**

---
### Etapa 1: Entendimiento de los datos

> En esta fase exploramos el **“qué”** y el **“cómo”** de nuestro dataset antes de transformarlo.

>**REGISTROS**: Filas
>**ATRIBUTOS**: Columnas

Como mínimo debemos conocer:
1. Cuantos registros hay
2. Cuantos atributos tiene cada registro
3. De que tipo son los atributos

Además:
1. Obtener una medida de centralidad para cada atributo
2. Obtener una medida de dispersión o desviación para los atributos que esto tenga sentido
3. Calcular la matriz de correlación de los atributos de entrada para identificar los atributos redundantes

**Como paso previo al preprocesamiento de los datos, debemos**
1. Detectar si hay datos faltantes (determinar en qué columna y cuantos datos faltan en un mismo registro)
2. Detectar si hay datos atípicos
3. Detectar si hay desbalance entre clases

> **Notar** que en esta etapa no hacemos ninguna modificación sobre los datos, solo estamos conociéndolos a fondo para saber con qué material contamos para trabajar

---

#### 1.1. Carga inicial y estructura
- **Dataset**: `adult.data` (UCI Adult)  
- **Dimensiones**: 32 561 registros × 15 columnas  
- **Target**: `income` (≤50K / >50K)  
- **Librerías base**:

```python
import pandas as pd
import numpy as np
import seaborn as sns
import matplotlib.pyplot as plt

url = 'https://archive.ics.uci.edu/dataset/2/adult
'

data = pd.read_csv(url, header=None, na_values=" ?")

data.columns = ['Age' 'Workclass', 'Fnlwgt', 'Education', 'Education-num', 'Marital-status', 'Occupation', 'Relationship', 'Race', 'Sex', 'Capital-gain', 'Capital-loss', 'Hpw', 'Country', 'C']

```

>`C`: es nuestro atributo a predecir (ingresos anuales USD)
> 	**C:** <=50k


**Cual es el numero de registro y atributos?**
```python
shape = data.shape
shape
```
**Cual es el tipo de los atributos?**
```python
data.dtypes
```
**Medidas de centralidad y Desviación para atributos numéricos (Estadísticas descriptivas)**
```python
data.describe()
```

**Diagrama de cajas y bigotes para atributos numéricos**
*Permite identificar la existencia de datos atípicos*

**Medida de centralidad para atributos categóricos**

**Correlación de los atributos de entrada numéricos**
*Permite detectar si hay atributos redundantes (correlación mayor a 0.85 o menor -0.85)*


**Cual es el máximo de datos faltantes en un mismo registro?**
*Si hay registros a los que les faltan muchos valores, es mejor eliminarlos*
```python
max(data.isnull().sum(axis=1))
```

**Cuantos datos faltantes hay por cada atributo**
```python
data.isunull().sum()
```

**Cuantos registros hay por cada clase, es decir, por cada valor del atributo de salida?**
```python
print(data['C'].value_counts())
```

### Etapa 2: Preparación de los datos
De acuerdo a lo observado en la etapa 1, se define una secuencia de actividades que modifican los datos para eliminar las situaciones que puedan ser causa de fallo o deficiencia en el proceso de aprendizaje:
1. Completar los datos faltantes utilizando **la media para atributos numéricos** y **la moda para atributos categóricos**
2. Convertir los atributos categóricos a escala numérica
3. Normalizar los valores de algunos atributos
4. Balancear las clases eliminando registros de la clase mayoritaria


### Etapa 3: Modelado
En esta etapa se van a utilizar los datos para realizar aprendizaje del atributo `C` 
Es decir, se va a predecir si una persona tiene ingresos superiores o inferiores a 50k dolares. Las actividades a realizar son:
1. Dividir el conjunto de datos en conjuntos de **entrenamiento (train)** y **prueba (test)**
2. Realizar el entrenamiento del modelo de *Regresion Logistica* usando el conjunto de entrenamiento
3. Aplicar el modelo construido a los datos del conjunto de test
4. Calculo de una métrica de desempeño para evaluar la calidad del modelo en sus predicciones sobre el conjunto de test
