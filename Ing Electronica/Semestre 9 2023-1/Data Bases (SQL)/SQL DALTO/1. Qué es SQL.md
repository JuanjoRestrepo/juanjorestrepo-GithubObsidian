Structured Query Language ( Lenguaje de Consultas Estructuado)

- Es un lenguaje de programación para **almacenar y procesar información** en una base de datos relacional. 

- **Una base de datos relacional almacena información en forma tabular, con filas y columnas** que **representan diferentes atributos de datos y las diversas relaciones entre los valores de datos.**

## ¿Qué podemos hacer con SQL?

- Crear ,modificar, eliminar y administrar Bases de Datos
![[utilidadesSQL.png|800]]

- Realizar consultas a una base de datos para obtener información específica.
	- Como encontrar clientes en un rango de edad
	![[BuscarRangoEdad.png|800]]
	
	O hasta productos con un precio específico
	
	![[productosPrecioEspecifico.png|800]]
	
	También podemos modificar los datos
![[ModificarDatos.png|800]]
	
	También se pueden agregar Restricciones/Reglas de integridad, es decir, **condiciones** para asegurarnos que los datos cumplan con ciertos criterios
	
![[ReglasRestricciones.png|800]]
	
	Por ejemplo, que un campo en una tabla no puede estar vacío, o solo debe contener un valor único. Esto asegura que los datos de una tabla sean concisos y consistentes

- Tambien se pueden General Informes, Análisis de Datos
- Incluso para garantizar **usuarios y permisos** esto para ciertas personas solo puedan acceder a ciertos datos
- **Copias de Seguridad**
- Limpieza de datos
