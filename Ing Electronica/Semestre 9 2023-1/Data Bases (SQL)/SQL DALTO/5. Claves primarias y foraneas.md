### **Cada tabla tiene su clave primaria**

**¿Cómo hace la tabla turnos médicos para identificar a cada turno?** 
- Por el id del turno

**¿Cómo hace la tabla usuarios para identificar a cada usuario?**
- Por el id del usuario

Ahora, las claves foraneas son claves que hacen referencia a una clave que pertenece a otra tabla. Dicha clave puede ser una clave primaria de aquella tabla. Por ejemplo:

### **Foreign Key:** 
Es una clave que nos permite hacer referencia a una clave primaria de otra tabla.

Debe ser un identificador ***único e inmutable***, es decir, que ***nunca puede cambiar, una vez sea asignada***

En resumen
- No puede ser nula
- Tiene que ser un identificador único
- Tiene que ser inmutable
