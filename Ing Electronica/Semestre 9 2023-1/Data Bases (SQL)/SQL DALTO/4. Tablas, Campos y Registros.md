# 2. Tipos de Variables de los Campos de Datos
---
![[Pasted image 20240112171422.png]]

1. **INTEGER:** Datos de tipo entero
2. **TEXT:** Datos tipo texto o string
3. **BLOB:** Datos de tipo Binario como imágenes, videos, etc.
4. **REAL:** Datos de tipo float, porcentajes, números con coma. Menos capacidad para almacenar valores grandes, pero mas rápido
5. **NUMERIC:** Datos de tipo Long Float, valores MUY GRANDES. Mayor precision matemática.

*NOTA: SQL tiene flexibilidad de almacenar valores de cualquier tipo en los diferentes campos, es decir, puedo almacenar texto en campos de tipo entero y vice versa. PERO ES MALA PRACTICA*


# 3. Primary Key ID Usuarios
---
Sabemos que cada registro debe ser único, es decir, que cada usuario deberá tener un ID único e irrepetible

Para garantizar la unicidad de los IDs, en SQLite Browser debemos activar la opción de Primary Key (PK) y AutoIncrement (AI) para que la key se incremente a medida que se agreguen nuevos registros

```SQLite
CREATE TABLE "usuarios" (
	"id_usuario"	INTEGER,
	"nombre"	TEXT,
	"apellido"	TEXT,
	"edad"	INTEGER,
	PRIMARY KEY("id_usuario" AUTOINCREMENT)
);
```

Las consultas se separan con punto y coma.

```SQLite
// Consulta 1
INSERT INTO usuarios (nombre, apellido, edad)
VALUES ("Lucas", "Dalto", 21); 

// Consulta 2
SELECT * FROM usuarios
```
