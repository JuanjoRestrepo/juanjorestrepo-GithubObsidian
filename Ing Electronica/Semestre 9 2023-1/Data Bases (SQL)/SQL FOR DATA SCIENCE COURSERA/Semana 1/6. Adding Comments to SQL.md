
# Why Add Comments
- Help you remember **what** you were doing and **why**
- Mute the expression of code (Commenting Out Code)
- Troubleshoot query issues systematically

## Ways of Adding Comments

## Single Line (``- -``)
```SQLite
SELECT shoe_id
- -,brand_id
,shoe_name
from shoes
```
## Section (``/* */``)
```SQLite
SELECT shoe_id
/* ,brand_id
,shoe_name
*/
from shoes
```
