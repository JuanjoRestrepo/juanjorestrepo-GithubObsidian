# What are Aggregate Functions?
_________________________________
- Used to summarize data.
- Finding the highest and lowest values.
- Finding the total number of rows.
- Finding the average value.

## Aggregate Functions

|**Function**|**Description**|
|---|---|
|AVG()|Averages a column of values|
|COUNT()|Counts the number of values|
|MIN()|Finds the minimum value|
|MAX()|Finds the maximum value|
|SUM()|Sums the column value|

## 1. AVERAGE Function
__________________________________
Rows containing NULL values are ignored by the **AVERAGE** function

```SQL
SELECT AVG(UnitPrice) AS avg_price
FROM products
```

## 2. COUNT Function
__________________________________
1. COUNT(`*`) : Counts all the rows in a table containing values or NULL values

```SQL
SELECT COUNT(*) AS
total_numbers
FROM Customers;
```

2. Count(column): Counts all the rows in a specific column ignoring NULL values

```SQL
SELECT COUNT(CustomerID) AS
total_customers
FROM Customers
```

## 3. MAX and MIN Functions
__________________________________
NULL values are ignored by the MIN and MAX functions.

```SQL
SELECT MAX(UnitPrice) AS max_prod_price
FROM Products
```

```SQL
SELECT MAX(UnitPrice) AS max_prod_price, MIN(UnitPrice) AS min_prod_price
FROM Products
```

## 4.  SUM Aggregate Function
__________________________________
```SQL
SELECT SUM(UnitPrice) AS total_prod_price
FROM Products
```

```SQL
SELECT SUM(UnitPrice*UnitsInStock) AS total_price
FROM Products
WHERE SupplierID = 23;
```

# Using DISTINCT on Aggreate Functions
__________________________________
- If **DISTINCT** is not specified, **ALL** is assumed
- Cannot use **DISTINCT** on COUNT(`*`)
- No value to use with MIN and MAX functions

```SQL
SELECT COUNT(DISTINCT CustomerID)
FROM Customers
```
