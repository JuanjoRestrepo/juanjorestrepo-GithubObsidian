# Multiplication Example
_________________________________
Total units on order multiplied by the unit price to calculate the total order cost.

What we have to do, is treat this just as we would any other column that we're retrieving.

Here we have the different columns that we're interested in.
- Product IDs
- Units on the order.
- Unit Price

We use an alias ***AS*** for what we want this new column to be named and this is going to be the ***total order cost***.

```SQL
SELECT
,UnitsOnOrder
,UnitPrice
,UnitsOnOrder * UnitPrice AS Total_Order_Cost
FROM Products;
```

# Combining Math Operations
_________________________________
Unit price, minus my discount, divided by the quantity

```SQL
SELECT
,Quantity
,UnitPrice
,Discount
,(UnitPrice - Discount)/Quantity AS Total_Cost
FROM OrderDetails;
```
