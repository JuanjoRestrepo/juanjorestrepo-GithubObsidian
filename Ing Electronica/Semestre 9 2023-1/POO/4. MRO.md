# MRO (Método Resolución de Orden)
---
Es el orden en el que python busca metodos y atributos en una clase

Si una clase tiene una larga lista de herencia, tenemos que entender qué se va a ejecutar primero.

```Python
class A:
    def hablar(self):
        print("Hola desde A")


class B:
    def hablar(self):
        print("Hola desde B")

  
class C(A):
    def hablar(self):
        print("Hola desde C")

  
class D(B,C):
    def hablar(self):
        print("Hola desde D")

d = D()
d.hablar()
```
En este ejemplo, dado que la clase D tiene un método definido, se da prioridad a este, es decir, se prioriza lo que contiene la clase D, en lugar de las herencias que provienen de las otras clases.

Si la clase D no tiene nada definido
```Python
class D(B,C):
    pass
```
Lo que tendremos de salida sera lo que se hereda de la clase B

```Python
# OUTPUT
# Hola desde B
```

Si no tuviese herencia de B, seguiria C porque no habria ningun metodo de la clase B para heredar
```Python
class B:
    pass

class C(A):
    def hablar(self):
        print("Hola desde C")

class D(B,C):
    pass
# OUTPUT
# Hola desde C
```

Y si no encuentra el método en ninguna de las clases, B o C, busca la que si tenga algún método
```Python
class A:
    def hablar(self):
        print("Hola desde A")

class B:
    pass

  
class C(A):
    pass

  
class D(B,C):
    pass

d = D()

d.hablar()
# OUTPUT
# Hola desde A
```

Para ver el orden de ejecución de las clases podemos usar el método `mro()` de python

```Python
print(D.mro())
[<class '__main__.D'>, 
 <class '__main__.B'>, 
 <class '__main__.C'>, 
 <class '__main__.A'>, <class 'object'>]
```

Para llamar a una clase especifica, creo primero el objeto, luego llamo la clase que quiero llamar y le paso el objeto creado

```Python
d = D()
B.hablar(d)
#️ OUTPUT
# Hola desde B
```
