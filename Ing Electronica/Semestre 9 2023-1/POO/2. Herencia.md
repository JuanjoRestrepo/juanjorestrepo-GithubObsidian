# Herencia
---
Permite a la clase hija acceder a todos lo métodos y tener las propiedades de la clase padre.

Si utilizamos como ejemplo una receta de galletas

![[Pasted image 20240122184447.png]]

Tenemos una clase padre la cual es 'Galletita'

Si queremos hacer otros tipos de galletas como de 'Avena y Pasas' o 'Chocolate' necesitamos la receta base de la Galleta y agregar los ingredientes adicionales a cada galleta.

En términos generales, las otras galletas heredan la receta base de una Galleta y terminan teniendo ingredientes adicionales, es decir, atributos adicionales.

La clase padre es la que hereda y la hija es la que heredo los atributos.

## Ejemplo:
---
Vamos crear un ejemplo para crear empleados.

1. Creamos la clase persona
2. Creamos la clase Empleado, la cual sera la que va a heredar los atributos 'nombre', 'edad' y 'nacionalidad'.
3. 
```Python
class Persona:

    def __init__(self, nombre, edad, nacionalidad):

        self.nacionalidad = nacionalidad
  
class Empleado(Persona) #Se pone Persona como parametro pues es la clase de la que Empleado va a tomar los atributos correspondientes
	pass
```

Si agregamos un método llamado 'hablar'
```Python
class Persona:

    def __init__(self, nombre, edad, nacionalidad):
        self.nombre = nombre
        self.edad = edad
        self.nacionalidad = nacionalidad

    def hablar(self):
	    print("Hola hola")

class Empleado(Persona):
    pass

roberto = Empleado("Roberto", 43, "argentino")
roberto.hablar()

# OUTPUT
# Hola hola
```

Ahora si definimos atributos para construir la clase 'Empleado' debemos hacerlo de la siguiente forma:

```Python
class Empleado(Persona):
    def __init__(self, nombre, edad, nacionalidad, trabajo, salario):
        super().__init__(nombre, edad, nacionalidad)
        self.trabajo = trabajo
        self.salario = salario

roberto = Empleado("Roberto", 43, "argentino", "Programador", 50000)


print(roberto.trabajo)
print(roberto.salario)
# OUTPUT
# Programador
# 50000
```

Como la clase Empleado esta heredando de la clase Persona el *'nombre', 'edad' y 'nacionalidad'*, debemos pasarle los atributos al `__init__`. 

Luego escribimos `super()` porque es la forma en la que le decimos que atributos de la clase padre va a heredar, para luego declarar los atributos propios que tendrá la clase hijo, que en este caso son: *'trabajo' y 'salario'*

Finalmente, para crear el objeto con todos los atributos, lo hacemos por medio de la clase Empleado pasándole todos los atributos: *'nombre', 'edad', 'nacionalidad', 'trabajo' y 'salario'*.

# Herencia Jerárquica
---
Tipo de herencia en la que hay una clase de la que dependen todas las demás

![[Pasted image 20240122191403.png]]

En este caso, la clase padre es Persona y de esta dependen las clases hijas Jefe, Estudiante y Persona. Todas esas tres, tienen como base la clase Persona

```Python
class Persona:
    def __init__(self, nombre, edad, nacionalidad):
        self.nombre = nombre
        self.edad = edad
        self.nacionalidad = nacionalidad

    def hablar(self):
        print("Hola hola")

  
class Empleado(Persona):
    def __init__(self, nombre, edad, nacionalidad, trabajo, salario):
        super().__init__(nombre, edad, nacionalidad)
        self.trabajo = trabajo
        self.salario = salario

  
class Estudiante(Persona):
    def __init__(self, nombre, edad, nacionalidad, notas, universidad):
		# Super Constructor para la Herencia
        super().__init__(nombre, edad, nacionalidad)
        self.notas = notas
        self.universidad = universidad
```
