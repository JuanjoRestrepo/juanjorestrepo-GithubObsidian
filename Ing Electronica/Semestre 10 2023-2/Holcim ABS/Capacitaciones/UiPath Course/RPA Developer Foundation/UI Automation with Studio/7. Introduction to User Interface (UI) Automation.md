## ¿Qué es la automatización de la interfaz de usuario (UI)?

La interfaz de usuario o la automatización de la interfaz gráfica de usuario (UI Automation) se refiere al proceso de interacción con elementos gráficos dentro de las aplicaciones mediante la simulación de controles de mouse y teclado.

Así como los usuarios humanos usan aplicaciones a través de actividades como hacer clic, escribir o seleccionar texto, los desarrolladores de RPA pueden configurar UiPath Robots en UiPath Studio para realizar las mismas tareas más rápido y sin errores.

![[Pasted image 20230714150259.png|500]]

A través de una integración profunda entre UiPath y todos los principales marcos de GUI desde Win32 hasta WPF, HTML y Java, los desarrolladores de RPA pueden automatizar fácilmente todo tipo de aplicaciones de escritorio.
  
UiPath reconoce los objetos gráficos por sus propios atributos específicos de la plataforma y proporciona una API de automatización de GUI unificada que funciona de la misma manera en todas partes.

## ¿Cómo Se debería ver la automatización de la interfaz de usuario?

Teniendo en cuenta que los robots realizarán acciones en las interfaces de usuario (UI) de la aplicación tal como lo harían los humanos, los desarrolladores de RPA deberán configurar cada acción en una ruta lógica y secuencial.

Echemos un vistazo a este ejemplo.

1. **Escenario: obtenga el número de transacción de la aplicación 'Double UI'.**
	Consideremos que nuestro objetivo es automatizar una tarea simple que ingresa datos en la aplicación Double UI, hace clic en el botón Aceptar y obtiene el número de transacción.
	
	Para hacer esto, debemos considerar el estado de la aplicación. Queremos comenzar desde cómo un usuario humano ejecutaría los pasos y luego dividir la tarea en cada paso. Como primer paso, veamos el ***Camino Humano (Human Path)***.

	1. Paso 1 - El Camino Humano: 
			![[Pasted image 20230714152050.png]]
			
		Pasos tomados por el usuario humano:

		- **Abra** la aplicación de demostración de interfaz de usuario.
		- **Escriba** el valor en el campo **'Cash In'**.
		- Haga **clic** en Aceptar.
		- **Copie** el número de transacción.
		- **Guarde** el número de transacción para futuras referencias.
		Los pasos del usuario humano son claros. El siguiente paso es traducir estos pasos en actividades de UiPath y configurarlos en UiPath Studio, para que el robot pueda realizar la misma tarea.

	2. Paso 2 - El Camino Robot: 

	![[Pasted image 20230714185202.png]]

	Estado inicial: la aplicación de IU doble está abierta en la pantalla de depósito.
	
	Pasos a realizar por el robot:
	
	- Use **Application Browser Activity** identifica la aplicación de demostración de la interfaz de usuario y abre la aplicación con la configuración necesaria.
	- **Escribir en** actividad identifica el campo **'Cash In'** e ingresa el valor requerido.
	- Una actividad de **clic** identifica el botón Aceptar y ejecuta la acción de clic.
	- Una actividad de **Get Text** identifica el valor del número de transacción, lo obtiene y lo almacena en una variable.
	
	Bastante simple, ¿verdad?


## Recapitulemos

- La automatización de la interfaz de usuario es el proceso de automatización de las interfaces de usuario de la aplicación mediante la simulación de acciones de entrada y salida humanas a través de actividades específicas de la interfaz de usuario.
- El primer paso para automatizar las interfaces de usuario es comprender la secuencia lógica de pasos que seguiría un usuario humano. El segundo paso consiste en traducir estos pasos en actividades de UiPath Studio y configurarlas.
- La complejidad de la interfaz de usuario o de la aplicación es irrelevante. Todas las aplicaciones de escritorio se pueden automatizar mediante el uso de actividades personalizadas o universales.
