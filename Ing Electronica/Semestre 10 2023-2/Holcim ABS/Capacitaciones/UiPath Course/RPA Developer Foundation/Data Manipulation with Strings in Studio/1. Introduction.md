# ¿Qué es Data Manipulation?

La manipulación de datos es el proceso de modificar, estructurar, formatear o clasificar datos para facilitar su uso y aumentar sus capacidades de gestión.

## ¿Cuáles son algunos escenarios comerciales en los que utilizaré la manipulación de datos?
- Los propietarios de sitios web emplean con frecuencia métodos de manipulación de datos para extraer y ver información específica de los registros de su servidor web. Eso permite ver sus páginas más populares, así como sus fuentes de tráfico.
- Considerar el proceso de consulta de bases de datos públicas financieras o jurídicas. La manipulación de datos proporciona los medios para que los analistas de crédito extraigan solo los datos relevantes y los utilicen en otros documentos o los correlacionen con información de otras fuentes.


## Objetos, Métodos y Propiedades
Para comprender la manipulación de datos, debemos comprender qué son los objetos, los métodos y las propiedades.

- Los objetos son los bloques de construcción fundamentales de Visual Basic; casi todo lo que hace en Visual Basic implica modificar objetos. Una variable contiene un objeto. Por ejemplo, si Username = "John Doe", la variable Username contiene el objeto String "John Doe".
- Las propiedades son atributos de un objeto o un aspecto de su comportamiento. Por ejemplo, la clase de cadena contiene dos propiedades: Chars (devuelve el objeto Char en una posición específica en el objeto String actual) y Longitud (devuelve el número de caracteres en el objeto String actual). Por ejemplo, según el ejemplo anterior, Username.Length devuelve 8.
- Los métodos son acciones que un objeto puede realizar. Los métodos a menudo tienen parámetros que califican cómo se realiza la acción. Por ejemplo, Username.Replace("John","Jack") devuelve "Jack Doe".
