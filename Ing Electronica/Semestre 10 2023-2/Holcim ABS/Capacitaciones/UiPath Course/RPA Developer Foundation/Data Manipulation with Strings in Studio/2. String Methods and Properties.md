## ¿Qué son?
Las cadenas son el tipo de datos correspondiente al texto. Es difícil imaginar un escenario de automatización que no implique el uso de cadenas.

Cada vez que se necesita capturar, procesar, enviar entre aplicaciones o mostrar un texto, las cadenas son útiles (a menos que los datos estén estructurados, como una tabla).

## ¿Cuáles son algunos escenarios comerciales en los que probablemente encontrará cadenas?
- Obtener el estado de una operación.
- Extraer la pieza relevante de una porción de texto más grande.
- Mostrar información al usuario humano.

## String Methods

1. **String.Concat**
	- Concatenates the string representations of two specified objects.  
	- Expression: String.Concat (VarName1, VarName2)
	- Output datatype: String

2. **Contains**
	- Checks whether a specified substring occurs within a string. Returns ***true or false.***  
	- Expression: VarName.Contains (“text”)
	- Output datatype: Boolean 

3. **String.Format**
  - Converts the value of objects to strings (and inserts them into another text).  
  - Expression: String.Format(“{0} is {1}”, VarName1, VarName2)
  - Output datatype: String

4.  **IndexOf**
	- Returns the zero-based index of the first occurrence of a specified Unicode character or string within this instance.  
	- Expression: VarName1.IndexOf(“a”)
	- Output datatype: Int32
	
5. LastIndexOf
	- Reports the zero-based index position of the last occurrence of a specified Unicode character or string within this instance.
	- Expression: VarName1.LastIndexOf("author")
	- Output datatype: Int32

6. **String.Join**
	- Concatenates the elements in a collection and displays them as String.  
	- Expression: String.Join(“|”, CollVarName1)
	- Output datatype: String

7. **Replace** 
	- Reemplaza todas las apariciones de una subcadena en una cadena.
	- Expresión: VarName.Replace ("original", "reemplazado")
	- Tipo de datos de salida: Cadena
	
8. **Split**
	- Splits a string into substrings using a given separator.  
	- Expression: VarName.Split(“|“c)(index)
	- Output datatype: Array of String
9. **Substring**
	- Extrae una subcadena de una cadena usando el índice inicial y la longitud.
	- Expresión: VarName1.Substring(startIndex, longitud)
	- Tipo de datos de salida: Cadena
