##   ¿Qué es?

La expresión regular (REGEX o regexp) es un patrón de búsqueda específico que se puede usar para hacer coincidir, ubicar y administrar texto fácilmente. Sin embargo, la creación de expresiones RegEx puede ser un desafío.

UiPath Studio contiene un constructor RegEx que simplifica la creación de expresiones regulares.

Los usos típicos de RegEx incluyen:

- Input validation.
- String parsing.
- Data scraping.
- String manipulation.

## ¿Cuáles son algunos escenarios comerciales en los que usaré RegEx?
Recuperar fragmentos de texto que siguen un determinado patrón, por ejemplo:

- Extraer números de teléfono que comienzan con un dígito determinado.
- Recopilar todos los nombres de las calles de un texto masivo, incluso si no siguen un patrón específico: algunos de ellos contienen "Calle", otros "Rd.", etc.
- Llevaría mucho más tiempo construir la misma expresión utilizando los métodos de cadena regulares; por ejemplo, RegEx tiene una expresión predefinida para ubicar todas las URL en una cadena.
