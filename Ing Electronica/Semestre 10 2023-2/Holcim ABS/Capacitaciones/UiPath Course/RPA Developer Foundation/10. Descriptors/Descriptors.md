
# Advanced Options of Selection Window

El objetivo de Modern Design es crear una automatización de interfaz de usuario más confiable que deba ajustarse y corregirse con menos frecuencia en producción.

La ventana de opciones de selección proporciona opciones avanzadas, como Forzar visibilidad, Destino de texto dinámico, Destino de texto nativo y modo de selección de imagen.

Puede usar estas funcionalidades y configurarlas según la aplicación que esté automatizando o el tipo de elemento de la interfaz de usuario que esté seleccionando.

Estas opciones ayudan a configurar el descriptor muy confiable mientras indican el objetivo en sí.

Aprendamos en detalle sobre estas siguientes opciones avanzadas:

1. Enforce Visibility
2. Dynamic Text Target
3. Native Text Target
4. Image Selection mode
