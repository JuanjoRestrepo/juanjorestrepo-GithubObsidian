
## Tipos de registros en UiPath

Al principio, mencionamos que el enfoque de esta lección es configurar un registro útil al desarrollar un proyecto. Para un poco de contexto, primero comencemos revisando los principales tipos de registros generados por UiPath Platform:

- Registros de estudio.
- Registros de configuración.
- Registros de diagnóstico del orquestador.
- Registros de robots.

## Robot logs
------------------------------------------
Durante la ejecución del proceso, el Robot genera un mensaje (Registro) para cada paso del camino. Estos se recopilan y almacenan en un archivo de registro. La operación general de recopilación y almacenamiento de registros se denomina Registro. Hay dos tipos de registros de robot:

- **Robot execution logs:** son mensajes generados por la ejecución de un proceso y normalmente contienen información relacionada con su comportamiento y mensajes definidos por el usuario.
- **Robot diagnostic logs:** brindan información relacionada con el propio Robot y su contexto.

### ***¿Por qué se centra la atención en los registros de ejecución de robots?*** 

Bueno, **los registros de ejecución de robots** se pueden usar para supervisar, diagnosticar y depurar procesos en producción, recopilar datos de rendimiento de procesos o incluso realizar un seguimiento de los resultados comerciales, como el valor total de las transacciones procesadas. Pueden ser registros predeterminados o registros definidos por el usuario.

![[Pasted image 20230723155420.png|300]]


Los **registros predeterminados**, **Default Logs** se generan automáticamente cuando ocurren ciertos eventos. Los eventos registrados por esta categoría son:

- **Inicio de ejecución/Execution Start** se genera cada vez que se inicia un proceso (Nivel = Información).
- **El fin de ejecución/Execution End** se genera cada vez que se finaliza un proceso (Nivel = Información).
- **Inicio de transacción/Transaction Start** se genera cada vez que se inicia una transacción dentro de un proceso (Nivel = Información).
- **Fin de transacción/Transaction End** se genera cada vez que se finaliza una transacción dentro de un proceso (Nivel = Información).
- **Registro de errores/Error Log** se genera cada vez que la ejecución encuentra un error y se detiene (Nivel = Error).
- Se genera un **registro de depuración/Debugging Log** si la Configuración de registro del robot se establece en Detallado y contiene nombres de actividades, tipos, valores de variables, argumentos, etc. (Nivel = Rastreo).


## Registro de niveles en UiPath

Cada registro tiene un nivel de registro que se refiere a qué tan detallado es el mensaje generado. En otras palabras, los niveles de registro le permiten clasificar los mensajes de registro por gravedad o por la importancia de un mensaje de registro relacionado con la ejecución de un proceso. Los niveles de registro se utilizan en Orchestrator para filtrar los registros por debajo de un nivel específico.

## Registros de nivel detallados

El nivel detallado registra un mensaje para las actividades: inicio y finalización, además de los valores de las variables y los argumentos que se utilizan. El nivel detallado se utiliza para la depuración.

De forma predeterminada, el nivel detallado incluye:

- **Entrada de registro de ejecución iniciada** generada cada vez que se inicia un proceso.

- **Entrada de registro de finalización de ejecución** generada cada vez que se finaliza un proceso.
- **Entrada de registro de transacción iniciada** generada cada vez que el robot obtiene un elemento de transacción de Orchestrator.

- **Entrada de registro de transacción finalizada** generada cada vez que el robot establece el estado de la transacción en Éxito o Error.

- **Entrada de registro de información de actividad** generada cada vez que se inicia, falla o finaliza una actividad dentro de un flujo de trabajo.

De forma predeterminada, ejecutar un proceso en Studio registrará registros de nivel de seguimiento. Para configurar el registro a nivel detallado localmente, acceda a la cinta Depurar, habilite la opción Registrar actividades y ejecute el proceso en modo de depuración.
