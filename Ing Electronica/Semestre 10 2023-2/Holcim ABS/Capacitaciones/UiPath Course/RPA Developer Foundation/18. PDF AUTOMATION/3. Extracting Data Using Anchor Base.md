
La actividad Base de anclaje se utiliza para identificar un elemento con un selector inestable en relación con un elemento con uno estable. Por ejemplo, podemos querer obtener un valor de una factura en PDF. El elemento de IU de valor tiene un selector inestable mientras que el elemento de etiqueta es estable.

Esta actividad se compone de dos bloques, ya que realiza una acción en relación con otro elemento fijo o ancla:

- El bloque de anclaje: solo admite las actividades Buscar elemento o Buscar imagen. Identifica el elemento de la interfaz de usuario que se utilizará como ancla.
- El bloque de acción: admite actividades de interacción de la interfaz de usuario para el elemento de destino. En la mayoría de los casos, para PDF, usaremos la actividad Obtener texto para recuperar el texto en el elemento de la interfaz de usuario de destino.
