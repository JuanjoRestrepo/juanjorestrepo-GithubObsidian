# ¿Qué es el repositorio de objetos?

El repositorio de objetos permite crear y reutilizar taxonomías de interfaz de usuario dentro y entre proyectos de automatización. Con Object Repository, puede crear una API de interfaz de usuario para su aplicación y compartirla con su equipo en cuestión de minutos.

## Conceptos clave

Tomemos un momento para centrarnos en los conceptos clave relacionados con el repositorio de objetos: descriptores de IU, aplicaciones, pantallas, elementos de IU y bibliotecas de IU.

![[Pasted image 20230721185318.png|400]]

### Descriptores de IU
Los descriptores de la interfaz de usuario se extraen directamente de una aplicación utilizando la grabadora Capture Elements o de actividades en el flujo de trabajo y se agregan a un esquema estructurado que los agrupa por aplicaciones, versiones de la aplicación, pantallas y elementos de la interfaz de usuario. Fuera de esta estructura de taxonomía, solo las pantallas y los elementos contienen información descriptiva. El resto se utilizan para agrupar y su función es garantizar actualizaciones entre versiones de una aplicación.

### Aplicaciones de interfaz de usuario
Una aplicación de interfaz de usuario es una aplicación dirigida que puede tener varias versiones y cada versión puede tener varias pantallas. Las aplicaciones versionadas se utilizan para agrupar pantallas y elementos de la interfaz de usuario. No contienen información de Descriptor.

### Pantallas
Las pantallas son ámbitos de la interfaz de usuario que se extraen de actividades dentro del flujo de trabajo o se generan en el momento de la captura de elementos. Una pantalla agrupa varios elementos de la interfaz de usuario que pertenecen a la misma pantalla.

### Elementos de la interfaz de usuario
Un elemento de la interfaz de usuario es la encapsulación de un descriptor de la interfaz de usuario, necesario para identificar el elemento en la pantalla, y los metadatos adicionales necesarios para describir el elemento.

### Bibliotecas de interfaz de usuario
Una biblioteca de interfaz de usuario es una encapsulación de elementos agrupados por aplicaciones, versiones de aplicaciones y pantallas. Los elementos que defina se pueden extraer como una biblioteca de interfaz de usuario y, después de publicarlos, se pueden instalar en otros proyectos como una dependencia.

# ¿Cómo se utiliza el repositorio de objetos?

#### **Creación, publicación y actualización de proyectos mediante bibliotecas de interfaz de usuario**

Para entender cómo hacer el mejor uso del repositorio de objetos en su equipo, consideremos un escenario de implementación. Su equipo tiene la tarea de desarrollar varios procesos utilizando UI Automation en la misma aplicación de destino. Se espera que la aplicación de destino se actualice en el futuro y su equipo necesita un método para actualizar rápidamente los proyectos cuando suceda.

Echemos un vistazo a los pasos clave que debe seguir:

### 1. Crear y publicar una biblioteca de interfaz de usuario

En este paso, captura todos los objetos de IU relevantes que identifican la aplicación, las pantallas y los elementos de IU en la aplicación de destino. Hay dos formas de hacer esto: puede comenzar desde un proyecto de biblioteca vacío y capturar los objetos o puede exportarlos desde un proyecto de tipo de proceso preexistente que usa actividades de IU modernas.

Una vez que haya extraído los elementos necesarios, puede ajustarlos para aumentar la confiabilidad y luego publicar la biblioteca de la interfaz de usuario localmente o en Orchestrator.

### 2. Importe y use la biblioteca de la interfaz de usuario

A continuación, su equipo puede importar la nueva biblioteca de interfaz de usuario en sus proyectos de tipo de proceso y desarrollar rápidamente la automatización de la interfaz de usuario utilizando los elementos del repositorio de objetos.

### 3. Actualice la biblioteca de la interfaz de usuario

En este punto, su equipo tiene varios procesos en producción desarrollados con la misma aplicación de destino y biblioteca de interfaz de usuario. Sin embargo, la aplicación de destino se actualizó y los descriptores deben actualizarse.

Para hacer esto fácilmente, puede abrir el proyecto de la biblioteca de la interfaz de usuario en Studio, editar los descriptores de la interfaz de usuario existentes para capturar los nuevos objetivos y publicar una nueva versión de la biblioteca.

### 4. Importe y actualice la biblioteca de la interfaz de usuario

Su equipo ahora puede actualizar la Biblioteca de UI en sus proyectos de tipo Proceso a la última versión. Los descriptores de IU en las actividades se actualizarán automáticamente.

Su equipo puede incluso actualizar varios proyectos al mismo tiempo utilizando la herramienta de actualización masiva de dependencias del proyecto desde la vista Backstage de Studio -> Herramientas.
