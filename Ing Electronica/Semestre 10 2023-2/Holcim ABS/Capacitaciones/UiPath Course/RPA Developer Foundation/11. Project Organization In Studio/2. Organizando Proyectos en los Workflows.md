
## Manejo de datos en proyectos con múltiples flujos de trabajo

Dividir un proyecto en flujos de trabajo más pequeños influye en cómo se manejan los datos. Dado que las variables solo funcionan dentro del mismo flujo de trabajo, tener más de un flujo de trabajo requiere argumentos.

Como probablemente sepa por el curso Variables, tipos de datos y flujo de control en Studio, los argumentos son muy similares a las variables: almacenan datos de forma dinámica, tienen los mismos tipos de datos y admiten los mismos métodos. La principal diferencia es la propiedad 'Dirección', que significa la dirección desde/hacia la cual se pasan los datos. La dirección puede ser Adentro, Afuera y Adentro/Afuera:


- **In:** si queremos pasar un valor para que se use solo dentro del flujo de trabajo invocado.
- **Out:** si queremos pasar un valor para que se use fuera del flujo de trabajo invocado, en el flujo de trabajo principal.
- **In/Out:** si queremos pasar un valor del flujo de trabajo principal al flujo de trabajo invocado, modifíquelo en el flujo de trabajo invocado y luego pase el nuevo valor al flujo de trabajo principal.

Considere un flujo de trabajo invocado que reste todos los impuestos de un salario bruto. Necesitarás al menos dos argumentos:

- Un argumento **'in'** asignado a la variable que contiene el salario bruto.
- Un argumento **'out'**  para pasar el valor del salario neto a una variable en el flujo de trabajo principal.


## Mejores prácticas sobre el uso de argumentos

**Denominación:** use la dirección como prefijo al nombrar argumentos. Por ejemplo:
	- in_ArgumentName1, out_ArgumentName2, io_ArgumentName3.

**Instrucciones:** Sea específico con las instrucciones de los argumentos. *Evite usar Entrada/Salida a menos que sea necesario.*

## Establecer la compatibilidad del proyecto

Para crear un nuevo proyecto en Studio, debe seleccionar la compatibilidad según el entorno en el que se ejecutará el proyecto:

- **Windows - Legacy:** utiliza .NET Framework 4.6.1. la compatibilidad utilizada en versiones anteriores a 2021.10. Esta es la opción por defecto.
- **Windows:** utiliza .NET 6 con soporte para Windows.
- **Multiplataforma:** utiliza .NET 6 con compatibilidad multiplataforma.


## Diseño de proyectos multiplataforma

Los proyectos multiplataforma le permiten crear automatizaciones que no requieren la interacción del usuario, incluidas las automatizaciones del navegador web con Chrome. Las automatizaciones multiplataforma se pueden ejecutar en sistemas operativos Windows y similares a Unix, como Linux y macOS.

Los entornos Linux le permiten ejecutar automatizaciones desatendidas y brindan una experiencia más rápida y una forma más fácil de ampliar su implementación. Cuando utilice entornos Linux, utilice robots Linux para ejecutar automatizaciones desatendidas. Al crear una automatización, asegúrese de seleccionar la compatibilidad multiplataforma.
