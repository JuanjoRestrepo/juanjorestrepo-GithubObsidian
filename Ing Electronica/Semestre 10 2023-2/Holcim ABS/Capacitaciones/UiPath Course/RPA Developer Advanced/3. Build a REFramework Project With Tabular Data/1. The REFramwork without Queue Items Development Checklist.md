**1. Prerequisites**  
De forma predeterminada, en el REFramework el tipo '**TransactionItem**' es '**QueueItem'**. Como estamos construyendo la automatización **sin las colas de Orchestrator**, como primer paso, necesitamos identificar **qué tipo de datos necesita procesar la automatización** para cada **transacción**.

**2. Configuration in UiPath Studio**  
Cubre la creación de un **nuevo proceso** con la plantilla REFramework. Posteriormente, en función de los requisitos del proceso comercial, lo lleva a través de cada paso para personalizar el archivo de configuración en consecuencia.

**3. Change the 'TransactionItem' data type**   
Ya hemos identificado el tipo de datos en la sección de Prerrequisitos. Esta sección cubre todos los pasos necesarios para cambiar el **tipo de datos** para **TransactionItem** del predeterminado **QueueItem** al **necesario** para el proceso.

**4. Applications used: Open/Close/Kill process**   
Cubre los pasos necesarios para editar los flujos de trabajo del marco que inician las aplicaciones requeridas y las cierran cuando finaliza el procesamiento. Si no es posible cerrarlos, los cierra a la fuerza.

Esta sección cubre los pasos para editar el flujo de trabajo '**Obtener datos de transacción****' para acomodar los datos de diferentes fuentes, ya que no estamos usando la cola de Orchestrator. También cubre los pasos para editar el flujo de trabajo '**Procesar transacción**' para procesar cada transacción en función de nuestra automatización de procesos comerciales.
