### Inner Join con Pandas

#### Primero, ¿Qué es un **Inner Join (Unión Interna)**?

![[Pasted image 20250528200241.png]]

- Solo devuelve filas que tengan valores coincidentes en ambas tablas

#### Con pandas

- Usamos el método `merge`
- Usamos el argumento `on` para indicar al método que queremos fusionar los dos dataframes de la columna `ward` 
- Como primero enumaramos la tabla de distritos `wards`, sus columnas apareceran primero en el resultado seguidas de la tabla de `census`
```python
ward_census = wards.merge(census, on='ward')
print(ward_census.head(4))
```

![[Pasted image 20250528195934.png]]

```python
print(ward_census.shape)
```

![[Pasted image 20250528200029.png]]

- El dataframe resultante es de **50 filas y 9 columnas**
- Las filas devueltas tienen valores coincidentes para la columna `ward` en ambas tablas

![[Pasted image 20250528200346.png]]

- Las columnas resultantes tienen valores con `x` y `y`
- Esto es porque tanto las tablas de distritos como las de census contenian direccion y zip code.
- Para evitar repeticiones de columnas con el mismo nombre, el metodo `merge` les asigna un sufijo
- Podemos usar el argumento `suffixes` para controlar este comportamiento

```python
ward_census = wards.merge(census, on='ward', suffixes=('_ward', '_cen'))
print(ward_census.head())
print(ward_census.shape)
```
