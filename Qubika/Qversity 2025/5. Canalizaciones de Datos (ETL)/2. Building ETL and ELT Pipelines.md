## Filtering a DataFrame

```python
# First, by rows
data_frame.loc[data_frame["name"] == "Apparel", :]

# Then, by columns
data_frame.loc[:, ["name", "num_firms"]]
```

- **`Data_frame.loc[ ... , : ]`**: Indica que vamos a seleccionar filas basadas en una condición y luego todas las columnas. El `:` después de la coma significa "todas las columnas".
- `.loc`: filtra el dataframe
- `:`: significa **todo**
- **`data_frame["name"] == "Apparel"`**: Esta es la **condición booleana** que se aplica a las filas.
    - `data_frame["name"]` selecciona la columna 'name' del DataFrame.
    - `"Apparel"` compara cada valor en la columna 'name' con la cadena "Apparel".
    - El resultado de esta comparación es una Serie de valores `True` o `False` (una máscara booleana) del mismo tamaño que el número de filas del DataFrame. `True` para las filas donde el nombre es "Apparel", `False` en caso contrario.


## Write a DataFrame to a .csv file

```python
# Write a DataFrame to a .csv file
data_frame.to_csv("cleaned_data.csv")
```

Esta línea de código utiliza el método `.to_csv()` de un DataFrame de pandas para **guardar el contenido del DataFrame en un archivo CSV**.

- **`data_frame.to_csv(...)`**: Es el método del objeto `data_frame` que permite exportar sus datos.
- **`"cleaned_data.csv"`**: Es la ruta y el nombre del archivo donde se guardarán los datos. Si el archivo no existe, se creará; si ya existe, se sobrescribirá por defecto.

## Running SQL Queries

```python
data_warehouse.execute(
    """
    CREATE TABLE total_sales AS
    SELECT
        ds,
        SUM(sales)
    FROM raw_sales_data
    GROUP BY ds;
    """
)
```

- **`data_warehouse.execute(...)`**: Llama a un método `execute` de un objeto `data_warehouse` (que representa la conexión a la base de datos). Este método se usa para enviar y ejecutar comandos SQL.
- **La consulta SQL interna:
    - **`CREATE TABLE total_sales AS`**: Crea una nueva tabla llamada `total_sales`.
    - **`SELECT ds, SUM(sales)`**: Selecciona la columna `ds` (probablemente una columna de fecha o identificador de día) y calcula la suma de la columna `sales`.
    - **`FROM raw_sales_data`**: Indica que los datos provienen de la tabla `raw_sales_data`.
    - **`GROUP BY ds`**: Agrupa los resultados por la columna `ds` para que `SUM(sales)` calcule las ventas totales para cada valor único de `ds`.
