
# Data Pipelines (Canalizadores de Datos)

- Son los responsables de mover datos de una fuente a un destino y transformarlos en algún punto del camino.

![[Pasted image 20250604185115.png]]

- Estas fuentes de datos pueden ser una variedad de cosas, como:
	- Archivos CSV
	- APIs
	- Bases de Datos
- Una vez se extraen los datos de un sistema de origen, **el objetivo es transformar estos datos y cargarlos en un destino donde puedan usarse para cosas** como:
	- Inteligencia Empresarial (Business Intelligence)
	- Machine Learning
	- AI

# ETL (Extract, Transform and Load)

##### **Los ETL Pipelines:**

1. **Extraen los Datos** antes de transformarlos y cargarlos en un destino
2. Patrón de Diseño de Data Pipelines **más tradicional**
3. Pueden extraer datos de **fuentes tabulares y no tabulares**
4. Usan bibliotecas de Python como pandas para manipular y transformar datos

# ELT (Extract, Load and Transform)

##### **Los ELT Pipelines:**

1. Patrón de Diseño más reciente
2. Ligado con la llegada de los **Data Warehouses**
3. Normalmente, operan con datos de origen tabular, antes de cargarlos en un **almacén de datos (Warehouse**) para su transformación

### Ejemplo ETL en Python 

```python
def load(data_frame, target_table):
    # Some custom-built Python logic to load data to SQL
    data_frame.to_sql(name=target_table, con=POSTGRES_CONNECTION)
    print(f"Loading data to the {target_table} table")

# Now, run the data pipeline
extracted_data = extract(file_name="raw_data.csv")
transformed_data = transform(data_frame=extracted_data)
load(data_frame=transformed_data, target_table="cleaned_data")
```

Este código Python define una función `load` que toma un DataFrame y un nombre de tabla, y luego **carga el DataFrame en una tabla SQL** usando una conexión a PostgreSQL.

1. **`data_frame.to_sql(name=target_table, con=POSTGRES_CONNECTION)`**:
	- Este es un método de pandas (`.to_sql()`) que se utiliza para **escribir el contenido de un DataFrame (`data_frame`) en una tabla en una base de datos SQL**.
	- `name=target_table`: Especifica el nombre de la tabla en la base de datos a la que se cargarán los datos.
	- `con=POSTGRES_CONNECTION`: Es el objeto de conexión a la base de datos (en este caso una conexión a PostgreSQL) que pandas usará para interactuar con la base de datos.

2. **`extract`**: Extrae datos de un archivo CSV (`raw_data.csv`).
3. **`transform`**: Transforma los datos extraídos.
4. **`load`**: Carga los datos ya transformados en una tabla SQL llamada `cleaned_data`.

### Ejemplo ELT en Python 

```python
def transform(source_table, target_table):
    data_warehouse.run_sql(f"""
    CREATE TABLE {target_table} AS
    SELECT
        <field-name>, <field-name>, ...
    FROM {source_table};
    """)

# Similar to ETL pipelines, call the extract, load, and transform functions
extracted_data = extract(file_name="raw_data.csv")
load(data_frame=extracted_data, table_name="raw_data")
transform(source_table="raw_data", target_table="cleaned_data")
```

1. **`def transform(source_table, target_table):`**:
	- Toma dos argumentos: `source_table` (la tabla de origen donde residen los datos brutos) y `target_table` (la tabla donde se almacenarán los datos transformados).
2. **`data_warehouse.run_sql(f"""...""")`**:
	- Dentro de la función `transform`, esta línea ejecuta una **consulta SQL directamente en el data warehouse**.
	- `data_warehouse` es un objeto que representa la conexión a tu almacén de datos (por ejemplo, Snowflake, BigQuery, Redshift, etc.).
	- `run_sql()` es un método de ese objeto que permite enviar y ejecutar comandos SQL.
	- La consulta SQL usa una f-string para insertar dinámicamente los nombres de las tablas:
	    - `CREATE TABLE {target_table} AS`: Crea una nueva tabla (o sobrescribe una existente) con el nombre especificado en `target_table`.
	    - `SELECT <field-name>, <field-name>, ...`: Selecciona y potencialmente modifica las columnas (`<field-name>`) de la tabla de origen. Aquí es donde se realizarían las operaciones de limpieza, agregación, unión, etc.
	    - `FROM {source_table};`: Indica de qué tabla se están extrayendo los datos dentro del data warehouse.
3. Flujo de la pipeline ELT:
	- **`extracted_data = extract(file_name="raw_data.csv")`**: La fase de **Extracción (E)**. 
		- Los datos se leen desde un archivo fuente (por ejemplo, un CSV).
	- **`load(data_frame=extracted_data, table_name="raw_data")`**: La fase de **Carga (L)**. 
		- Los datos _extraídos_ (que aún están en su formato bruto) se cargan directamente en una tabla (`raw_data`) dentro del data warehouse. Esto se hace antes de cualquier transformación significativa.
	- **`transform(source_table="raw_data", target_table="cleaned_data")`**: La fase de **Transformación (T)**. 
		- Una vez que los datos brutos están en el data warehouse, la función `transform` se llama para ejecutar la lógica de transformación **directamente en el data warehouse**, moviendo los datos procesados de `raw_data` a `cleaned_data`.
