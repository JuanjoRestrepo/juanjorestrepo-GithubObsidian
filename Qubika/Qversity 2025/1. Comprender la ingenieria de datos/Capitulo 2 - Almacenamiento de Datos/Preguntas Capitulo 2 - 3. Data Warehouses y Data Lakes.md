**Tell the truth (Di la verdad)**
Hasta ahora, has oído hablar de los lagos de datos, los almacenes de datos y las bases de datos, y acabas de ver las diferencias entre los tres.

¿Cuál de las siguientes afirmaciones es cierta?

Selecciona una respuesta

- Un catálogo de datos es un documento que enumera los precios de los distintos servicios de almacenamiento de datos.
- **Un almacén de datos es un tipo de base de datos.**
- Una base de datos relacional suele almacenar datos no estructurados.
- El lago de datos almacena datos bien organizados y procesados, fáciles de analizar.


---

**Un lago de datos:**
- Está optimizado para ser rentable.
- Puede almacenar datos estructurados, semiestructurados y no estructurados.
- Almacena datos sin procesar.

**Almacén de datos en la nube:**
- Normalmente almacena cantidades de datos menores que el otro.
- Almacena principalmente datos estructurados.
- Está optimizado para el análisis.
