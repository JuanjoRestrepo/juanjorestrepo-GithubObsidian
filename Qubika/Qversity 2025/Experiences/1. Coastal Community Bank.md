 - Complejidad de compartir datos

# Stack de Qubika
1. Databricks (main)
	1. Se puede integrar con AWS, Azure, Google Cloud, etc...
	2. Snowflake (competencia) 
	3. Se usa para la transformacion, generacion de reportes, modelos
- Proceso
	- El banco tiene los datos en un sharepoint, computadora, etc...
	- Se suben al datalake de azure (Faltan cositas, especialmente las que estan en excel)
	- 2. Ingesta de datos (Azure signals)
	- 3. Datalake tables
		- Base de datos de databricks y se crean workflows
	- 4. Powerbi
		- Business inteligence del banco para reportes a nivel ejecutivo, toma de decisiones, analisis de riesgos, etc...
		- Donde la data ya esta acomodada y procesada para que pueda ser interpretada por el usuario
