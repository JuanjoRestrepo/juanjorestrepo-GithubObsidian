Para cargar un DataFrame en una base de datos Postgres, pandas proporciona el método `.to_sql`

## `to_sql`:
- Se llama en el DF que se va a cargar y toma los parámetros: **nombre, con, if_exists, index y index_label**


![[Pasted image 20250609182719.png]]

- *db_engine*: se pasa el parámetro con, para formar una conexion a la base de datos

- *name:* el nombre de la tabla en la base de datos en la que se escribira el dataframe
- *con:* 
- *if_exists:* determina como se agregan los datos a la tabla en una DB
	- *append*: los datos se agregan a la tabla existente
	- *replace*: sobrescribe los datos existentes en la tabla, usando el Dataframe actual
- *index:* booleano
	- True: si el índice se debe cargar en la tabla SQL
	- False: lo contrario
- *index_label:* nombre de la columna en SQL en la que se escribirá el índice de pandas, si se carga el índice en la tabla
	- En el ejemplo `timestamps` es el nombre de la columna en la que se escribirá el índice de pandas


## Validating Data Persistence with Pandas

Una vez se han cargado los datos en una base de datos Postgres, **es importante validar que se hayan conservado los datos como se esperaba**

- Sino, los consumidores y procesos posteriores se verán limitados por datos erróneos
- Los usuarios de datos pueden perder la confianza en los datos creados por el pipeline

Para ello, tendremos en cuenta lo siguiente:

1. Asegurarse que los datos deben poder consultarse (queriable) y devolver resultados lógicos
2. Asegurarse que los recuentos coincidan (hagan match) entre los datos transformados y datos persistentes
3. Validar que cada fila este presente en ambos DataFrames

#### Ejemplo con pandas

```python
# Pull data written to SQL table
to_validate = pd.read_sql("SELECT * FROM cleaned_stock_data", db_engine)
```

`read_sql`: permite consultar los datos cargados en una BD SQL para su validación

Luego este Dataframe se puede comparar con el Dataframe transformado para validar los recuentos y registrar la igualdad (*counts, record equality*)
