## Logging Data Pipeline Performance (Registro para alertar sobre Rendimiento de Pipelines)

## Los registros

- Los registros **son mensajes creados y escritos durante la ejecución** de un Pipeline
- Son configurados por los desarrolladores y **documentan el rendimiento de un pipeline**
- Proveen un **punto de partida cuando las soluciones fallan,** permitiendo **revisar la ejecución del proceso**
- Esenciales para crear canales de datos transparentes

```python
import logging

logging.basicConfig(format='%(levelname)s: %(message)s', level=logging.DEBUG)

# Create different types of logs
logging.debug(f"Variable has value {path}")
logging.info("Data has been transformed and will now be loaded.")
```

Ahora exploraremos cuatro niveles de registro:

#### Debug

![[Pasted image 20250605172834.png]]
- Usamos los Debug Logs para proporcionar conocimientos sobre cuestiones como la **dimensionalidad de los datos, el tipo y los valores de las variables**
### Info
- Para proporcionar **informacion basica y puntos de control (Checkpoints**) en todo la ejecucion del pipeline
- Notificar sobre operaciones que ocurren en los datos

### Warnings y Errors

```python
import logging

logging.basicConfig(format='%(levelname)s: %(message)s', level=logging.DEBUG)

# Create different types of logs
logging.warning("Unexpected number of rows detected.")
logging.error("{ke} arose in execution.")
```

- Los Warnings son cuando **algo inesperado sucede**, pero n**o necesariamente se producido una excepción** (Cantidad inesperada de filas o tipos de datos nunca antes vistos)
- Los registros de Errores cuando ocurre una **excepción que debería detener la ejecución**

### Handling exceptions with `try-except`

Pass the specific exception in the `except` clause
```python
try:
    # Try to filter by price_change
    clean_stock_data = transform(raw_stock_data)
    logging.info("Successfully filtered DataFrame by 'price_change'")

except KeyError as ke:
    # Handle the error, create new column, transform
    logging.warning(f"[{ke}]: Cannot filter DataFrame by 'price_change'")
    raw_stock_data["price_change"] = raw_stock_data["close"] - raw_stock_data["open"]
    clean_stock_data = transform(raw_stock_data)
```
