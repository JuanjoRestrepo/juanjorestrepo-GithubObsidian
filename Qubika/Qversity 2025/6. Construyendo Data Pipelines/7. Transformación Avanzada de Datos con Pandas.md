## Datos Faltantes

![[Pasted image 20250609175806.png]]

- Normalmente se asigna con valor **NaN**
- Para esto, podemos usar el metodo `fillna` de pandas

![[Pasted image 20250609180042.png]]

- En el ejemplo, se relleno con ceros, pero se puede con cualquier valor
- Tambien se pueden pasar diccionarios

![[Pasted image 20250609180128.png]]

- Cuando el `axis=1` los pares clave-valor representan nombres de columnas, y los valores asociados se usan para completar los valores faltantes de esa columna
- En esta ocasión, rellenamos con **cero para open** y **0.5 para close**

![[Pasted image 20250609180247.png]]

- Tambien podemos rellenar usando los valores de otras columnas

![[Pasted image 20250609180358.png]]

## Grouping data

![[Pasted image 20250609181139.png]]

El equivalente en python es `groupby()`

![[Pasted image 20250609181207.png]]

- Se agrupa por la columna `ticker` y encuentra la media de las otras columnas
- `axis=0` significa que agrupa por etiquetas de filas
- `axis=1` significa que agrupa por etiquetas de columnas

![[Pasted image 20250609181626.png]]
- Tambien se puede usar los valores mínimos, máximos y la sumatorias
