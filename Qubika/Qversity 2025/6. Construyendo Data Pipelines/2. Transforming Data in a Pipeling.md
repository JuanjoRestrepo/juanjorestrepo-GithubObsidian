## Filtrado de Registros en pandas con `.loc[]` e `.iloc[]`

En pandas, los accesores `.loc[]` e `.iloc[]` son herramientas fundamentales para seleccionar y filtrar datos (filas y columnas) dentro de un DataFrame.

### 1. Filtrado con `.loc[]` (Basado en Etiquetas/Condiciones Booleanas)

`data_frame.loc[filas, columnas]` permite transformar ambas dimensiones de un DataFrame.

* **Sintaxis General**: `DataFrame.loc[etiqueta_fila / condición_booleana, etiqueta_columna / lista_de_columnas]`
* **`:` (dos puntos)**: Significa "todas las filas" o "todas las columnas", dependiendo de su posición.

#### Ejemplos Prácticos:
1.  **Mantener solo entradas no-cero (filtrado de filas por condición)**:
```python
cleaned = raw_stock_data.loc[raw_stock_data["open"] > 0, :]
```

- `raw_stock_data["open"] > 0`: Crea una serie booleana (True/False) donde `True` indica que el valor en la columna "open" es mayor que 0.
    * `raw_stock_data.loc[condicion_booleana, :]`: Selecciona todas las filas donde la condición es `True` y todas las columnas (`:`).

2.  **Eliminar columnas en exceso (filtrado de columnas por nombres)**:
```python
cleaned = raw_stock_data.loc[:, ["timestamps", "open", "close"]]
```
- `raw_stock_data.loc[:, lista_de_nombres_columnas]`: Selecciona todas las filas (`:`) y solo las columnas cuyos nombres están en la lista `["timestamps", "open", "close"]`.

3.  **Combinar en un solo paso (filtrado de filas y columnas simultáneamente)**:

```python
cleaned = raw_stock_data.loc[raw_stock_data["open"] > 0, ["timestamps", "open", "close"]]
```
-  Aplica la condición de fila y la selección de columna en una única operación `.loc[]`. Es más eficiente.

### 2. Filtrado con `.iloc[]` (Basado en Índice de Enteros)

`DataFrame.iloc[]` usa el indexado de enteros (posiciones numéricas) para filtrar DataFrames.

* **Sintaxis General**: `DataFrame.iloc[índice_fila / rango_filas, índice_columna / rango_columnas]`
* **Importante**: Es exclusivo del índice final (como en slicing de listas de Python).

#### Ejemplo Práctico:

```python
cleaned = raw_stock_data.iloc[[0:50], [0, 1, 2]] # Nota: la imagen muestra [0, 1, 2], lo cual es una lista de índices de columnas.
```

## Validando Transformaciones en DataFrames de pandas

Transformar datos conlleva riesgos:
* **Pérdida de información**: Asegúrate de que las transformaciones no eliminen datos importantes.
* **Creación de datos defectuosos**: Valida que las transformaciones no introduzcan errores o inconsistencias.
### Métodos para Investigar DataFrames Transformados (Ejemplos):

1.  **Inspeccionar las primeras filas (`.head()`):**
    ```python
    cleaned = raw_stock_data.loc[raw_stock_data["open"] > 0, ["timestamps", "open", "close"]]
    print(cleaned.head())
    ```
    * Muestra las primeras filas del DataFrame `cleaned` después de la transformación. Permite una revisión rápida de los datos transformados.

2.  **Obtener los registros más pequeños y grandes (`.nsmallest()` y `.nlargest()`):**
    ```python
    print(cleaned.nsmallest(10, ["timestamps"]))
    print(cleaned.nlargest(10, ["timestamps"]))
    ```
    * `.nsmallest(n, columnas)`: Devuelve las `n` filas con los valores más pequeños en las columnas especificadas.
    * `.nlargest(n, columnas)`: Devuelve las `n` filas con los valores más grandes en las columnas especificadas.
    * Estos métodos son útiles para verificar si las transformaciones han afectado los valores extremos de manera inesperada.
