
Carga datos a un archivo:
- Asegura que los consumidores de datos tengan acceso estable a los datos transformados
- Ocurre como un paso final en un proceso ETL, así como entre pasos discretos
- Captura una "instantánea" de los datos


# Carga de datos en archivos CSV usando pandas

El método `.to_csv()`

```python
import pandas as pd

# Extracción y transformación de datos
raw_data = pd.read_csv("raw_stock_data.csv")
stock_data = raw_data.loc[raw_data["open"] > 100, ["timestamps", "open"]]

# Cargar datos en un archivo .csv
stock_data.to_csv("stock_data.csv")
```


# Personalizando la salida de archivos CSV

`stock_data.to_csv("./stock_data.csv", header=True)`
* Toma `True`, `False` o una lista de valores de cadena

`stock_data.to_csv("./stock_data.csv", index=True)`
* Toma `True` o `False`
* Determina si la columna de índice se escribe en el archivo

`stock_data.to_csv("./stock_data.csv", sep="|")`
* Toma un valor de cadena usado para separar columnas en el archivo
* El carácter `|` es una opción común


# Asegurando la persistencia de los datos

¿Se almacenó correctamente el DataFrame en el archivo CSV?

```python
import pandas
import os # Importar el módulo os

# Extraer, transformar y cargar datos
raw_data = pandas.read_csv("raw_stock_data.csv")
stock_data = raw_data.loc[raw_data["open"] > 100, ["timestamps", "open"]]
stock_data.to_csv("stock_data.csv")

# Comprobar que la ruta existe
file_exists = os.path.exists("stock_data.csv")
print(file_exists)
```
