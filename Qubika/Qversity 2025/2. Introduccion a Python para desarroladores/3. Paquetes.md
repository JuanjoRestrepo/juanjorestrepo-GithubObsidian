# Packages

- Una colección de módulos = Package
    - También podría escucharse como una librería
- Los packages están disponibles públicamente y son gratuitos
- Primero necesitan ser descargados de PyPI
- Luego pueden ser importados y usados como módulos


**Instalando un paquete**

- Terminal / Símbolo del sistema
    - Nos permite ejecutar comandos para realizar tareas

<!-- end list -->

```python
python3 -m pip install <package_name>
```

- `python3` - Usado para ejecutar código Python desde la terminal
- `pip` - Preferred Installer Program
