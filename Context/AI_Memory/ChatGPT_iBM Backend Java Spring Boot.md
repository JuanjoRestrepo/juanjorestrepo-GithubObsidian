## 1️⃣ ¿Qué es SonarQube? (en una frase)
**SonarQube** es una herramienta de **análisis estático de código** que revisa tu código **sin ejecutarlo** para detectar:
- Bugs potenciales
- Vulnerabilidades de seguridad
- Code smells (malas prácticas)
- Duplicación de código
- Deuda técnica
- Cobertura de pruebas

Se integra normalmente en **CI/CD** (Jenkins, GitHub Actions, GitLab CI).

---

## 2️⃣ ¿Qué revisa SonarQube en Java?
En proyectos Java / Spring Boot, SonarQube valida cosas como:

- Métodos demasiado largos
- Clases con demasiadas responsabilidades
- Manejo incorrecto de excepciones
- Posibles `NullPointerException`
- Uso inseguro de APIs
- Convenciones de naming
- Falta de pruebas unitarias
- Violaciones de principios SOLID

Ejemplo típico:
```java
if (obj.equals(null))  // ❌ Sonar lo marca
```
