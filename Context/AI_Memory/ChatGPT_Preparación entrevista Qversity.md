### a) SQL avanzado  
**Pregunta tipo:**  
> “Write a query to calculate the 90th percentile of sales_per_day per store and flag days above that percentile as outliers.”

```sql
WITH store_sales AS (
  SELECT
    store_id,
    sale_date,
    SUM(amount) AS total_sales
  FROM sales
  GROUP BY store_id, sale_date
),
percentiles AS (
  SELECT
    store_id,
    PERCENTILE_CONT(0.9) WITHIN GROUP (ORDER BY total_sales) AS p90
  FROM store_sales
  GROUP BY store_id
)
SELECT
  s.store_id,
  s.sale_date,
  s.total_sales,
  CASE WHEN s.total_sales > p.p90 THEN 'outlier' ELSE 'normal' END AS outlier_flag
FROM store_sales s
JOIN percentiles p USING (store_id);
```

def summarize_by_category(df, category_col, value_col):
    df_clean = df.dropna(subset=[category_col, value_col])
    summary = (
        df_clean
        .groupby(category_col)[value_col]
        .agg(['mean', 'std', 'count'])

### c) DBT  
**Pregunta tipo:**  
> “Explain the dbt workflow and how you’d implement tests and snapshots.”

1. **Project structure:**  
   - `models/` → SQL files  
   - `tests/` → YAML con tests de singularidad, no‑null  
   - `snapshots/` → versionado de cambios de datos
2. **Flujo:**  
   1. `dbt run` (compila y materializa)  
   2. `dbt test` (valida tests definidos en YAML)  
   3. `dbt snapshot` (guarda historiales)  
3. **Idempotencia:** cada ejecución produce resultados consistentes; las transformaciones deben ser determinísticas.

### e) Fundamentos de datos  
**Pregunta tipo:**  
> “What’s the difference between a data lake and a data warehouse? And ETL vs ELT?”

- **Data Lake:** almacena datos crudos en múltiples formatos.  
- **Data Warehouse:** datos estructurados, optimizados para consultas analíticas.  
- **ETL:** extraer, transformar y cargar antes de análisis.  
- **ELT:** extraer, cargar y luego transformar dentro del almacenamiento moderno (p.ej., Snowflake).

### f) Conceptos básicos de IA  
**Pregunta tipo:**  
> “Define supervised vs unsupervised learning and explain accuracy, precision, recall and F1.”

- **Supervised:** modelos entrenados con etiquetas (p.ej., regresión, clasificación).  
- **Unsupervised:** descubre patrones sin etiquetas (p.ej., clustering, PCA).  
- **Métricas:**  
  - **Accuracy:** (TP+TN)/Total  
  - **Precision:** TP/(TP+FP)  
  - **Recall:** TP/(TP+FN)  
  - **F1‑score:** 2·(Precision·Recall)/(Precision+Recall)
