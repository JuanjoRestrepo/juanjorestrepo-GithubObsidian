For the past two challenges, we've been working primarily in UNIX System Services (USS) with a shell that we got from Secure Shelling (SSHing) into the system. You can certainly accomplish a lot this way, but many mission-critical applications and important business resources rely on job control language (JCL), partitioned data sets, and other features that we devoted a lot of time on in the earlier challenges.

Put simply, JCL and data sets are unique parts of the IBM® z/OS® operating system that help make it strong, secure and mature. We rely on this foundational technology as we move towards newer tools like Red Hat® Ansible®, Python, AI and advanced cryptography.

Fortunately, we have IBM Z® Open Automation Utilities, which lets us perform a wide variety of z/OS tasks right from the USS shell. We can even reference these utilities from Python, meaning a lot of the logic we learned about from the previous challenge will directly apply here.
